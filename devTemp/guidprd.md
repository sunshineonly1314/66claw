## 一、产品概述

### 1.1 产品定位

安装向导是 ClawbotCN 的首次使用配置界面，帮助用户完成从 AI 服务配置到系统启动的全流程引导。

### 1.2 访问入口

- **访问地址**: `http://<host>:<port>/setup`
- **触发条件**: 首次安装或配置未完成时自动跳转
- **退出条件**: 完成所有配置步骤后重启并跳转至主页

### 1.3 流程概览

```
Step 1        Step 2        Step 3        Step 4        Step 5        Step 6
AI服务    →   安全设置   →   工作目录   →   指挥渠道   →   产品验证   →   完成重启
选择配置      选择模式      设置目录      选择渠道      许可证验证     配置摘要
```

### 1.4 支持平台

| 平台 | 版本类型 | 沙盒类型 | 隔离级别 |
|------|---------|---------|---------|
| macOS | Lite | 软沙盒 | ⭐⭐⭐ |
| Windows | Lite | 轻量沙盒 | ⭐⭐⭐ |
| Windows | Pro | Docker 沙盒 | ⭐⭐⭐⭐⭐ |
| Linux | Lite | 轻量沙盒 | ⭐⭐⭐ |
| Linux | Pro | Docker 沙盒 | ⭐⭐⭐⭐⭐ |

## 四、Step 2：安全设置

### 4.1 页面信息

| 项目 | 内容 |
|------|------|
| 标题 | 第二步：安全设置 |
| 副标题 | 选择 AI 助手的权限级别 |

### 4.2 页面元素

#### 4.2.1 沙盒说明折叠区

- **默认状态**: 展开
- **标题**: 💡 什么是「沙盒」？
- **内容**:
  > 简单说：沙盒就像给 AI 画了个「活动范围」，它只能在这个范围里干活。
  > 超出范围的文件和操作，AI 碰不到，也改不了。

#### 4.2.2 风险提示框

- **样式**: 橙色/黄色警告框
- **图标**: ⚠️
- **标题**: 重要提示：请认真阅读
- **内容**:
  > AI 助手存在「提示词注入」风险 —— 恶意网页或文档可能诱导 AI 执行危险操作，例如：读取你的密码文件、发送敏感信息、删除重要数据。
  >
  > 👉 强烈建议：使用一台独立设备部署 ClawbotCN，与重要数据物理隔离。
  >
  > 如果必须在工作电脑上使用，请选择「智能保护」模式，并确保工作目录不包含敏感文件。

#### 4.2.3 免责声明

- **样式**: 小字灰色文案
- **内容**: ClawbotCN 提供沙盒保护机制，但无法完全杜绝 AI 误操作风险。使用本软件即表示您已了解并接受相关风险，因使用不当造成的数据丢失或安全问题，开发者不承担责任。

#### 4.2.4 安全模式选择

三个选项卡片，纵向排列：

**选项 1：完全保护**
| 属性 | 内容 |
|------|------|
| 图标 | 🛡️ |
| 标题 | 完全保护 |
| 描述 | AI 的所有操作都在「沙盒」中进行，无法访问沙盒外的文件。最安全，但某些需要系统权限的功能可能受限。 |
| 适合场景 | 电脑上有重要文件、多人共用设备 |

**选项 2：智能保护（推荐）**
| 属性 | 内容 |
|------|------|
| 图标 | 🔒 |
| 标题 | 智能保护 |
| 标签 | ⭐ 推荐 |
| 描述 | 你直接对话时，AI 有正常权限；后台执行的任务自动受沙盒限制。兼顾使用体验和安全性。 |
| 适合场景 | 日常工作电脑、需要 AI 协助处理文件 |
| 默认选中 | ✅ |

**选项 3：关闭保护**
| 属性 | 内容 |
|------|------|
| 图标 | ⚡ |
| 标题 | 关闭保护 |
| 标签 | 👨‍💻 懂行专用 |
| 描述 | AI 拥有完整系统权限，解锁全部能力，探索更多可能性。 |
| 警告 | ⚠️ 务必了解风险：AI 可能误删文件、执行危险命令。选择此模式 = 你已充分理解并愿意承担一切后果。 |
| 适合场景 | 独立设备、已备份数据、懂技术能自己兜底的高手 |

#### 4.2.5 快速决策指引

- **样式**: 灰色提示框
- **图标**: 📋
- **标题**: 不知道选哪个？看这里：
- **内容列表**:
  - 这是我的主力工作电脑 → 选「智能保护」
  - 电脑上有公司/客户数据 → 选「完全保护」
  - 独立设备 + 我懂技术 → 可选「关闭保护」解锁全部能力

#### 4.2.6 平台相关提示

根据检测到的平台动态显示不同内容：

**macOS 版本**:
> ℹ️ 当前版本: macOS Lite（软沙盒）
>
> macOS 版本使用软沙盒保护，通过目录隔离和命令过滤提供基本安全保障。软沙盒无法像 Docker 那样完全隔离系统，如需更高安全级别，建议在虚拟机或专用设备上运行。

**Windows/Linux Lite 版本**:
> ℹ️ 当前版本: {平台} Lite（轻量沙盒）
>
> Lite 版本使用轻量沙盒保护，通过目录限制和命令过滤提供基本安全保障。如需更高安全级别，可考虑安装 Pro 版本（Docker 沙盒）。

**Windows/Linux Pro 版本**:
> ✅ 当前版本: {平台} Pro（Docker 沙盒）
>
> Pro 版本使用 Docker 容器沙盒，提供完整的文件系统、进程和网络隔离。这是最高安全级别的保护方案。

### 4.3 下一步条件

- 已选择任意安全模式（默认已选「智能保护」）

| 项目 | 内容 |
|------|------|

## 九、状态管理

### 9.1 全局状态

| 状态项 | 类型 | 说明 |
|-------|------|------|
| currentStep | number | 当前步骤 (1-6) |
| platform | object | 平台信息 (os, arch, variant, sandboxType) |
| selectedProvider | string | 选中的 AI 平台 ID |
| selectedSecurity | string | 安全模式 (full/standard/trust) |
| workspace | string | 主工作目录 |
| trustedDirs | array | 额外信任目录列表 |
| selectedChannels | array | 选中的渠道 ID 数组 |
| licenseValidated | boolean | 许可证是否已验证 |
| licenseExpires | string | 许可证过期时间 |

### 9.2 步骤验证规则

| 步骤 | 进入下一步条件 |
|------|---------------|
| Step 1 | selectedProvider 不为空 && apiKey 不为空 |
| Step 2 | selectedSecurity 不为空（默认已选） |
| Step 3 | workspace 不为空 && 路径有效 |
| Step 4 | 无强制条件 |
| Step 5 | licenseValidated === true |
| Step 6 | - |

### 9.3 步骤跳转规则

- 允许点击「上一步」回退
- 已完成的步骤可以点击进度条节点跳转
- 未完成的步骤不可跳转

## 十、错误处理

### 10.1 网络错误

| 场景 | 处理方式 |
|------|---------|
| API 请求超时 | 显示 Toast 提示 + 允许重试 |
| 服务器错误 | 显示具体错误信息 + 允许重试 |
| 离线状态 | 显示离线提示 + 阻止下一步 |

### 10.2 验证错误

| 场景 | 处理方式 |
|------|---------|
| API Key 无效 | 输入框下方红字提示 |
| 许可证无效 | 验证状态区红色提示 |
| 路径无效 | 输入框下方红字提示 + 建议操作 |

### 10.3 重启失败

| 场景 | 处理方式 |
|------|---------|
| 重启超时 | 显示失败提示 + 手动操作指引 |
| 服务无法恢复 | 显示详细错误 + 联系支持选项 |
