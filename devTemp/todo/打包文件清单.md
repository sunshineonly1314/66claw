## 完整打包流程

```powershell
# 1. 进入项目目录
cd D:\codeknowledge\clawdbot-main\clawdbot-main

# 2. 安装依赖
pnpm install

# 3. 构建 TypeScript
pnpm build

# 4. 准备生产依赖（在外部目录）
mkdir -Force E:\clawdbuild\test-prod-deps
Copy-Item package.json E:\clawdbuild\test-prod-deps\
cd E:\clawdbuild\test-prod-deps
npm install --omit=dev

# 5. 回到项目目录，运行 Inno Setup 编译
cd D:\codeknowledge\clawdbot-main\clawdbot-main\scripts\windows
# 用 Inno Setup 打开 setup.iss 并编译
```

## setup.iss 关键配置说明

```ini
; 输出目录和文件名
OutputDir=E:\clawdbuild
OutputBaseFilename=ClawdbotCN-Setup-2026.2.26-x64

; node_modules 来源（需要提前准备）
Source: "E:\clawdbuild\test-prod-deps\node_modules\*"; DestDir: "{app}\node_modules"
```

**注意：** 如果需要修改输出路径，请同步修改 setup.iss 中的 `OutputDir` 和 node_modules 路径。

## 常见问题

### Q: 编译 setup.iss 报错找不到文件？
A: 确保已运行 `pnpm build` 生成 dist 目录，并准备好 node_modules。

### Q: 安装包太大？
A: node_modules 会占用大部分空间，可以考虑：
1. 使用 `npm install --omit=dev` 只安装生产依赖
2. 排除不需要的扩展插件
