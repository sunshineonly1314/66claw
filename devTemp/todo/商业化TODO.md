## 一、代码签名证书（优先级：高）

### 为什么需要？
- 未签名的安装包会触发 Windows SmartScreen "Windows 已保护你的电脑" 警告
- 杀毒软件可能误报为病毒
- 企业客户无法安装（被组策略拦截）
- **付费用户会以为买到假软件，导致退款和投诉**

### 需要购买什么？
| 证书类型 | 价格参考 | 推荐程度 | 说明 |
|----------|----------|----------|------|
| OV 代码签名证书 | ¥1500-3000/年 | ⭐⭐ | 基础级，新软件仍有 SmartScreen 警告，需积累下载信誉 |
| EV 代码签名证书 | ¥3000-5000/年 | ⭐⭐⭐⭐⭐ | **强烈推荐**，立即受信任，无 SmartScreen 警告 |

### 国内购买渠道
1. **亚洲诚信** (trustasia.com) - 国内 DigiCert 代理
2. **天威诚信** (itrus.cn) - 国内老牌 CA
3. **沃通 WoSign** (wosign.com)
4. **环度网信** (sslzhengshu.com)

### 购买流程
1. 选择 EV 代码签名证书（推荐）
2. 提交企业营业执照、法人身份证等材料
3. 等待审核（通常 3-7 个工作日）
4. 收到 USB 硬件令牌（EV 证书必须用硬件存储）
5. 配置签名环境

### 配置签名（购买后）

**修改 setup.iss 添加签名：**
```ini
[Setup]
; 添加签名工具配置
SignTool=mysigntool

[SignTool]
; 替换为实际证书信息
mysigntool=signtool sign /f "$qYOUR_CERT.pfx$q" /p "PASSWORD" /tr http://timestamp.digicert.com /td sha256 /fd sha256 $f
```

**或在构建脚本中签名：**
```powershell
# 签名安装包
signtool sign /f "证书.pfx" /p "密码" /tr http://timestamp.digicert.com /td sha256 /fd sha256 "ClawdbotCN-Setup.exe"

# 验证签名
signtool verify /pa "ClawdbotCN-Setup.exe"
```

## 二、软件著作权登记（优先级：中）

### 为什么需要？
- 保护你的二次开发代码
- 发生侵权纠纷时的法律凭证
- 部分招投标/政府采购要求提供
- 税收优惠（软件企业认定前置条件）

### 登记流程
1. 准备材料：
   - 软件著作权登记申请表
   - 源代码（前后各连续 30 页，共 60 页）
   - 软件说明书（操作手册或设计文档）
   - 企业营业执照副本
   
2. 登记渠道：
   - **中国版权保护中心** (ccopyright.com.cn) - 官方渠道，¥300
   - 代理机构 - 价格 ¥500-1500，加急 3-5 个工作日

3. 审核周期：普通 30-60 个工作日

### 注意事项
- 软件名称：建议用你们的品牌名，如 "ClawdbotCN AI 智能助手软件"
- 版本号：建议从 V1.0 开始
- **原始开源代码部分不能登记**，只能登记你们的二次开发部分

## 四、用户协议和隐私政策（优先级：高）

### 为什么需要？
- 中国《个人信息保护法》强制要求
- 应用商店上架必备
- 明确用户和你们的权利义务
- 免责条款保护

### 需要准备的文档

1. **用户服务协议** - 包含：
   - 服务内容描述
   - 用户权利和义务
   - 付费条款和退款政策
   - 知识产权声明
   - 免责声明
   - 争议解决方式

2. **隐私政策** - 包含：
   - 收集哪些用户数据
   - 数据如何使用
   - 数据如何存储和保护
   - 用户数据权利（查看、删除等）
   - 第三方 SDK 说明（如果有）

### 建议
- 可参考同类软件的协议模板
- 如果涉及较大金额或敏感数据，建议找律师审核

## 六、企业主体（优先级：中）

### 为什么需要？
- 以公司名义销售更专业
- 方便开具发票
- 购买代码签名证书需要企业资质
- 软件著作权可以登记在企业名下

### 如果已有公司
- 确保经营范围包含"软件开发"或"信息技术服务"
- 用公司名义购买证书和登记著作权

### 如果没有公司
- 可以以个人名义销售（但开票受限）
- 或者成立个体工商户/有限公司
