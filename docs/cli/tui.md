# `openclawcn tui`

Open the terminal UI connected to the Gateway.

Related:
- TUI guide: [TUI](/tui)

## Examples

```bash
openclawcn tui
openclawcn tui --url ws://127.0.0.1:18789 --token <token>
openclawcn tui --session main --deliver
```
