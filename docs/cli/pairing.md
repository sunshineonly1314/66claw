# `openclawcn pairing`

Approve or inspect DM pairing requests (for channels that support pairing).

Related:
- Pairing flow: [Pairing](/start/pairing)

## Commands

```bash
openclawcn pairing list whatsapp
openclawcn pairing approve whatsapp <code> --notify
```
