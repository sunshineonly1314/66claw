# `openclawcn setup`

Initialize `~/.openclawcn/openclawcn.json` and the agent workspace.

Related:
- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
openclawcn setup
openclawcn setup --workspace ~/clawd
```

To run the wizard via setup:

```bash
openclawcn setup --wizard
```
