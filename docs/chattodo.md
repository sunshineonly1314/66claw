## 一、全局优化

### 1.1 新手引导系统 (Onboarding)

- [ ] **P0** 创建新手引导向导组件 `ui/src/ui/views/onboarding.ts`
  - 分步骤引导：连接网关 → 配置模型 → 开始对话
  - 展示 OpenClawCN 核心能力卡片（天气、GitHub、生图、智能家居等）
  - 提供"跳过引导"选项
  - 首次访问自动显示，完成后不再显示

- [ ] **P0** 引导状态持久化
  - localStorage 存储引导完成状态
  - 提供"重新查看引导"入口（设置页或帮助菜单）

### 1.2 连接状态反馈增强

- [ ] **P0** 连接失败提示优化
  - 将 `disconnected (1008): unauthorized...` 替换为用户友好的中文提示
  - 提供明确的解决步骤（带复制按钮的命令）
  - 添加"一键复制 Token 命令"功能

- [ ] **P0** 连接状态视觉增强
  - 顶栏 Health 状态添加脉动动画（连接中）
  - 添加自动重连进度指示
  - 断开时显示上次连接时间

- [ ] **P1** 按钮禁用原因提示
  - 所有禁用按钮添加 `title` 属性说明原因
  - 考虑在按钮旁显示小文字提示（如 `(未连接)`）

### 1.3 全局加载与空状态

- [ ] **P1** 统一加载状态组件
  - 创建 `LoadingState` 组件，统一加载动画风格
  - 添加加载超时提示（超过 10s 提示检查网络）

- [ ] **P1** 统一空状态组件
  - 创建 `EmptyState` 组件，包含图标、标题、描述、操作按钮
  - 所有空状态提供明确的下一步操作

## 验收标准

1. **新用户首次访问**：能在 3 分钟内完成连接并发送第一条消息
2. **功能可发现性**：用户能自行发现 80% 以上的功能
3. **错误恢复**：所有错误提示都有明确的解决步骤
4. **响应性能**：页面切换 < 200ms，无明显卡顿
5. **翻译完整**：无英文原始 key 显示
