## 1. 产品概述

### 1.1 产品定位

ClawbotCN 是一个全栈国内运行的 AI 智能体网关控制平台，提供以下核心能力：

- **多渠道统一接入**：将 AI 智能体连接到 15+ 即时通信平台（微信、钉钉、飞书、企业微信、QQ、WhatsApp、Telegram、Discord、Slack 等）
- **多模型灵活切换**：支持 OpenAI、Anthropic、Google、AWS Bedrock、Ollama、GitHub Copilot 等多种 AI 模型提供商
- **智能体管理**：创建、配置和管理多个 AI 智能体，每个智能体可拥有独立的模型、技能、身份和工作空间
- **技能扩展**：75+ 可安装技能，覆盖生产力、开发、创意、通信等多个领域
- **MCP 协议支持**：通过 Model Context Protocol 扩展工具能力
- **Web 控制台**：全功能浏览器端管理界面，支持中英文双语

### 1.2 目标用户

| 用户角色 | 描述 | 主要使用场景 |
|---------|------|-------------|
| 个人用户 | 使用 AI 智能体进行日常对话、知识查询 | 对话页面、技能安装 |
| 开发者 | 搭建和管理 AI 智能体服务 | 配置管理、调试、日志 |
| 运营人员 | 管理多渠道 AI 客服/机器人 | 渠道管理、会话监控、定时任务 |
| 管理员 | 负责系统安全和权限控制 | 节点管理、执行审批、安全模式 |

### 1.3 技术架构概要

- **前端框架**：Lit（Web Components）
- **构建工具**：Vite
- **开发语言**：TypeScript
- **通信协议**：WebSocket（实时双工通信）+ HTTP REST
- **国际化**：自研 i18n 方案，支持中文（zh-CN）和英文（en）
- **主题系统**：支持亮色 / 暗色 / 跟随系统三种模式
- **桌面端**：Tauri 封装，支持 Windows / macOS

## 4. 安装向导 (Setup Wizard)

### 4.1 页面概述

安装向导是用户首次启动 ClawbotCN 后看到的第一个页面，引导用户完成从零到可用的全部核心配置。该页面仅在首次使用时出现，配置完成后不再显示（除非用户主动进入修改配置）。

- **页面标题**：ClawbotCN 安装向导
- **路由路径**：`/setup`（独立于主应用，由后端直接生成静态 HTML）
- **触发条件**：检测到配置不完整（缺少 API Key、工作目录或许可证）时自动重定向
- **使用频次**：一次性使用，完成后跳转到主控制台
- **技术实现**：后端 SSR 渲染的独立 HTML 页面（非 Lit 组件），无需前端框架加载

### 4.2 页面布局


### 4.3 进入条件与恢复机制

| 需求项 | 详细描述 |
|--------|---------|
| 自动检测 | 网关启动时检测配置完整性，不完整则将 `/` 请求重定向到 `/setup` |
| 完整性判断 | 需同时满足：有 API Key (`auth.profiles` 非空)、有工作目录 (`agents.defaults.workspace`)、有许可证 (`license.key`) 或有完成标记 (`setup.completedAt`) |
| 断点恢复 | 用户中途关闭浏览器后再次访问，自动恢复到上次完成的步骤（通过 `setup.lastCompletedStep` 持久化） |
| 历史配置检测 | 如果检测到之前已完成过配置（配置完整），显示"欢迎回来"页面(Page 0)，提供"直接开始使用"和"修改配置"两个选项 |
| 区域检测 | 自动检测用户所在区域（中国/全球），据此调整提供商推荐顺序 |
