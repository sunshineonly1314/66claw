## 一、风险提示放置位置总览

| 位置 | 触发时机 | 必要性 | 目的 |
|------|----------|--------|------|
| **首次启动协议弹窗** | 首次打开软件 | ⭐⭐⭐ 必须 | 用户同意协议才能使用 |
| **安全模式选择弹窗** | 切换到放开模式时 | ⭐⭐⭐ 必须 | 二次确认高风险操作 |
| **设置页模式说明** | 查看安全模式设置时 | ⭐⭐ 建议 | 常驻风险说明 |
| **对话界面风险标识** | 放开模式下对话时 | ⭐⭐ 建议 | 持续提醒当前风险状态 |
| **关于页面** | 查看软件信息时 | ⭐ 可选 | 展示开源协议声明 |

## 五、对话界面 - 放开模式风险标识

### 5.1 顶部常驻提示条

当用户处于**放开模式**时，在对话界面顶部显示：

```
┌─────────────────────────────────────────────────────────────┐
│ ⚠️ 当前为【放开模式】，AI安全限制已降低，请谨慎使用  [切换] │
└─────────────────────────────────────────────────────────────┘
```

- 背景色：**浅黄色** 或 **浅橙色**
- 点击"切换"可快速跳转到模式设置

### 5.2 对话框状态标识

在对话输入框旁边或上方显示当前模式：

```
智能模式：  🤖 智能模式
放开模式：  ⚡ 放开模式 ⚠️
绝对安全：  🛡️ 绝对安全
```

## 七、数据记录要求（技术实现）

为确保法律条款有效，需要记录以下数据：

| 记录项 | 存储位置 | 用途 |
|--------|----------|------|
| 协议同意时间 | 本地 + 可选云端 | 证明用户已同意协议 |
| 协议版本号 | 本地 | 证明用户同意的是哪个版本 |
| 安全模式选择记录 | 本地日志 | 证明用户自主选择了高风险模式 |
| 模式切换时间戳 | 本地日志 | 证明切换发生的时间 |
| 放开模式确认记录 | 本地日志 | 证明用户二次确认过风险 |

### 日志格式建议

```json
{
  "event": "mode_switch",
  "timestamp": "2026-02-03T14:30:00.000Z",
  "from_mode": "smart",
  "to_mode": "open",
  "user_confirmed": true,
  "confirm_timestamp": "2026-02-03T14:30:05.000Z"
}
```

## 八、文案优化原则

### 8.1 语言风格

| 场景 | 语气 | 示例 |
|------|------|------|
| 首次协议 | 正式、清晰 | "请您仔细阅读并同意..." |
| 风险警告 | 直接、警示 | "⚠️ 您即将..." |
| 日常提示 | 简洁、友好 | "当前为放开模式" |

### 8.2 关键词使用

**必须出现的关键词（法律效力）：**
- "自愿承担"
- "自行核验"
- "风险自担"
- "已阅读并理解"

**避免的表述：**
- ❌ "绝对安全"（没有绝对）
- ❌ "保证准确"（AI无法保证）
- ❌ "完全免责"（法律上无效）
