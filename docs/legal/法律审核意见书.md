## 三、需要补充/修改的条款

### 3.1 【重要】增加"生成式AI专项风险告知弹窗"

**问题**：根据《生成式人工智能服务管理暂行办法》第四条、第九条，提供生成式AI服务需要明确告知用户服务性质。

**建议**：在用户首次使用时，增加单独的**风险告知弹窗**，要求用户勾选确认：

```
┌─────────────────────────────────────────────────────────┐
│              AI 服务重要风险告知                          │
├─────────────────────────────────────────────────────────┤
│ 1. 本软件调用第三方AI大模型，AI生成内容可能不准确        │
│ 2. AI可能产生"幻觉"，编造不存在的事实                    │
│ 3. AI可能被恶意提示词攻击影响                            │
│ 4. 请勿将AI回答用于医疗、法律、财务等专业决策            │
│ 5. 您输入的内容将传输至第三方AI服务商处理                │
│                                                          │
│ ☑ 我已阅读并理解上述风险，自愿承担使用风险               │
│                                                          │
│                    [确认并继续]                           │
└─────────────────────────────────────────────────────────┘
```

### 3.2 【重要】补充"算法备案"相关说明

**问题**：根据《互联网信息服务算法推荐管理规定》，具有舆论属性或社会动员能力的算法推荐服务需要备案。

**建议**：在协议中增加条款：

```markdown
## 第X条 算法服务说明

X.1 本软件通过API调用第三方AI模型，不直接运行人工智能算法。

X.2 本软件不具备算法推荐、个性化推送等功能，仅提供用户主动
发起的对话交互服务。

X.3 如相关法规要求，我们将依法履行算法备案等合规义务。
```

### 3.3 【建议】强化"跨境数据传输"条款

**问题**：使用 Anthropic/OpenAI/Google 等境外服务涉及数据出境，需符合《数据出境安全评估办法》。

**当前条款**（隐私政策4.1）已有基本说明，建议强化为：

```markdown
### 4.1.1 跨境数据传输专项告知

当您选择使用以下境外AI服务时：
- Anthropic Claude（美国）
- OpenAI GPT（美国）  
- Google Gemini（美国）

您输入的内容将被传输至境外服务器处理。请注意：

(a) 此数据传输是服务运行的技术必要条件；
(b) 境外服务商受其所在国法律管辖，数据保护标准可能与中国不同；
(c) 您可选择仅使用境内AI服务（通义千问、文心一言、豆包等）以
    避免数据出境；
(d) **您使用境外AI服务即视为明确同意此跨境数据传输，并理解
    相关风险。**
```

### 3.4 【建议】增加"服务暂停/终止"的退款条款

**问题**：如果用户已付费但服务被终止，需要明确退款政策，否则可能引发消费纠纷。

**建议增加**：

```markdown
## 第X条 退款政策

X.1 因您违反本协议导致服务终止的，已支付费用不予退还。

X.2 因我们主动终止服务的，将按以下方式处理：
    (a) 未使用的授权期限，按剩余比例退款；
    (b) 退款将在30个工作日内原路返还。

X.3 因第三方AI服务停止运营导致本软件无法使用的，我们将尽力
    提供替代方案，但不承担退款义务。
```

## 五、特别风险提示

### 5.1 关于"AI模型有自己的意识"的说法

**法律上，AI 不具有法律主体资格**。当前条款已通过以下方式规避：
- 定性为"技术工具"（第2.1条）
- 明确内容由"第三方AI服务生成"（第2.2条）
- 全面免责声明（第三条）

**建议**：在市场宣传中避免使用"AI有意识""AI会思考"等拟人化表述，以免被解读为服务承诺。

### 5.2 关于"模型被攻击"的风险

当前条款（3.3、3.4）已覆盖 Prompt Injection 等攻击风险。

**建议**：
1. 在技术层面增加基本的输入过滤机制
2. 保留用户输入日志（匿名化），以便在出现争议时举证

### 5.3 关于"几十万赔偿"的担忧

**当前保护措施**：
- 责任上限条款（7.1）：最高赔偿 = 12个月用户付费
- 特殊损害免责（7.2）：排除间接损失、利润损失等
- 第三方责任切割（4.2）：上游模型问题不由你负责

**额外建议**：
1. **购买商业保险**：建议投保"软件产品责任险"或"网络安全责任险"
2. **保留证据**：记录用户同意协议的时间戳、版本号等
