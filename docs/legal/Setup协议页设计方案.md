## 一、现有 Setup 流程

```

    ↓

    ↓
```

## 三、交互逻辑

### 3.1 勾选状态

| 状态 | 勾选框 | 边框 | 按钮 |
|------|--------|------|------|
| **未勾选** | ☐ 空心 | 🔴 红色虚线 | 灰色禁用 |
| **已勾选** | ☑ 绿勾 | 无边框/灰色 | 品牌色可点击 |

### 3.2 未勾选点击按钮

**方案A（简单）**：按钮保持灰色，点击无反应

**方案B（友好）**：协议区域闪烁红色 + 滚动到协议区域

### 3.3 三个链接

```
《用户协议》  《隐私政策》  《风险告知》
     ↓             ↓            ↓
   弹窗          弹窗          弹窗
```

点击任一链接 → 弹出对应文档全文（模态框或新页面）

```
  ☑  我已阅读并同意 《用户协议》《隐私政策》《风险告知》      ← 绿色勾，边框消失
```

### CSS 参考

```css
/* 未勾选 */

  border: 2px dashed #ff4d4f;   /* 红色虚线 */
  padding: 12px 16px;
  border-radius: 6px;
}

/* 已勾选 */
.agreement-row.checked {
  border: none;
}

/* 链接 */
.agreement-row a {
  color: #1890ff;
  text-decoration: underline;
  margin: 0 4px;
}

/* 勾选图标 */
.agreement-row.checked .checkbox {
  color: #52c41a;
}
```
