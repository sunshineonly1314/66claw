## 修改方案

### Control UI (主要修改这个)
**位置**: `ui/src/ui/`
**修改文件**:
- `app.ts` - 主应用逻辑
- `app-render.ts` - 界面渲染
- `styles.css` - 全局样式
- `views/` - 各个视图组件

**构建**: `cd ui && pnpm build`

### A2UI Canvas (基本不改)
**位置**: `vendor/a2ui/` (Google 开源库) + `src/canvas-host/a2ui/index.html`
**修改建议**: 只改 `index.html` 的样式/文案,vendor/ 内容不要动
**构建**: `pnpm canvas:a2ui:bundle`
**来源**: Copyright 2025 Google LLC (Apache 2.0 License)
