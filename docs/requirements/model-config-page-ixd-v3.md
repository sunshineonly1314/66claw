# 模型配置页 — 多维度交互设计稿 v3

> **文档类型**: UI/UE 交互设计规范
> **页面路由**: `/models`
> **设计原则**: 多维度筛选 + 状态清晰 + 去 AI 味道
> **核心理念**: 文本/图片/视频是不同的模型，按能力、厂家、状态多维度管理

---

## 一、核心问题与设计思路

### 1.1 核心认知

**关键事实**:
- 文本模型 ≠ 图片模型 ≠ 视频模型（不同能力）
- 同一厂家可能有多种能力的模型（如硅基流动：文本、图片、Embedding）
- 用户需要知道：我配置了哪些能力的模型？还缺哪些能力？

### 1.2 多维度设计

**四个维度**:
1. **能力维度**: 文本 / 图片 / 视频 / Embedding（主导航）
2. **配置状态**: 已配置 / 未配置（次要筛选）
3. **厂家分类**: 国内 / 国际 / 本地（折叠区）
4. **免费属性**: 免费 / 付费（标签标识）

## 九、交互流程设计

### 9.1 首次配置流程（单能力）

```

   ↓

   ↓
3. 弹窗打开，显示"配置 DeepSeek - 文本对话"

   ↓
```

```
1. 用户在"文本对话" Tab
   ↓
2. 点击"立即配置 硅基流动"
   ↓
3. 弹窗显示提示: "此 API Key 还支持图片、Embedding"
   ↓
4. 填写 API Key → 选择文本模型 → 测试连接
   ↓
5. 保存成功 → 关闭弹窗
   ↓
6. "文本对话" Tab 已配置区显示硅基流动卡片
   ↓
7. 切换到"图片" Tab
   ↓
8. 硅基流动显示"已有 API Key，选择模型即可"

   ↓
10. "图片" Tab 已配置区显示硅基流动卡片
```

### 9.3 切换模型流程

```
1. 在已配置卡片点击"切换模型"
   ↓
2. 弹出下拉列表，显示该厂家该能力的所有可用模型
   ↓
3. 选择新模型 → 即时生效，无需重新测试
```

```typescript
  );

  // 3. 分类: 已配置 / 推荐 / 国内 / 国际 / 本地
  const categorized = categorizeProviders(filtered, userConfigs, capability);

  // 4. 渲染
  renderProviders(categorized);
};
```
