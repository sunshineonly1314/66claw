# 模型配置页 — UI/UE 交互设计稿 v2

> **文档类型**: 交互设计规范
> **页面路由**: `/models`（原 `/free-models` 升级版）
> **设计参考**: 复用 Setup 页面的卡片选择模式
> **设计原则**: 去 AI 味道、分类清晰、状态明确

---

## 一、从 Setup 页面学到的设计模式

### 1.1 Setup 页面的优秀交互模式

1. **清晰的分类折叠结构**
   ```
   🇨🇳 推荐服务 (3个大卡片，永久展开)
   🇨🇳 更多国内服务 (折叠)
   🌐 国际服务 (折叠，标注"需科学上网")
   🔧 本地模型 & 自定义 (折叠)
   ```

2. **两种卡片样式区分优先级**
   - **大卡片**: 推荐选项（如 Kimi Code），视觉突出
   - **小卡片**: 更多选项，紧凑排列

3. **状态通过选中样式表达**
   - 选中: 蓝色边框 + 蓝色勾选图标
   - 未选中: 灰色边框 + 半透明

4. **避免多余文案**
   - 不说"AI 助手"、"智能推荐"等词
   - 直接描述功能: "代码专用模型"、"免费送额度"

### 1.2 应用到模型配置页

**核心变化**:
- **状态维度**: Setup 是"选择一个"，模型配置是"管理多个（已配置 vs 未配置）"
- **分类逻辑**: 不按"文本/图片/视频"分组，而是按**提供商特性**分组
- **配置状态**: 已配置的显示在最上方，未配置的折叠在下方

## 三、分类逻辑与优先级

### 3.1 顶部固定区: 已配置模型

**展示逻辑**:
- 所有已配置的模型显示在最上方
- 不折叠，永久可见
- 按配置时间排序（最新在前）

**卡片状态**:
```
┌──────────────────────────────────────────────┐
│ ✅ 硅基流动                        [状态指示] │
│ 模型: Qwen/Qwen2.5-7B-Instruct              │
│ 特性: 免费 · Embedding · 多模型              │
│ ──────────────────────────────────────────── │
│ [重新配置]  [切换模型]  [删除]              │
└──────────────────────────────────────────────┘
```

**状态指示器**:
- ✅ 正常: 绿色点 + "正常"
- ⚠️ 异常: 黄色点 + "API 密钥失效"
- ⏸️ 暂停: 灰色点 + "额度用完"（仅免费模型）

### 3.2 分类区: 未配置模型

**分类顺序**:

| 分类 | 标识 | 折叠默认 | 说明 |
|------|------|---------|------|
| 免费模型 | 💡 | 展开 | 突出免费属性，鼓励配置 |
| 国内服务 | 🇨🇳 | 折叠 | 通义、豆包、DeepSeek 等 |
| 国际服务 | 🌐 | 折叠 | 标注"需科学上网" |
| 本地模型 | 🔧 | 折叠 | Ollama、vLLM |

**特殊处理: 硅基流动**
- 如果未配置: 在"免费模型"分类下**置顶**，添加「推荐配置」标签
- 原因: 提供免费 Embedding，但**不强制**用户配置

## 五、配置流程设计

### 5.1 配置弹窗（3 步骤，左右布局）

```
┌─────────────────────────────────────────────────────────────┐
│ 配置 [提供商名称]                                      [×] │
├─────────────────────────────────────────────────────────────┤
│ 左侧 (40%)           │ 右侧 (60%)                           │
│                      │                                       │
│ 步骤 1               │ 基本信息                              │
│ ○ 获取 API Key       │ 提供商: DeepSeek                      │
│                      │ 官网: https://platform.deepseek.com   │
│ 步骤 2 (当前)        │ 每日额度: 无限制（按量付费）           │
│ ● 填写配置           │ 能力: 对话、代码、推理                 │
│                      │                                       │
│ 步骤 3               │ ────────────────────────────────────│
│ ○ 测试连接           │                                       │
│                      │ API Key *                             │
│                      │ [●●●●●●●●●●●●●●●●] [显示]           │
│                      │                                       │
│                      │ 模型 (可选，留空则使用默认)            │
│                      │ [deepseek-chat ▼]                    │
│                      │                                       │
│                      │ [测试连接]  (未填 Key 时禁用)         │
│                      │                                       │
│                      │ ✅ 连接正常                           │
├─────────────────────────────────────────────────────────────┤
│                              [取消]  [保存]  (测试通过后启用) │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 交互流程

1. **点击"立即配置"** → 打开弹窗
2. **步骤 1 自动显示**: 提供商基本信息 + 注册链接
3. **步骤 2: 填写配置**
   - 输入 API Key
   - 可选: 选择或输入模型 ID
   - "测试连接"按钮在未填 Key 时禁用
4. **步骤 3: 测试连接**
   - 点击"测试连接" → 按钮显示 loading (⏳ 验证中...)
   - 成功: ✅ 显示成功提示，"保存"按钮启用
   - 失败: ❌ 显示错误原因（如"API Key 无效"）
5. **保存**
   - 保存成功: 自动关闭弹窗 → 页面顶部显示"配置成功"(3s 消失) → 刷新卡片列表
   - 保存失败: 自动关闭弹窗 → 页面顶部显示错误条(可手动关闭)

## 七、状态与反馈设计

### 7.1 页面加载状态

| 场景 | 展示 |
|------|------|
| 首屏加载 | 骨架屏（卡片框架） |
| 刷新列表 | 顶部显示 loading 条 |

### 7.2 操作反馈

| 操作 | 成功反馈 | 失败反馈 |
|------|---------|---------|
| 配置成功 | 自动关闭弹窗 → 顶部绿色提示(3s) → 刷新列表 | 自动关闭弹窗 → 顶部红色错误条(可关) |
| 删除成功 | 自动关闭确认框 → 顶部提示(3s) → 刷新列表 | 顶部红色错误条(可关) |
| 测试连接 | 弹窗内显示 ✅ 成功 | 弹窗内显示 ❌ 原因（不关弹窗） |

### 7.3 全局消息条

```
┌─────────────────────────────────────────────────────────────┐
│ ✅ 配置成功                                           [×]   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ ❌ 保存失败: API Key 无效，请检查后重试                [×]   │
└─────────────────────────────────────────────────────────────┘
```

**规则**:
- 成功: 绿色背景，3s 自动消失
- 错误: 红色背景，需手动关闭
- 同时只显示一条，新消息覆盖旧消息

## 十、数据结构与接口

### 10.1 已配置模型数据

```typescript
interface ConfiguredModel {
  provider: string;        // "deepseek" | "siliconflow" | "longcat" ...
  providerName: string;    // "DeepSeek" | "硅基流动" | "LongCat"
  model: string;           // "deepseek-chat"
  apiKey: string;          // 加密后的 Key
  status: "ok" | "error" | "paused";
  statusMessage?: string;  // "API Key 失效" | "额度用完"
  capabilities: string[];  // ["对话", "代码", "推理"]
  isFree: boolean;         // 是否免费模型
  freeQuota?: {
    used: number;          // 已用 tokens
    total: number;         // 总额度
    resetTime: string;     // "00:00"
  };
  configuredAt: string;    // ISO 时间戳
}
```

### 10.2 未配置模型数据

```typescript
interface AvailableProvider {
  id: string;              // "deepseek"
  name: string;            // "DeepSeek"
  category: "free" | "domestic" | "international" | "local";
  isFree: boolean;
  features: string[];      // ["性价比之王", "代码专家"]
  capabilities: string[];  // ["对话", "代码"]
  registerUrl: string;
  docsUrl: string;
  defaultModel?: string;
}
```

### 10.3 接口设计

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/models/configured` | GET | 获取已配置模型列表 |
| `/api/models/available` | GET | 获取可配置提供商列表 |
| `/api/models/test` | POST | 测试 API Key 连接 |
| `/api/models/save` | POST | 保存配置 |
| `/api/models/update` | PUT | 更新配置（切换模型、修改 Key） |
| `/api/models/delete` | DELETE | 删除配置 |
| `/api/models/free-stats` | GET | 获取免费模型统计（已省金额等） |

## 十一、关键交互细节

### 11.1 避免的 AI 味道词汇

❌ 不用: "智能推荐"、"AI 助手"、"赋能"、"大模型"

## 十二、验收标准

| 类别 | 检查项 |
|------|--------|
| 分类逻辑 | 已配置在顶部，未配置按 4 个分类折叠 |
| 免费模型 | 免费标签醒目，硅基流动在免费区置顶但不强制 |
| 配置流程 | 3 步流程清晰，测试通过后保存按钮启用 |
| 自动关闭 | 保存成功/失败后弹窗自动关闭 |
| 反馈及时 | 所有异步操作有 loading；成功/失败有明确提示 |
| 去 AI 味道 | 不出现"智能"、"赋能"等词汇 |
| 响应式 | 桌面/平板/移动端布局合理 |

## 十三、与 Setup 页面的差异对比

| 维度 | Setup 页面 | 模型配置页 |
|------|-----------|-----------|
| 选择模式 | 单选（选一个平台） | 多选管理（已配置 vs 未配置） |
| 卡片状态 | 选中 vs 未选中 | 已配置 vs 未配置 |
| 分类逻辑 | 推荐 + 国内 + 国际 + 本地 | 已配置 + 免费 + 国内 + 国际 + 本地 |
| 配置后 | 进入下一步 | 卡片移到"已配置"区 |
| 免费模型 | 无单独区域 | 单独折叠区，突出省钱效果 |
| 硅基流动 | 与其他平台平等 | 标记"推荐配置"但不强制 |
