# 模型配置页 — 双模式交互设计 (世界顶级 UI/UE)

> **设计师**: 世界顶级 UI/UE 交互体验设计师
> **设计理念**: 双模式切换 + 任务导向 + 认知负荷最小化
> **核心洞察**: 查看 ≠ 配置，两种心智模式需要完全不同的界面

---

## 一、核心设计洞察

### 1.1 用户的两种心智模式

```
模式 A: 查看当前能力状态（Overview）
  ├─ 心智: "我现在有哪些能力？缺什么？"
  ├─ 任务: 快速了解文本/图片/视频的配置现状
  └─ 交互: 信息展示为主，极少操作

模式 B: 配置新模型（Configuration）
  ├─ 心智: "我要添加图片生成能力"
  ├─ 任务: 按厂家、地区、免费/付费筛选，完成配置
  └─ 交互: 引导式流程，需要决策和输入
```

**设计原则**: 不在一个界面里混合两种模式，用视图切换来区分。

**场景**: 用户已配置硅基流动的文本模型，现在要添加图片模型

**交互**:
1. 系统检测到已有 API Key

  };

  };

### 7.2 筛选器状态

```typescript
interface FilterState {
  capability: "text" | "image" | "video" | "embedding" | null;
  region: "domestic" | "international" | "local" | "all";
  type: "free" | "paid" | "all";
}
```

### 7.3 智能检测逻辑

```typescript
const detectExistingApiKey = (provider: string, capability: string) => {
  // 检查用户是否已配置该提供商的其他能力
  const userConfigs = getUserConfigs();
  const existing = userConfigs.find(c => c.provider === provider);

  if (existing && existing.apiKeyShared) {
    return {
      hasApiKey: true,
      apiKey: existing.apiKey,
      existingCapabilities: Object.keys(existing.capabilities),
    };
  }

  return { hasApiKey: false };
};
```
