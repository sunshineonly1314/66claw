# 模型配置页 — UI/UE 交互设计稿 (IxD)

> **文档类型**: 交互设计 + 视觉规范
> **页面**: 控制台「模型配置」页（路由 `/models`，原 `/free-models` 升级版）
> **设计参考**: 复用 Setup 页面的卡片交互模式
> **设计原则**: 去 AI 味道、分类清晰、状态明确、操作直接

---

## 一、核心设计思路（基于 Setup 页面模式）

### 1.1 用户痛点与解决方案

| 用户痛点 | 现有方案问题 | 新方案价值 |
|---------|------------|----------|
| 免费模型配置分散在单独页面 | 用户不知道还有其他模型可配 | 统一入口，免费/付费/本地一目了然 |
| 不知道哪些模型支持图片/视频 | 能力信息隐藏在文档里 | 按能力维度分组展示，直观可见 |
| 硅基流动是必配项，但未突出 | 与其他平台平等展示 | 醒目标记「必需配置」+用途说明 |
| Setup 页配置后就忘了还能改 | Setup 完成后无入口 | 常驻配置入口，支持随时调整 |
| 不知道 LongCat、百灵免费 | 免费标签不够醒目 | 免费标签 + 每日额度 + 省钱统计 |

### 1.2 页面核心价值

- **统一配置入口**: 所有模型提供商（国内/国外/本地）集中管理
- **能力可视化**: 按文本/图片/视频能力分类，一眼知道哪个模型能干什么
- **免费优先策略**: 突出免费模型（LongCat、百灵），鼓励用户优先配置
- **必需项引导**: 硅基流动作为 embedding 免费提供商，明确标记「必需配置」
- **配置门槛降低**: 3 步配置流程 + 自动测试 + 即时反馈

**字段说明**:

- **重置时间**: 仅免费模型显示（如"每日00:00重置"）

```
┌─────────────────────────────────────────────────────────────┐

│                                                              │
│                                          [立即配置]          │

```

**字段说明**:
- **免费/付费标签**: 醒目展示，免费用金色 🎁，付费用蓝色 💰
- **能力标签**: 最多展示 4 个核心能力
- **特性列表**: 最多展示 3 个亮点特性
- **配置按钮**: 主操作按钮，醒目

## 七、配置弹窗设计（3 步流程）

### 7.1 弹窗布局

```
┌─────────────────────────────────────────────────────────────┐
│ ⚙️ 配置 [提供商名称]                                    [×]  │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│ ─── 步骤 1: 了解提供商 ───                                   │
│ 📊 基本信息                                                  │
│ • 每日免费额度: 50 万 tokens                                 │
│ • 重置时间: 每日 00:00 (北京时间)                            │
│ • 能力支持: 对话、代码、长文本                                │
│                                                              │
│ ─── 步骤 2: 获取 API 密钥 ───                                │
│ [打开注册页面 →]  (新窗口)                                   │
│                                                              │
│ ─── 步骤 3: 填写配置 ───                                     │
│ API 密钥 *                                                   │
│ [●●●●●●●●●●●●●●●●●●●●]  [显示]                             │
│                                                              │
│ [测试连接]  (未填写时禁用)                                    │
│                                                              │
│ ✅ 测试成功! 连接正常                                        │
│                                                              │
├─────────────────────────────────────────────────────────────┤
│                              [取消]  [保存配置]  (测试成功后启用) │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 交互流程

1. **填写 API 密钥**:
   - 未填写: 「测试连接」、「保存配置」禁用
   - 已填写: 「测试连接」启用

2. **测试连接**:
   - 点击「测试连接」→ 按钮显示 loading (⏳ 验证中...)
   - 成功: 显示 ✅ 成功提示，「保存配置」启用
   - 失败: 显示 ❌ 失败原因（如"API 密钥无效"）

3. **保存配置**:
   - 仅测试成功后可点击
   - 保存成功: **自动关闭弹窗** + 页面顶部显示成功提示(3s 自动消失)
   - 保存失败: **自动关闭弹窗** + 页面顶部显示错误条(可手动关闭)

## 八、状态与反馈设计

### 8.1 加载状态

| 场景 | 展示方式 |
|------|---------|
| 首屏加载 | 骨架屏（保持布局稳定） |
| 测试连接中 | 按钮内 loading (⏳ 验证中...) |
| 保存配置中 | 按钮内 loading (💾 保存中...) |
| 删除中 | 按钮内 loading (🗑️ 删除中...) |

### 8.2 成功反馈

| 操作 | 反馈方式 |
|------|---------|

| 错误类型 | 反馈方式 |
|---------|---------|

## 十二、无障碍设计 (Accessibility)

### 12.1 键盘导航

- Tab 键: 按顺序聚焦可交互元素
- Enter/Space: 触发按钮
- Esc: 关闭弹窗

### 12.2 屏幕阅读器

- 所有按钮有 `aria-label`
- 状态指示器有 `aria-label` (如 "状态: 正常")
- 错误提示有 `role="alert"`

### 12.3 对比度

- 所有文字与背景对比度 ≥ 4.5:1 (WCAG AA)
- 按钮禁用态与启用态有明显视觉差异

## 十三、技术实现建议

### 13.1 前端状态管理

```typescript
interface ModelConfigState {
  // 必需配置
  siliconFlowConfigured: boolean;

  // 免费模型
  freeModelsEnabled: boolean;
  freeModelsStats: {
    todaySavings: number;
    totalSavings: number;
    todayFreeRequests: number;
  };

  // 已配置模型（按能力分组）
  configuredModels: {
    text: ConfiguredModel[];
    image: ConfiguredModel[];
    video: ConfiguredModel[];
  };

  // 可配置平台（按能力分组）
  availablePlatforms: {
    text: Platform[];
    image: Platform[];
    video: Platform[];
  };

  // 弹窗状态
  configModal: {
    open: boolean;
    platform: Platform | null;
    apiKey: string;
    testing: boolean;
    testResult: { success: boolean; message: string } | null;
    saving: boolean;
  };

  // 全局反馈
  notification: {
    type: "success" | "error" | null;
    message: string;
    autoClose: boolean; // true = 3s 自动关闭
  };
}
```

### 13.2 后端接口

| 接口 | 方法 | 说明 |
|------|------|------|
