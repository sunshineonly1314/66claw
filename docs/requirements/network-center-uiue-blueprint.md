## 1. 状态条 (所有 Tab 共享)

固定在 Tab 栏上方，一行概括全局状态。可点击跳转。

```
┌──────────────────────────────────────────────────────────────────────────┐
│  {网络模式}  ·  {在线设备数}  ·  {穿透状态}                               │
└──────────────────────────────────────────────────────────────────────────┘

三种状态组合示例:

  仅本机模式 · 暂无设备 · 无远程访问
  局域网模式 · 192.168.1.100 · 3 台设备在线 · 无远程访问
  局域网模式 · 192.168.1.100 · 5 台设备在线 · Tailscale 组网已开启
  远程模式 · Tailscale · 2 台设备在线 · 公网访问已开启
  仅本机模式 · 1 台设备在线 · FRP 穿透已连接

点击交互:
  点"仅本机模式"/"局域网模式" → 跳转 Tab 2 (连接方式)
  点"N 台设备在线"             → 跳转 Tab 1 (我的设备)
  点"Tailscale/FRP"            → 跳转 Tab 2 (连接方式) 并滚动到穿透区

重启态:
  ┌──────────────────────────────────────────────────────────────────────┐
  │  正在重启...                                                         │
  └──────────────────────────────────────────────────────────────────────┘
  (黄色背景，脉冲动画，重连后自动恢复)
```

### 11.2 重连失败恢复流程

网络模式切换导致网关重启，如果 15 秒内无法重连:

```
自动重连中 (800ms → 1.6s → 3.2s → 6.4s → 12.8s → 15s)
  │
  └─ 超过 15 秒仍未连上
      │
      ▼
  ┌───────────────────────────────────────────────────────────────────┐
  │  ⚠ 重启似乎遇到了问题                                             │
  │                                                                   │
  │  网关重启后没能连上。可能的原因:                                    │
  │  · 网关还在启动中（再等一会儿试试）                                 │
  │  · 新的网络设置有问题（比如端口被占用）                             │
  │  · 密码可能没有正确保存                                            │
  │                                                                   │
  │  ┌──────────┐  ┌──────────────┐                                   │
  │  │ 再试一次 │  │ 恢复默认设置 │                                   │
  │  └──────────┘  └──────────────┘                                   │
  │                                                                   │
  │  "恢复默认设置"会把网络模式改回"只有本机"。                          │
  │  如果还是连不上，试试重启 OpenClawCN 程序。                         │
  └───────────────────────────────────────────────────────────────────┘

  "再试一次" → 重置退避计时器，从 800ms 重新开始
  "恢复默认设置" → 直接写入 loopback config 并重启
    (需要 UI 直接发 HTTP fallback，因为 WS 已断)
```

### 11.6 命令列表通配符教学

Tab3 "允许的命令列表"中，通配符 `*` 需要解释:

```
  ── 允许的命令列表 ──────────────────────────── [+ 添加命令]
  （只有在"只允许指定命令"模式下才会显示这个列表）

  ┌───────────────────────────────────────────────────────────────────┐
  │  ℹ 什么是"匹配规则"?                                              │
  │    用 * 号表示"任意字符"。比如:                                    │
  │    · node*  = 允许 node、node --version、node app.js 等           │
  │    · git*   = 允许 git pull、git push、git status 等              │
  │    · *      = 允许所有命令（不推荐）                               │
  └───────────────────────────────────────────────────────────────────┘

  ┌───────────────────────────────────────────────────────────────────┐
  │  匹配规则: node*                                                  │
  │  允许的命令举例: node --version, node app.js                      │
  │  上次使用: 2 小时前                                  ┌────┐      │
  │                                                      │删除│      │
  │                                                      └────┘      │
  └───────────────────────────────────────────────────────────────────┘

添加命令弹窗:
  ┌──────────────────────────────────────────────────┐
  │  添加允许的命令                               [X] │
  │                                                  │
  │  输入匹配规则:                                    │
  │  ┌──────────────────────────────┐                │
  │  │ python3*                     │                │
  │  └──────────────────────────────┘                │
  │                                                  │
  │  这会允许 AI 执行所有以 python3 开头的命令，       │
  │  比如 python3 script.py、python3 -m pip 等。      │
  │                                                  │
  │  常用模板:                                        │
  │  ┌──────┐ ┌──────┐ ┌────────┐ ┌──────┐         │
  │  │ node*│ │ git* │ │python3*│ │ npm* │         │
```
