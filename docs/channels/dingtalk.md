# 钉钉机器人接入指南

> 手把手教你创建钉钉企业内部机器人，对接 Clawdbot AI 助手

---

## 前置条件

在开始之前，请确认你满足以下条件：

| 条件 | 说明 | 必需 |
|------|------|:----:|
| 管理员权限 | 钉钉企业管理员或开发者权限 | 是 |
| 企业认证 | 企业已完成钉钉认证 | 是 |
| 钉钉登录 | 电脑已登录钉钉账号 | 是 |
| 已安装 Clawdbot | 如未安装请先参考 [安装指南](/install) | 是 |

> **注意**：普通员工账号无法创建应用，必须使用管理员账号。没有企业账号？可以免费创建一个钉钉团队：打开钉钉 App → 工作台 → 创建团队

---

## 为什么选择 Stream 模式？

本指南使用 **Stream 模式**（长连接），这是目前最推荐的接入方式：

| 对比项 | Stream 模式 | HTTP 模式 |
|-------|:-----------:|:---------:|
| 需要服务器 | 不需要 | 需要 |
| 需要公网 IP | 不需要 | 需要 |
| 需要域名和 HTTPS | 不需要 | 需要 |
| 配置难度 | 简单 | 复杂 |
| AI Card 流式响应 | 支持 | 不支持 |
| **推荐度** | 强烈推荐 | 不推荐 |

**Stream 模式的优势：**
- 在自己电脑上运行 Clawdbot 就能收到消息
- 无需购买服务器或配置网络
- 支持打字机效果的流式响应

## 快速设置（约 10 分钟）

### 第一步：登录钉钉开放平台

1. 打开浏览器，访问 **[钉钉开放平台](https://open-dev.dingtalk.com)**

2. 点击页面右上角的 **「登录」** 按钮，页面会显示二维码

3. 打开手机钉钉 App → 点击右上角 **「+」** → **「扫一扫」**

4. 扫描电脑屏幕上的二维码，手机上点击 **「确认登录」**

5. 如果账号绑定了多个企业，选择你要创建机器人的企业，点击 **「确定」**

登录成功后会进入「开发者后台」首页。

> **遇到问题？** 如果提示没有权限，请联系企业钉钉管理员为你添加「开发者」权限

---

### 第二步：创建企业内部应用

1. 在页面 **左侧菜单栏** 找到并点击 **「应用开发」**

2. 展开后点击 **「企业内部开发」**

3. 在右侧页面点击 **「创建应用」** 按钮

4. 填写应用信息：

   | 填写项 | 说明 | 示例 |
   |-------|------|------|
   | 应用名称 | 给用户看的名字，建议简洁好记 | `AI 助手` |
   | 应用描述 | 简单说明用途 | `智能问答助手` |
   | 应用图标 | 机器人头像（可选） | 任意图片 |

5. 点击 **「确定创建」**，创建成功后会自动跳转到应用详情页

---

### 第三步：获取 AppKey 和 AppSecret（重要）

这是接入机器人的关键凭证，相当于「账号」和「密码」。

1. 在应用详情页，点击左侧菜单 **「凭证与基础信息」**（在「基础信息」分组下）

2. 在右侧页面找到应用凭证：

   | 名称 | 页面显示 | 格式示例 |
   |------|---------|---------|
   | **AppKey** | Client ID（即 AppKey） | `dingabc123def456` |
   | **AppSecret** | Client Secret（即 AppSecret） | 需点击查看 |

3. **复制 AppKey**：点击 Client ID 右边的 **「复制」** 图标，粘贴到记事本保存

4. **复制 AppSecret**：
   - 点击 Client Secret 右边的 **「查看」** 按钮
   - 可能需要手机钉钉扫码验证身份
   - 验证通过后显示完整的 Secret
   - **立即复制并保存！**

> **安全提醒**：
> - AppSecret 关闭页面后就看不到了，请立即复制保存
> - 如果忘记了，只能点「重置」生成新的
> - 重置后旧 Secret 会失效，需要重新配置

---

### 第四步：添加「机器人」能力

1. 在应用详情页，点击左侧菜单 **「添加应用能力」**

2. 在右侧的能力卡片中找到 **「机器人」**

3. 点击卡片上的 **「添加」** 按钮

添加成功后，左侧菜单会多出一个「机器人」选项。

---

### 第五步：配置机器人（关键步骤）

这是最关键的一步，**必须选择 Stream 模式**！

1. 点击左侧菜单新出现的 **「机器人」** 选项

2. **选择消息接收模式**：

   找到「消息接收模式」选项：
   
   | 选项 | 是否选择 | 原因 |
   |------|:-------:|------|
   | HTTP 模式 | 否 | 需要公网 IP 和服务器 |
   | **Stream 模式** | **是** | 无需服务器，本地即可运行 |

   > **必须选择「Stream 模式」！** 否则需要购买服务器配置公网访问

3. 填写机器人信息：

   | 填写项 | 说明 | 示例 |
   |-------|------|------|
   | 机器人名称 | 钉钉用户看到的名字 | `AI 助手` |
   | 机器人描述 | 用户搜索时看到的简介 | `智能问答机器人` |
   | 机器人头像 | 可选 | 上传图片 |

4. 点击页面底部的 **「发布」** 按钮保存配置

---

### 第六步：添加权限（推荐）

添加权限可以让机器人功能更完善：

1. 点击左侧菜单 **「权限管理」**

2. 在页面顶部搜索框搜索并添加以下权限：

   | 权限名称 | 用途 | 必需 |
   |---------|------|:----:|
   | `机器人发送消息` | 让机器人能回复消息 | 是 |
   | `通讯录个人信息读权限` | 获取用户姓名 | 否 |
   | `群成员信息读权限` | 获取群成员列表 | 否 |

3. 勾选需要的权限后，点击 **「批量申请」** 按钮

> 企业内部应用的权限会自动通过，无需等待审核

---

### 第七步：发布应用

只有发布后的应用，员工才能使用。

1. 点击左侧菜单 **「版本管理与发布」**

2. 点击 **「创建新版本」** 按钮

3. 填写版本信息：

   | 填写项 | 内容 |
   |-------|------|
   | 版本号 | `1.0.0` |
   | 版本描述 | `首次发布`（随便写） |

4. 点击 **「保存」**，然后点击 **「发布」**

企业内部应用一般秒过审核，稍等几秒就发布成功了。

---

### 第八步：配置 Clawdbot

现在回到你的电脑，配置 Clawdbot 连接钉钉。

#### 方式一：通过 Web 界面配置（推荐）

1. 打开浏览器访问 `http://localhost:18789/setup`（或你的 Gateway 地址）

2. 在「渠道配置」页面选择「钉钉」

3. 填入之前保存的 AppKey 和 AppSecret

4. 点击「验证并保存」，系统会自动验证凭证是否正确

#### 方式二：手动编辑配置文件

**Windows 用户**：

1. 按 `Win+R`，输入 `%USERPROFILE%\.clawdbot\` 按回车

2. 找到或创建 `config.yaml` 文件，用记事本打开

3. 添加以下内容：

```yaml
channels:
  dingtalk:
    enabled: true
    app:
      appKey: "dingabc123def456"    # 替换为你的 AppKey
      appSecret: "你的AppSecret"     # 替换为你的 AppSecret
```

4. 保存文件（Ctrl+S）

**Mac/Linux 用户**：

```bash
# 编辑配置文件
nano ~/.clawdbot/config.yaml

# 添加上面的配置内容后
# 按 Ctrl+O 保存，Ctrl+X 退出
```

---

### 第九步：启动并测试

#### 启动 Clawdbot

**Windows**：双击桌面上的 Clawdbot 图标，或在开始菜单搜索 `Clawdbot`

**Mac/Linux**：

```bash
clawdbot gateway run
```

#### 测试机器人

1. 打开钉钉 App（手机或电脑）

2. 点击顶部 **搜索框**

3. 输入机器人名称（如「AI 助手」）

4. 点击搜索结果中的机器人进入对话

5. 发送一条消息，如 `你好`

如果收到回复，配置成功！

- 和机器人私聊

## 常见问题

### Q: 机器人不响应消息？

**排查步骤**：

1. **检查应用是否已发布**
   - 进入「版本管理与发布」确认状态为「已发布」

2. **检查是否选择了 Stream 模式**
   - 进入「机器人」配置页面确认消息接收模式

3. **检查 Clawdbot Gateway 是否运行**

   ```bash
   clawdbot channels status --probe
   ```

4. **查看日志排查问题**

   ```bash
   clawdbot logs --follow
   ```

### Q: 提示「AppKey 不存在或无效」？

**原因**：AppKey 复制不完整，或应用未发布

**解决**：
1. 检查 AppKey 是否复制完整（不要有多余空格）
2. 确认应用已在「版本管理与发布」中发布上线

### Q: 提示「AppSecret 不正确」？

**原因**：AppSecret 错误、过期或复制不完整

**解决**：
1. 回到开放平台「凭证与基础信息」页面
2. 点击 AppSecret 的「重置」按钮
3. 重新生成并复制新的 Secret
4. 更新 Clawdbot 配置

### Q: 找不到「应用开发」菜单？

**原因**：账号没有开发者权限

**解决**：联系企业钉钉管理员，为你添加开发者权限

### Q: 发布应用时提示「没有权限」？

**原因**：只有企业管理员才能发布应用

**解决**：
- 联系管理员帮你发布
- 或请管理员给你「应用发布」权限

## 完整配置参考

```yaml
channels:
  dingtalk:
    # ========== 基础配置 ==========
    enabled: true                     # 是否启用钉钉渠道
    
    # ========== 应用凭证（必填）==========
    app:
      appKey: "dingabc123def456"      # AppKey (Client ID)
      appSecret: "your_secret"        # AppSecret (Client Secret)
      robotCode: "xxx"                # 机器人 RobotCode (可选)
      signSecret: "xxx"               # 消息加签密钥 (可选)
      debug: false                    # 调试模式 (可选)
    
    # ========== Stream 模式配置 ==========
    stream:
      enableAICard: true              # 启用 AI Card 流式响应（打字机效果）
      sessionTimeout: 1800000         # 会话超时 (ms)，默认 30 分钟
      enableMediaUpload: true         # 启用图片自动上传
    
    # ========== 访问控制 ==========
    dmPolicy: "pairing"               # 私聊策略: open / pairing / allowlist
    allowFrom:                        # 允许的用户 ID 列表（allowlist 模式）
      - "user123"
    
    groupPolicy: "allowlist"          # 群聊策略: open / allowlist
    groups:                           # 各群单独配置
      "chatId123":
        requireMention: true          # 是否需要 @机器人 才响应
        allowFrom:                    # 此群允许的发送者
          - "user1"
```

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|-----|------|:----:|--------|------|
| `enabled` | boolean | 否 | `true` | 是否启用钉钉渠道 |
| `app.appKey` | string | **是** | - | 应用 AppKey (Client ID) |
| `app.appSecret` | string | **是** | - | 应用 AppSecret (Client Secret) |
| `app.robotCode` | string | 否 | - | 机器人 RobotCode |
| `app.signSecret` | string | 否 | - | 消息加签密钥 |
| `dmPolicy` | string | 否 | `"pairing"` | 私聊策略 |
| `groupPolicy` | string | 否 | `"allowlist"` | 群聊策略 |
| `stream.enableAICard` | boolean | 否 | `true` | 启用 AI Card 流式响应 |
| `stream.sessionTimeout` | number | 否 | `1800000` | 会话超时时间（30分钟） |

### 私聊策略 (dmPolicy)

| 值 | 说明 |
|:--|------|
| `open` | 任何人都可以私聊机器人 |
| `pairing` | 需要配对审批后才能使用（推荐） |
| `allowlist` | 只有 `allowFrom` 列表中的用户可以使用 |

### 群聊策略 (groupPolicy)

| 值 | 说明 |
|:--|------|
| `open` | 所有群都可以 @机器人 使用 |
| `allowlist` | 只有配置的群可以使用 |

## 验证连接

启动网关后，使用以下命令验证连接状态：

```bash
clawdbot channels status --probe
```

期望输出：

```
钉钉 (dingtalk)
├─ 状态: 已连接
├─ 模式: Stream
└─ 应用: dingabc123...
```
