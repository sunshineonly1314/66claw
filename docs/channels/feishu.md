# 飞书 (Feishu/Lark)

飞书渠道支持通过企业自建应用接收和发送消息，并深度集成飞书生态（文档、知识库、多维表格）。

## 为什么选择飞书？

| 优势 | 说明 |
|-----|------|
| **无需公网 IP** | 使用 WebSocket 长连接，内网即可运行 |
| **图片/文件理解** | 发送图片、文件、语音、视频给机器人，AI 自动识别和理解 |
| **Markdown 支持最好** | 代码高亮、表格、卡片消息 |
| **生态集成** | AI 可直接操作文档、知识库、多维表格 |
| **配置简单** | 10 分钟即可完成基础配置 |

---

## 前置条件

在开始之前，请确认你拥有以下权限和条件：

| 条件 | 说明 | 必需 |
|------|------|------|
| 管理员权限 | 飞书企业管理员或应用管理员权限 | ✅ |
| 开放平台 | 企业已开通飞书开放平台功能 | ✅ |
| 飞书登录 | 电脑已登录飞书账号 | ✅ |

> ⚠️ **注意**：如果提示"无权限访问"，需要联系企业管理员开通开发者权限。

## 1. 登录飞书开放平台

### 步骤 1：访问开放平台

打开浏览器，访问：

```
https://open.feishu.cn/app
```

### 步骤 2：扫码登录

1. 点击页面右上角的「**登录**」按钮
2. 页面显示二维码
3. 打开手机飞书 App → 点击右上角「**+**」→「**扫一扫**」
4. 扫描电脑屏幕上的二维码

### 步骤 3：进入开发者后台

登录成功后，进入「**开发者后台**」首页，显示你的应用列表。

> 💡 **提示**：如果提示"无权限访问"，说明你不是企业管理员，需要联系管理员给你开通开发者权限。

## 2. 创建企业自建应用

### 步骤 1：点击创建按钮

在开发者后台首页，找到并点击蓝色的「**创建企业自建应用**」按钮。

### 步骤 2：填写应用信息

弹出创建表单，填写以下内容：

| 字段 | 示例值 | 说明 |
|------|--------|------|
| 应用名称 | `AI 助手` | 给用户看的名字，建议简洁好记 |
| 应用描述 | `智能问答机器人` | 简单说明用途 |
| 应用图标 | 可选 | 机器人的头像 |

填写完成后，点击「**创建**」按钮。

> ✅ **创建成功！** 会自动跳转到应用详情页。

## 3. 添加「机器人」能力

### 步骤 1：找到应用能力入口

1. 在应用详情页，看**左侧菜单栏**
2. 找到「**添加应用能力**」并点击

### 步骤 2：添加机器人能力

1. 右侧显示各种能力卡片（网页、小程序、机器人等）
2. 找到「**机器人**」卡片（有个机器人图标）
3. 点击卡片上的「**+ 添加**」按钮

> ✅ 添加成功后，左侧菜单会多出一个「**机器人**」选项。

## 4. 获取 App ID 和 App Secret

> ⚠️ **非常重要！请仔细阅读本节**
>
> 这是接入机器人的关键凭证，相当于「账号」和「密码」。

### 步骤 1：进入凭证页面

看左侧菜单，找到「**凭证与基础信息**」并点击

### 步骤 2：复制 App ID

在页面中找到 **App ID**（以 `cli_` 开头的字符串）：

| 字段 | 格式示例 | 操作 |
|------|---------|------|
| App ID | `cli_a1b2c3d4e5f6` | 点击右边的复制图标 |

### 步骤 3：复制 App Secret

| 字段 | 操作 |
|------|------|
| App Secret | 点击「**显示**」按钮后立即复制 |

> 🔐 **安全提示**：
> - App Secret 是应用的安全密钥，请妥善保管
> - 不要告诉别人或发到群里
> - 如果泄露，可以在开放平台重置

---

## 5. 获取 Encrypt Key 和 Verification Token

### 步骤 1：进入事件配置

1. 左侧菜单找到「**开发配置**」分组
2. 点击展开后，找到「**事件与回调**」并点击

### 步骤 2：获取加密密钥

找到「**加密策略**」区域：

| 字段 | 操作 |
|------|------|
| Encrypt Key | 如果是第一次创建，点击「**刷新**」按钮生成，然后点击「**显示**」查看并复制 |
| Verification Token | 点击「**显示**」按钮，复制完整内容 |

---

## 6. 配置事件订阅 - 启用长连接

> ⭐ **这是最关键的一步！**

### 步骤 1：选择事件配置方式

在「**事件与回调**」页面，找到「**事件配置方式**」：

| 选项 | 说明 | 推荐 |
|------|------|------|
| 将事件发送至开发者服务器 | 需要公网服务器 | ❌ 不要选 |
| **使用长连接接收事件** | 无需服务器 | ✅ **必须选这个** |

### 为什么必须选长连接模式？

| 模式 | 是否需要服务器 | 是否需要公网 IP | 配置难度 |
|------|--------------|----------------|---------|
| 发送至开发者服务器 | ✅ 需要 | ✅ 需要 | 复杂 |
| **使用长连接接收事件** | ❌ 不需要 | ❌ 不需要 | **简单** |

**长连接模式的优势：**
- ✅ 不需要购买服务器
- ✅ 不需要有公网 IP
- ✅ 不需要配置域名和 HTTPS
- ✅ 在自己电脑上运行 OpenClawCN 就能收到消息

### 步骤 2：保存配置

选择好后，点击「**保存**」按钮。

---

## 7. 添加「接收消息」事件

> ⚠️ **如果不做这一步，机器人收不到任何消息！**

### 步骤 1：添加事件

1. 还是在「**事件与回调**」页面
2. 往下滚动，点击蓝色的「**添加事件**」按钮

### 步骤 2：搜索并选择事件

1. 在弹出的窗口中，搜索框输入：`接收消息`
2. 找到「**接收消息 im.message.receive_v1**」
3. 点击右边的复选框 **打勾** ✅
4. 点击「**确认添加**」按钮

### 步骤 3：确认添加成功

回到事件列表，确认已经添加成功。

> ⚠️ **非常重要**：这是最容易被忘记的一步！

---

## 8. 添加权限

> ⚠️ **如果没有这些权限，机器人能收到消息但回复不了！**

### 步骤 1：进入权限管理

点击左侧菜单的「**权限管理**」

### 步骤 2：开通必需权限

在搜索框中依次搜索并开通：

| 序号 | 搜索关键词 | 权限名称 | 用途 | 必需 |
|------|-----------|---------|------|------|
| 1 | `im:message` | 获取与发送单聊、群组消息 | 基础消息能力 | ✅ |
| 2 | `im:message:send_as_bot` | 以应用的身份发消息 | 机器人发送消息 | ✅ |
| 3 | `im:resource` | 获取与上传图片或文件资源 | 接收和发送图片/文件 | ✅ |
| 4 | `im:message.group_at_msg` | 接收群聊中@机器人消息事件 | 群聊@功能 | 群聊必选 |

**操作步骤**：
1. 在搜索框输入权限关键词
2. 找到对应权限
3. 点击右边的「**开通权限**」按钮

> ⚠️ **前三个权限是必须的！** 缺少 `im:resource` 会导致机器人无法接收和发送图片/文件。

## 10. 配置 OpenClawCN

现在回到你的电脑，配置 OpenClawCN 连接飞书。

### Windows 用户

1. 打开 OpenClawCN 安装目录（通常是 `C:\Users\你的用户名\.openclawcn\`）
2. 找到或创建 `config.yaml` 文件（用记事本打开）
3. 添加以下内容：

```yaml
channels:
  feishu:
    enabled: true
    appId: "cli_xxxxx"           # 替换为你的 App ID
    appSecret: "xxxxx"           # 替换为你的 App Secret
```

4. 保存文件

### Mac/Linux 用户

1. 打开终端
2. 编辑配置文件：

```bash
nano ~/.openclawcn/config.yaml
```

3. 添加上面的配置内容，然后按 `Ctrl+O` 保存，`Ctrl+X` 退出

## 常见问题

### 机器人收不到消息

**检查清单**：
- [ ] 是否添加了 `im.message.receive_v1` 事件（第 7 步）
- [ ] 是否选择了「**使用长连接接收事件**」（第 6 步）
- [ ] 应用是否已发布（第 9 步）
- [ ] 所有权限状态是否为"已开通"
- [ ] OpenClawCN 是否在运行

### 找不到「添加应用能力」在哪？

**解决**：
1. 在应用详情页的左侧菜单栏往下滚动
2. 如果还是找不到，可能是飞书改版了
3. 试试在菜单里找「**应用能力**」或「**机器人**」相关的选项

### 提示"App ID 不存在"？

**原因**：App ID 复制不完整或格式错误。

**解决**：
1. 检查 App ID 是否以 `cli_` 开头
2. 确认没有多复制空格
3. 重新到开放平台复制

### 机器人能收到消息，但不回复？

**原因**：90% 是因为权限没开！

**解决**：回到第 8 步，确认 `im:message` 和 `im:message:send_as_bot` 这两个权限都已开通

### 群聊@机器人没反应？

**排查**：
1. 检查是否开通了 `im:message.group_at_msg` 权限
2. 确认机器人已被邀请进群（在群设置里添加机器人）

### 发送消息报错

检查 `以应用的身份发消息` 权限是否已开通

## 完整配置参数

```yaml
channels:
  feishu:
    # ========== 基础配置 ==========
    enabled: true                    # 是否启用
    appId: "cli_xxxxx"               # App ID (必填)
    appSecret: "xxx"                 # App Secret (必填)
    
    # ========== 连接配置 ==========
    domain: "feishu"                 # feishu (国内) / lark (国际版)
    connectionMode: "websocket"      # websocket (推荐) / webhook
    
    # ========== 私聊配置 ==========
    dmPolicy: "pairing"              # open / pairing / allowlist
    allowFrom:                       # 允许的用户 ID 列表
      - "ou_xxx"
    
    # ========== 群聊配置 ==========
    groupPolicy: "allowlist"         # open / allowlist / disabled
    requireMention: true             # 群聊是否需要 @机器人
    groups:                          # 各群单独配置
      "oc_xxx":
        requireMention: false
    
    # ========== 消息配置 ==========
    renderMode: "auto"               # auto / raw / card
    mediaMaxMb: 30                   # 收发媒体最大大小 (MB)
    
    # ========== 工具配置 ==========
    tools:
      doc: true                      # 文档工具
      wiki: true                     # 知识库工具
      drive: true                    # 云空间工具
      scopes: true                   # 权限诊断
```

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `enabled` | boolean | `true` | 是否启用飞书渠道 |
| `appId` | string | - | 飞书应用 App ID (必填) |
| `appSecret` | string | - | 飞书应用 App Secret (必填) |
| `domain` | string | `"feishu"` | `feishu` 国内版，`lark` 国际版 |
| `connectionMode` | string | `"websocket"` | 连接模式 |
| `dmPolicy` | string | `"pairing"` | 私聊策略 |
| `groupPolicy` | string | `"allowlist"` | 群聊策略 |
| `requireMention` | boolean | `true` | 群聊是否需要 @机器人 |
| `renderMode` | string | `"auto"` | 消息渲染模式 |

### 私聊策略 (dmPolicy)

| 值 | 说明 |
|---|------|
| `open` | 任何人都可以私聊机器人 (需要 `allowFrom` 包含 `*`) |
| `pairing` | 需要配对审批后才能使用 (推荐) |
| `allowlist` | 只有 `allowFrom` 列表中的用户可以使用 |

### 群聊策略 (groupPolicy)

| 值 | 说明 |
|---|------|
| `open` | 所有群都可以 @机器人 使用 |
| `allowlist` | 只有配置的群可以使用 |
| `disabled` | 禁用群聊功能 |

### 渲染模式 (renderMode)

| 值 | 说明 |
|---|------|
| `auto` | 自动检测：有代码块或表格时用卡片，否则纯文本 |
| `raw` | 始终纯文本 |
| `card` | 始终卡片 (支持语法高亮、表格) |

## 飞书工具 (高级功能)

配置飞书后，AI 将自动获得以下工具能力：

### 文档工具 (feishu_doc)

让 AI 能够读写飞书文档：

```
用户: 帮我读取这个文档 https://feishu.cn/docx/abc123
用户: 创建一个会议纪要文档，内容是...
用户: 把这段内容追加到文档末尾
```

**需要额外权限**:
- `docx:document:readonly` - 只读
- `docx:document` - 读写
- `docx:document.block:convert` - Markdown 转换

### 知识库工具 (feishu_wiki)

让 AI 能够浏览和管理知识库：

```
用户: 列出我们的知识库空间
用户: 在产品文档空间创建一个新页面
用户: 帮我查找关于 XXX 的文档
```

**需要额外权限**:
- `wiki:wiki:readonly` - 只读
- `wiki:wiki` - 读写

> ⚠️ **重要**: 权限通过后，还需要将机器人添加到知识库空间成员！
>
> 操作：打开知识库 → 设置 → 成员 → 添加机器人

### 多维表格工具 (feishu_bitable)

让 AI 能够读写多维表格：

```
用户: 查看这个表格的数据 https://feishu.cn/base/xxx
用户: 在表格里添加一条记录
用户: 更新第 3 行的状态为"已完成"
```

**需要额外权限**:
- `bitable:app:readonly` - 只读
- `bitable:app` - 读写

> ⚠️ **重要**: 机器人只能访问被分享给它的多维表格！

### 云空间工具 (feishu_drive)

让 AI 能够管理云空间文件：

```
用户: 列出我的文件
用户: 创建一个新文件夹叫"项目资料"
用户: 把这个文件移动到另一个文件夹
```

**需要额外权限**:
- `drive:drive:readonly` - 只读
- `drive:drive` - 读写

> ⚠️ **重要**: 机器人没有"我的空间"，只能访问被分享的文件夹！

## 更多常见问题

### 如何清理历史 / 开始新对话

在聊天中发送 `/new` 命令即可清空对话历史，开始全新对话。

### 消息为什么不是流式输出？

飞书 API 有请求频率限制，流式更新容易触发限流。当前采用完整回复后一次性发送。

### 国际版 Lark 如何配置？

如果你使用的是海外版飞书（Lark），需要修改配置：

```yaml
channels:
  feishu:
    domain: "lark"  # 改成 lark
    appId: "cli_xxxxx"
    appSecret: "xxxxx"
```

### 如何获取我的 Open ID？

配置 `allowFrom` 白名单时需要用户的 Open ID（格式如 `ou_xxxxx`）。

**最简单的方法**：
1. 先不配置 `allowFrom`（或设置 `dmPolicy: "open"` 和 `allowFrom: ["*"]`）
2. 启动 OpenClawCN
3. 用飞书给机器人发一条消息
4. 在 OpenClawCN 日志中找到 `from=ou_xxxx...`，这就是你的 Open ID

### 如何限制谁可以使用机器人？

使用 `allowFrom` 配置白名单：

```yaml
channels:
  feishu:
    appId: "cli_xxxxx"
    appSecret: "xxxxx"
    dmPolicy: "allowlist"        # 只允许白名单用户
    allowFrom:
      - "ou_xxxxx"               # 用户1的 Open ID
      - "ou_yyyyy"               # 用户2的 Open ID
```

> 💡 **测试技巧**：先设置 `dmPolicy: "open"` 和 `allowFrom: ["*"]` 让所有人可用，正式上线前再改回 `allowlist`。

### 知识库/文档工具返回空结果？

光有 API 权限还不够！还需要把机器人添加为知识库/文档的成员：

1. 打开知识库空间或文档
2. 点击 **分享** 或 **设置 → 成员管理**
3. 搜索并添加你的机器人

### 图片/文件收发失败？

1. 检查 `im:resource`（获取与上传图片或文件资源）权限是否已开通
2. 文件大小不能超过 30MB
3. 如果发图片给机器人后没反应，确认权限已审核通过（权限状态为"已开通"而非"审核中"）

### 发送图片/文件/语音给机器人，但 AI 没识别到？

**说明**：机器人支持接收以下类型的消息，AI 会自动理解内容：

| 消息类型 | 说明 |
|---------|------|
| 图片 | AI 自动识别图片内容（需要配置视觉模型） |
| 文件 | PDF、Word 等文档 |
| 语音 | 语音消息 |
| 视频 | 视频消息 |
| 表情包 | 表情贴纸 |
| 富文本 | 包含内联图片的富文本消息 |

**排查**：
1. 确认 `im:resource` 权限已开通
2. 查看 OpenClawCN 日志是否有 `[feishu] 下载图片` 或 `[feishu] 下载媒体失败` 信息
3. 如果日志显示下载成功但 AI 没理解，可能需要配置支持视觉的模型
