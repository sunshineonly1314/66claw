# Clawdbot Windows 安全模式详解

本文档详细说明 Clawdbot 在 Windows 上的三种安全模式，帮助用户了解**在每种模式下能做什么、不能做什么**。

---

## 重要提醒（请务必阅读）

### 1. 审批通知在哪里？

当 AI 需要执行需要你确认的操作时，**通知会出现在 Web 控制台**：

```
http://localhost:18789
```

**关键**：
- 你必须**保持浏览器打开并连接到这个地址**才能收到通知
- 如果你关闭了浏览器，AI 的操作请求会在 **2 分钟后自动被拒绝**
- 建议安装后**一直保持这个页面打开**（可以最小化）

### 2. 什么是"已信任的操作"（白名单）？

简单说就是：**AI 可以直接执行的操作，不需要问你**。

比如打开记事本、打开浏览器、运行 Python 脚本，这些都是"已信任的操作"，AI 可以直接做。

但如果 AI 想删除文件、安装软件、修改系统设置，这些**不在信任列表里**，就需要问你。

### 3. 如何添加信任的操作？

当 AI 请求一个新操作时，你会看到三个选项：

| 选项 | 意思 | 效果 |
|-----|------|------|
| **仅这一次** | 只允许这一次 | 下次还会问你 |
| **以后都信任** | 加入信任列表 | 以后不再询问 |
| **拒绝** | 不允许 | AI 无法执行这个操作 |

> **小白建议**：如果你确定这个操作是安全的（比如安装一个 Python 库），可以选择"以后都信任"，这样下次就不用再确认了。

## 核心问题解答

### 问：我能用 Clawdbot 操作 Windows 电脑吗？

**答：可以，但取决于安全模式。**

| 安全模式 | 能否操作 Windows | 说明 |
|---------|-----------------|------|
| 🛡️ 完全保护 | ❌ 不能 | 所有操作都在隔离环境中，不会影响你的电脑 |
| 🔒 智能保护 | ⚠️ 有限 | 只能操作你指定的文件夹，执行信任列表中的操作 |
| ⚡ 关闭保护 | ✅ 完全可以 | 拥有完整系统权限，可以执行任何操作 |

### 问：是否有可视化界面？

**答：有！所有模式都有 Web 控制台。**

安装完成后，打开浏览器访问 `http://localhost:18789`：

- **对话界面**：直接和 AI 对话，输入一句话指令
- **配置向导**：修改设置、切换安全模式
- **操作审批**：当 AI 需要执行敏感操作时，这里会弹出请求

### 问：能否用"一句话指令"让 AI 帮我干活？

**答：可以！这正是 Clawdbot 的设计目标。**

示例：
- "帮我打开浏览器搜索今天的天气"
- "把桌面上的图片整理到一个文件夹"
- "帮我写一个 Python 脚本处理 Excel"

**但能做到什么程度，取决于安全模式。** 请继续阅读下文。

## 三种安全模式详解

### 🛡️ 完全保护模式

> **适合：有重要文件、共用电脑、担心 AI 误操作的用户**

#### 能做什么

| 能力 | 是否可用 | 说明 |
|-----|---------|------|
| 🌐 网页浏览 | ✅ 可以 | 使用独立浏览器，不访问你的登录状态 |
| 💬 AI 对话 | ✅ 可以 | 正常问答、写作、翻译、编程辅助 |
| 🔍 网络搜索 | ✅ 可以 | 搜索信息、查询资料 |
| 🎨 生成图片 | ✅ 可以 | 调用 AI 绘图接口 |
| 📊 数据分析 | ⚠️ 有限 | 只能分析你上传的文件，不能访问本地文件 |

#### 不能做什么

| 能力 | 是否可用 | 原因 |
|-----|---------|------|
| 📁 读取本地文件 | ❌ 不能 | 隔离环境无法访问你的文件系统 |
| 📝 写入本地文件 | ❌ 不能 | 同上 |
| ⚙️ 执行系统命令 | ❌ 不能 | 命令执行被禁用（`security: deny`） |
| 🔧 安装软件 | ❌ 不能 | 无系统权限 |
| 📂 整理文件夹 | ❌ 不能 | 无法访问本地目录 |

#### 代码验证

```yaml
# src/gateway/setup-wizard.ts 中的配置
tools:
  exec:
    security: deny        # 拒绝所有命令执行
```

### 🔒 智能保护模式（推荐）

> **适合：日常工作电脑、希望平衡安全与功能的用户**

这是**默认推荐**的模式，兼顾安全性和实用性。

#### 能做什么

| 能力 | 是否可用 | 说明 |
|-----|---------|------|
| 🌐 网页浏览 | ✅ 可以 | 使用独立浏览器配置文件 |
| 💬 AI 对话 | ✅ 可以 | 正常问答、写作、翻译、编程辅助 |
| 🔍 网络搜索 | ✅ 可以 | 搜索信息、查询资料 |
| 🎨 生成图片 | ✅ 可以 | 调用 AI 绘图接口 |
| 📁 读取指定文件夹 | ✅ 可以 | 只能访问你配置的工作目录 |
| 📝 写入指定文件夹 | ✅ 可以 | 同上 |

#### 需要你确认的操作

当 AI 想执行**不在上面列表**中的操作时，Web 控制台会弹出通知：

```
┌─────────────────────────────────────────────────┐
│  🔔 AI 请求执行操作                              │
│                                                  │
│  操作：pip install pandas                        │
│  位置：C:\Users\你\Documents\project             │
│                                                  │
│  [仅这一次]  [以后都信任]  [拒绝]                │
│                                                  │
│  ⏱️ 将在 2 分钟后自动拒绝                        │
└─────────────────────────────────────────────────┘
```

**三个选项的区别**：

| 选项 | 效果 | 适用场景 |
|-----|------|---------|
| **仅这一次** | 只允许这一次，下次还会问 | 不确定是否安全时 |
| **以后都信任** | 加入信任列表，以后不再询问 | 确定是安全操作时 |
| **拒绝** | 不执行，AI 会收到拒绝通知 | 觉得不安全时 |

**重要**：
- 超时时间是 **2 分钟**（120 秒）
- 如果你不操作，2 分钟后会**自动拒绝**
- 你必须**打开浏览器**才能看到这个通知

### ⚡ 关闭保护模式

> **适合：独立设备、技术高手、需要完整功能的用户**

⚠️ **警告**：此模式有风险！AI 可能因误操作或恶意提示词注入造成数据丢失。

#### 能做什么

| 能力 | 是否可用 | 说明 |
|-----|---------|------|
| 🌐 网页浏览 | ✅ 可以 | 可以使用你的浏览器登录状态 |
| 💬 AI 对话 | ✅ 可以 | 完全功能 |
| 📁 读取任意文件 | ✅ 可以 | 完整文件系统访问 |
| 📝 写入任意文件 | ✅ 可以 | 完整文件系统访问 |
| 🗑️ 删除文件 | ✅ 可以 | **危险！不会询问** |
| ⚙️ 执行任意命令 | ✅ 可以 | **不需要确认，直接执行** |
| 🔧 安装软件 | ✅ 可以 | 拥有系统权限 |
| 📂 管理系统 | ✅ 可以 | 完整权限 |

#### 风险提示

1. **AI 可能误删文件**：执行 `rm -rf` 类命令时不会询问
2. **恶意提示词注入**：打开的文档可能包含诱导 AI 执行危险操作的指令
3. **无法撤销**：危险操作执行后无法回退

#### 适用场景

- 专门用于 AI 的独立电脑/虚拟机
- 需要自动化大量文件操作
- 技术人员了解风险并能处理问题

## 如何切换安全模式

### 方法 1：Web 控制台（推荐）

1. 打开 `http://localhost:18789/setup`
2. 点击"安全设置"
3. 选择新的模式
4. 点击保存

### 方法 2：修改配置文件

编辑 `C:\Users\你的用户名\.clawdbot\config.yaml`：

```yaml
# 完全保护
tools:
  exec:
    security: deny

# 智能保护
tools:
  exec:
    security: allowlist
    ask: on-miss
    safeBins:
      - notepad
      - explorer
      - python
      # ...等等

# 关闭保护
tools:
  exec:
    security: full
    ask: off
```

## 常见问题

### Q1: 为什么我让 AI 执行命令，它说"被拒绝"？

**可能原因**：

| 原因 | 解决方法 |
|-----|---------|
| 你在使用「完全保护」模式 | 切换到「智能保护」或「关闭保护」 |
| 操作不在信任列表，你没有确认 | 打开 Web 控制台，查看是否有等待确认的请求 |
| 操作超时被自动拒绝 | 保持浏览器打开，及时确认 |
| 操作在黑名单中 | 这个操作永远不会被执行（如删除文件） |

### Q2: 我选了「智能保护」，但什么命令都执行不了？

**这是一个已知 Bug（v2026.1.30 之前的版本）**。

**临时解决方案**：手动编辑配置文件 `~/.clawdbot/config.yaml`：

```yaml
tools:
  exec:
    security: allowlist
    ask: on-miss          # 确保有这行！
    safeBins:
      - notepad
      - explorer
      - code
      - python
      - node
      - npm
      - git
```

### Q3: 操作审批的通知在哪里？

**在 Web 控制台** `http://localhost:18789`。

**重要提醒**：
1. 你必须**打开浏览器并保持连接**才能收到通知
2. 如果关闭浏览器，将**无法看到审批请求**
3. 超时 **2 分钟**后操作会被**自动拒绝**

**建议**：安装后把这个页面一直开着（可以最小化）。

### Q4: 我怎么知道 AI 在等我确认？

1. 对话界面会显示"等待确认..."
2. Web 控制台会弹出通知（如果你打开了浏览器）
3. AI 会告诉你"需要你的确认才能继续"

### Q5: 为什么智能保护模式不能删除文件？

**这是设计如此**，目的是保护你的数据。

代码中写死了 `allowDelete: false`（见 `src/config/region-cn.ts` 第 505 行）。

如果你确实需要让 AI 删除文件，必须切换到「关闭保护」模式。

### Q6: 我想让 AI 帮我整理文件，需要什么模式？

**推荐使用「智能保护」模式**：

1. 在配置向导中选择「智能保护」
2. 设置工作目录为你要整理的文件夹（如 `D:\Documents`）
3. AI 可以在这个目录内：
   - ✅ 移动文件（mv, move）
   - ✅ 重命名文件（ren, rename）
   - ✅ 复制文件（cp, copy）
   - ✅ 创建文件夹（mkdir）
   - ❌ 删除文件（不行，这是硬限制）

如果需要删除文件，必须切换到「关闭保护」模式。

### Q7: 浏览器控制受安全模式影响吗？

**浏览器控制不受安全模式限制**，所有模式都可以：
- ✅ 打开网页
- ✅ 点击、输入、滚动
- ✅ 截图
- ✅ 提取页面内容

**区别在于浏览器配置**：

| 模式 | 浏览器配置 | 能访问你的登录状态吗？ |
|-----|-----------|---------------------|
| 完全保护 | 独立配置（clawdbot） | ❌ 不能 |
| 智能保护 | 独立配置（clawdbot） | ❌ 不能 |
| 关闭保护 | 可选使用你的配置 | ✅ 可以（如果你允许） |

### Q8: 如何添加新的信任操作？

**方法 1：通过确认弹窗**

当 AI 请求一个新操作时，选择**"以后都信任"**，这个操作就会被加入信任列表。

**方法 2：手动编辑配置**

编辑 `~/.clawdbot/config.yaml`，在 `safeBins` 列表中添加：

```yaml
tools:
  exec:
    safeBins:
      - notepad
      - explorer
      # 添加你想信任的命令
      - pip
      - conda
      - wps
```

## 推荐设置

### 小白用户

选择 **🔒 智能保护** 模式，设置一个专门的工作目录（如 `C:\Clawdbot\workspace`）。

**你能做的**：
- 让 AI 帮你处理工作目录内的文件
- 安全地浏览网页
- 执行常用操作（打开软件、运行脚本等）

**你不用担心**：
- AI 误删重要文件（删除功能被禁用）
- AI 访问敏感目录（只能访问你指定的目录）
- 危险命令被执行（黑名单保护）

**记住**：
- 保持浏览器打开 `http://localhost:18789`
- 看到操作确认请求时，仔细阅读后再决定

### 开发者

选择 **🔒 智能保护** 模式，工作目录设置为你的项目根目录。

常用开发命令（python, node, npm, git）已在信任列表中。

需要其他命令时，在确认弹窗中选择"以后都信任"。

### 技术高手 / AI 探索者

可以选择 **⚡ 关闭保护** 模式，但强烈建议：
- 在虚拟机或独立设备上运行
- 定期备份重要数据
- 不要让 AI 打开不信任的文档（可能包含恶意提示词）
