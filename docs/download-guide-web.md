## 第一步：下载安装包

### 先选个适合你的版本

Clawdbot 提供 **Lite（轻量版）** 和 **Pro（专业版）** 两种版本，满足不同需求。

#### 版本对比

| 特性 | Lite 轻量版 | Pro 专业版 |
|------|------------|-----------|
| 安装体积 | ~80-150 MB | 主程序 ~150MB + Docker ~600MB |
| 沙盒隔离 | 目录隔离 + 命令过滤 | 完整容器级隔离 |
| 安全等级 | ⭐⭐⭐ 日常使用足够 | ⭐⭐⭐⭐⭐ 企业级保护 |
| 系统依赖 | 开箱即用 | 需要 Docker Desktop |
| 推荐人群 | 个人用户、想快速上手 | 企业用户、高安全需求 |

**不知道选哪个？** 大多数情况选 **Lite 轻量版** 就够了，简单省心。

#### 平台支持

| 平台 | 版本 | 架构支持 | 沙盒类型 |
|------|------|---------|---------|
| Windows | Lite | x64 | 轻量沙盒（目录隔离 + 命令过滤） |
| Windows | Pro | x64 | Docker 容器沙盒 |
| macOS | Lite | arm64 / x64 / Universal | 软沙盒（目录隔离） |
| Linux | Lite | x64 / arm64 | 轻量沙盒（chroot + 用户隔离） |
| Linux | Pro | x64 / arm64 | Docker 容器沙盒 |

#### 系统要求

| 要求 | 说明 |
|------|------|
| **Windows** | Windows 10/11 (64位) |
| **macOS** | macOS 11 Big Sur 及以上（M 系列芯片或 Intel 都 OK） |
| **Linux** | Ubuntu 20.04+、Debian 11+、RHEL 8+、Fedora 34+ 等主流发行版 |
| **Node.js** | >= 22.12.0（使用安装包会自动内置，无需手动安装） |

## 第二步：安装运行

### Windows 用户

**exe 安装程序版**（推荐）
1. 双击下载的 `.exe` 文件
2. 跟着安装向导点「下一步」
3. 安装完成后，从开始菜单或桌面快捷方式启动

**zip 便携版**
1. 右键解压到任意目录（建议路径不含中文）
2. 进入文件夹，双击 `Clawdbot.exe` 启动

**Pro 版特别说明**
- 请确保 Docker Desktop 已安装并正在运行
- 首次启动会自动拉取沙盒镜像（约 80MB），稍等片刻

---

### macOS 用户

1. 双击 `.zip` 文件自动解压
2. 将 `Clawdbot.app` 拖入「应用程序」文件夹
3. 双击打开

**首次运行可能遇到安全提示？**

如果提示「无法验证开发者」，打开终端执行：

```bash
xattr -cr /Applications/Clawdbot.app
```

然后再次双击打开即可。

---

### Linux 用户

**通用压缩包**
```bash
# 解压
tar -xzf clawdbot-lite-vX.X.X-linux-x64.tar.gz
cd clawdbot-lite

# 启动
./clawdbot
```

**DEB 包（Debian/Ubuntu）**
```bash
sudo dpkg -i clawdbot-lite_X.X.X_amd64.deb
clawdbot
```

**RPM 包（RHEL/CentOS/Fedora）**
```bash
sudo rpm -i clawdbot-lite-X.X.X-1.x86_64.rpm
clawdbot
```

**使用 systemd 管理（可选）**
```bash
# 启动服务
sudo systemctl start clawdbot

# 设置开机自启
sudo systemctl enable clawdbot

# 查看运行日志
journalctl -u clawdbot -f
```

### Step 2：安全设置

选择 AI 助手的权限级别。**这一步非常重要，请认真阅读。**

#### 什么是「沙盒」？

简单说：沙盒就像给 AI 画了个「活动范围」，它只能在这个范围里干活。超出范围的文件和操作，AI 碰不到，也改不了。

#### ⚠️ 重要安全提示

> **请务必了解以下风险：**
>
> AI 助手存在「**提示词注入**」风险 —— 恶意网页、文档、邮件可能包含隐藏指令，诱导 AI 执行危险操作，例如：
> - 读取你的密码文件、浏览器记录
> - 发送敏感信息到外部
> - 删除重要数据或系统文件
> - 执行恶意脚本或命令
>
> **强烈建议**：使用一台独立设备部署 Clawdbot，与重要数据物理隔离。
>
> 如果必须在工作电脑上使用，请至少选择「智能保护」模式，并确保工作目录不包含敏感文件。

#### 三种安全模式

| 模式 | 图标 | 描述 | 适合场景 |
|------|------|------|---------|
| **完全保护** | 🛡️ | AI 的所有操作都在沙盒中，无法访问沙盒外的任何文件 | 电脑上有重要/敏感文件、多人共用设备 |
| **智能保护** | 🔒 | 直接对话时 AI 有正常权限，后台任务自动受沙盒限制 | ⭐ **推荐** · 日常工作电脑 |
| **关闭保护** | ⚡ | AI 拥有完整系统权限，解锁全部能力 | 独立/废弃设备、已完整备份、技术专家 |

#### 快速决策指引

| 你的情况 | 建议选择 |
|---------|---------|
| 这是我的**日常工作电脑** | 智能保护 |
| 电脑上有**公司资料/客户数据** | 完全保护 |
| 这是**独立设备** + 我懂技术能兜底 | 可选关闭保护 |
| **不确定选哪个** | 智能保护（默认推荐） |

> 🔔 **选择「关闭保护」需要二次确认**：系统会弹窗让你确认已了解风险，这不是吓你，是真的有风险。

### Step 3：设置工作目录

指定 Clawdbot 可以操控的文件夹范围。

#### 主工作目录

这是 AI 助手的主要工作区域，AI 可以在此目录内自由读写文件。

| 平台 | 默认路径 |
|------|---------|
| Windows | `C:\Clawdbot\workspace` |
| macOS | `~/.clawbotcn/workspace` |
| Linux | `/opt/clawdbot/workspace` |

#### 额外信任目录（可选）

如果你需要 AI 访问其他文件夹（比如你的项目目录），可以在这里添加。

#### ⚠️ 目录选择安全建议

| 做法 | 说明 |
|------|------|
| ✅ **推荐** | 新建一个专用文件夹，如 `D:\AI-Workspace` |
| ✅ **推荐** | 选择不包含敏感信息的项目目录 |
| ❌ **避免** | 不要选择「桌面」「文档」「下载」等系统目录 |
| ❌ **避免** | 不要选择包含密码、证书、密钥的目录 |
| ❌ **避免** | 不要选择系统目录（如 `C:\Windows`、`/etc`） |

> **为什么要这样？** 万一 AI 被恶意提示词攻击，它能造成的破坏仅限于工作目录内。目录选得越小、越独立，风险越可控。

## 常见问题

### 下载安装类

**Q: Lite 版和 Pro 版怎么选？**
- **日常使用**：选 Lite 版，安装简单，资源占用少
- **高安全需求**：选 Pro 版，提供完整容器级隔离

**Q: 浏览器没有自动打开配置页面？**
- 手动访问 `http://localhost:端口/setup`（端口号看启动时的提示，通常是 18789）

**Q: Windows 提示"Windows 已保护你的电脑"？**
- 点击「更多信息」→「仍要运行」即可

### 配置类

**Q: 安全模式怎么选？**
- 不确定就选**智能保护**，兼顾体验和安全
- 处理敏感数据选**完全保护**
- 技术用户在独立设备上可选**关闭保护**

**Q: 可以同时连接多个 AI 平台吗？**
- 安装向导中只能配置一个主要平台，完成后可在设置中添加更多

**Q: 指挥渠道必须配置吗？**
- 不是必须的，可以跳过。你也可以直接通过 Web 界面与 AI 对话

**Q: API Key 填错了怎么办？**
- 完成向导后，可以在「设置」→「AI 服务」中修改

### 使用类

**Q: 如何更新到新版本？**
- 下载新版安装包，直接覆盖安装即可，配置会自动保留

**Q: 如何完全卸载？**
- Windows：控制面板 → 卸载程序，或删除解压目录
- macOS：将 app 拖入废纸篓，删除 `~/.clawbotcn` 目录
- Linux：`sudo dpkg -r clawdbot` 或 `sudo rpm -e clawdbot`
