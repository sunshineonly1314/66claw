## 一、一句话说清楚

**OpenClawCN 是一个跑在用户自己设备上的全能 AI 助手网关平台。**

用户在微信、钉钉、飞书、Slack、Discord 等 15+ 聊天工具里正常聊天，后台 OpenClawCN 接管消息，调度最合适的 AI 模型来回答——能打字、能说话、能画图、能生视频、能调工具、能记住你是谁。

一个后台，所有渠道，所有 AI 能力，数据全在自己手里。

## 三、核心能力矩阵

### 3.1 全渠道接入——"用户在哪，AI 就在哪"

不需要用户下载新 App，不需要换聊天工具。OpenClawCN 像一个"AI 分身"住进用户已有的聊天软件里。

**国内渠道（独有，上游不支持）：**
- 钉钉
- 飞书/Lark
- 企业微信（含 12+ 专业工具：客服、群摘要、工单、巡检等）
- 微信
- QQ

**国际渠道：**
- WhatsApp / Telegram / Slack / Discord / Signal / Microsoft Teams / Google Chat / Line / Matrix / IRC 等

> **对比上游**：上游只做国际渠道。我们独家覆盖了中国主流企业 IM，这是最核心的差异化壁垒。

### 3.2 全模态 AI 能力——"不只是聊天"

| 能力 | 说明 | 亮点 |
|------|------|------|
| 文本对话 | 智能问答、长文写作、代码生成 | 对接 25+ 厂商，自动选最优模型 |
| 图片理解 | 拍照/截图发给 AI 即可识别分析 | 支持所有视觉大模型 |
| 图片生成 | 用自然语言描述即可生图 | DALL-E / 通义万相 / 硅基流动 / **本地显卡直出** |
| 视频生成 | 描述场景即可生成短视频 | 智谱 CogVideoX、硅基流动 |
| 语音识别 (ASR) | 发语音消息自动转文字 | **可完全离线运行**，无需联网 |
| 语音合成 (TTS) | AI 回复可自动朗读 | **可完全离线运行**，支持中文语音 |
| 文档理解 | PDF、音频、视频文件智能分析 | 多格式支持 |

> **对比上游**：视频生成、离线语音（ASR+TTS）、本地显卡出图，均为我们独有能力。

### 3.3 智能记忆系统——"越用越懂你"

- **自动记忆**：不需要用户主动操作，AI 自动从对话中提取关键信息（你的偏好、习惯、身份、待办等）
- **长期记忆**：跨对话持久保存，下次聊天自动想起
- **隐私安全**：所有记忆数据存在用户自己的设备上，不上传云端

> 类似 ChatGPT Plus 的记忆功能，但数据完全自主可控。

### 3.4 智能调度引擎——"自动帮你选最对的 AI"

用户不需要懂什么是"模型"。发一条消息，系统自动判断：
- 这是文字任务还是图片任务？简单还是复杂？
- 哪个 AI 模型最擅长处理？
- 哪个最便宜？
- 当前哪个可用？

然后自动路由到最优模型，用户完全无感。

### 3.5 技能与工具生态——"AI 的能力可以无限扩展"

- **75+ 内置技能**：编程助手、网页搜索、新闻聚合、天气查询、GitHub、Notion、Trello、Spotify、桌面控制等
- **MCP 协议**：一键安装第三方 AI 工具（带中国镜像加速）
- **插件 SDK**：企业可自行开发定制插件
- **多 Agent 编排**：用自然语言描述需求，自动组建 AI 团队协作

## 四、典型应用场景

### 场景 1：个人 AI 管家

一个打工人在飞书里直接 @AI 助手：
- "帮我把这段英文邮件翻译成中文"
- "这个 Excel 截图里的数据帮我画个柱状图"
- "提醒我明天下午 3 点开会"
- "帮我生成一张产品发布的海报"

**价值**：不用切换 App，不用注册新账号，在工作场景里直接用 AI。

### 场景 2：企业智能客服

在企业微信里部署 AI 客服：
- 自动应答常见问题
- 复杂问题自动转人工
- 工单自动生成和跟踪
- 群消息自动摘要
- 定时巡检和播报

**价值**：降低客服人力成本 50%+，7x24 响应，服务质量标准化。

### 场景 3：开发者 AI 工作台

开发者在 Slack/Discord/终端里：
- 代码审查和生成
- Bug 分析和修复建议
- 文档自动生成
- GitHub PR/Issue 管理
- 多模型对比测试

**价值**：开发效率提升 30%+，统一 AI 入口替代碎片化的 AI 工具。

### 场景 4：内容创作工作流

创作者在微信/钉钉里：
- "帮我写一篇小红书风格的产品推广文案"
- "把这段文字生成一张配图"
- "根据这个脚本生成一段 5 秒的视频片段"
- AI 自动记住品牌调性和写作风格

**价值**：文+图+视频一站式 AI 创作，降低内容生产门槛。

### 场景 5：离线/隐私场景

对数据安全要求极高的用户：
- 本地部署 Ollama 大模型，对话不出设备
- 本地语音识别（SenseVoice），语音不上传
- 本地语音合成（Kokoro），发音不联网
- 本地图片生成（sd.cpp），创意不外泄
- 支持 U 盘便携模式，随插随用

**价值**：真正的数据自主可控，满足金融、医疗、政府等敏感行业需求。

## 八、快速 FAQ

**Q：跟 ChatGPT 有什么区别？**
A：ChatGPT 是一个在线聊天网页。我们是一个 AI 网关平台——可以在钉钉、微信等任何渠道用，可以同时调用多家 AI，可以完全离线，数据在你自己设备上。

**Q：跟 Coze/扣子有什么区别？**
A：Coze 是字节的闭源 SaaS 产品，只支持飞书和豆包生态。我们开源、全渠道、全厂商、可离线、可私有部署。

**Q：需要什么硬件？**
A：最低一台普通电脑即可运行。如果要用本地语音/出图，建议有独立显卡（4GB 以上显存）。纯在线模式对硬件无要求。

**Q：企业用安全吗？**
A：完全私有部署，数据不出设备/内网。支持沙箱执行、权限审批、操作审计。MIT 开源可审计代码。

**Q：个人用户免费吗？**
A：软件本身 MIT 开源免费。AI 模型的调用费用取决于用户选择的厂商（有大量免费模型可选）。
