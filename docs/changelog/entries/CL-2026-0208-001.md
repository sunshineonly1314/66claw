## 一句话摘要

SiliconFlow API 返回 403 时，错误信息无法传递到 chat 前端，用户看到空白页面。修复后动态显示供应商名称和具体操作指引。

## 问题描述

用户在 chat 页面发送消息后，页面短暂显示"思考中"圆点动画，随后动画消失，**没有任何文字响应**。用户完全不知道发生了什么。

Gateway 日志显示 SiliconFlow API（`deepseek-ai/DeepSeek-V3`）持续返回 HTTP 403 错误：
```
[agent/embedded] [Error] 403 status code (no body) | failover=auth
```

## 根因分析

### 两层问题

**第 1 层：API 层面**
- SiliconFlow API Key 失效或额度用尽，返回 403 Forbidden（无响应体）

**第 2 层：代码层面（BUG）**
错误信息生成了（`payloads.length=1`），但无法传递到前端 UI。断裂链路：

```
API 403 → 错误 payload 生成 ✅
→ 但：没有流式 assistant 事件（403 是立即失败，不走流式）❌
→ emitChatFinal 的 streaming buffer 为空 → message: undefined ❌
→ UI 收到 "final" 事件 → reading indicator 消失
→ loadChatHistory → transcript 中是空 assistant 消息 → 什么都不显示 ❌
```

同时前端存在多个交互缺陷：
- `formatErrorHint` 会用英文 pattern 重新匹配中文错误，把详细信息覆盖为 generic 提示
- `isError: true` 标志虽然设置了，但渲染层完全忽略，错误消息无视觉区分
- `error` 事件不触发 `loadChatHistory`，可能导致状态不一致

## 修改内容

### 核心 Bug 修复（3 处）

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `src/agents/pi-embedded-runner/run.ts` | 修改 | 当 API 立即返回错误（无流式文本）时，将错误 payload 作为 assistant 事件发出，填充 streaming buffer |
| `src/agents/pi-embedded-helpers/errors.ts` | 修改 | 403/401 "no body" 错误生成动态中文提示，包含供应商中文名和模型名 |
| `src/gateway/server-methods/chat.ts` | 修改 | `agentRunStarted=true` 时也将 reply 文本写入 transcript（兜底） |

### 动态供应商名称（3 处）

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `src/agents/pi-embedded-helpers/errors.ts` | 新增 | `getProviderDisplayName()` 函数，用 `CN_PROVIDERS` 做 ID→中文名映射 |
| `src/agents/pi-embedded-helpers/errors.ts` | 修改 | `formatAssistantErrorText` 新增 `provider`/`model` 可选参数 |
| `src/agents/pi-embedded-runner/run/payloads.ts` | 修改 | `buildEmbeddedRunPayloads` 新增并透传 `provider`/`model` 参数 |
| `src/agents/pi-embedded-runner/run.ts` | 修改 | 两处调用点传入 `provider`/`modelId` |

### 前端交互优化（5 处）

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `ui/src/ui/controllers/chat.ts` | 修改 | "final" 事件中无 message 且无 stream 时，显示"未收到模型响应数据"兜底提示 |
| `ui/src/ui/app-gateway.ts` | 修改 | "error" 事件也触发 `loadChatHistory`，确保 UI 与服务端同步 |
| `ui/src/ui/chat/error-hints.ts` | 修改 | 添加中文 pattern（"api key 已失效"等）；检测后端已格式化的中文消息直接透传，防止双重格式化 |
| `ui/src/ui/chat/grouped-render.ts` | 修改 | 读取 `isError` 标志，为错误消息添加 `chat-bubble--error` CSS 类 |
| `ui/src/styles/chat/grouped.css` | 新增 | 错误气泡样式：橙色左侧边线 + 淡橙色背景，与正常消息视觉区分 |

### 错误提示中文化（1 处）

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `src/auto-reply/reply/agent-runner-execution.ts` | 修改 | 上下文溢出、排序异常、处理失败等 fallback 提示从英文改为中文 |
