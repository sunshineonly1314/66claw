常见问题

社区版够用吗？
够用。16 家 AI 供应商全部可用，中文界面、桌面客户端、自动更新、智能压缩全都有。 日常和 AI 对话完全没问题，就是少了一些自动化和高级功能。
专业版比社区版多了什么？
主要多了三块：① 智能调度 — 发图自动切视觉模型、发代码自动切代码模型； ② 海量插件和工具推荐；③ 音频/视频理解 + 企业协作功能。
团队版的 1v1 交付包含什么？
远程帮你安装客户端、配置 AI 供应商的 API Key、调通第一次对话、 确认一切正常运行。大概 30~60 分钟搞定。
可以从社区版升级吗？
可以，随时补差价升级到专业版或团队版。已用天数按比例折算，不浪费。
AI 供应商的费用包含在里面吗？
ClawdBot 是 AI 客户端工具，不包含各供应商的 API 调用费用。 但我们会自动帮你优先使用免费额度，尽量帮你省钱。
一台设备不够用怎么办？
社区版 1 台、专业版 3 台、团队版 5 台。 可以在设备管理里随时解绑旧设备、绑定新设备。
