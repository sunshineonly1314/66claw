## 概述

ClawbotCN Web UI 是一个单页应用（SPA），提供完整的 AI 助手管理界面。用户可以通过浏览器与 AI 助手对话、管理技能、配置消息渠道、监控系统状态等。

### 技术架构

- **前端框架**: Lit (Web Components)
- **路由方式**: 客户端 SPA 路由
- **通信协议**: WebSocket (实时通信) + HTTP REST API
- **默认端口**: 18789
- **支持的浏览器**: 现代浏览器 (Chrome, Firefox, Edge, Safari)

### 访问认证

网关支持以下认证方式：
- **Token 认证**: 通过 URL 参数 `?token=xxx` 或设置页面输入
- **密码认证**: 通过 URL 参数 `?password=xxx` 或设置页面输入
- **无认证模式**: 本地开发时可禁用认证

## 对话页面 /chat

### 页面说明

主要的 AI 对话界面，用户可以在此与 AI 助手进行自然语言交互。

### 功能特性

#### 1. 消息输入与发送

| 功能 | 操作方式 | 说明 |
|------|----------|------|
| 发送消息 | Enter 键或点击发送按钮 | 发送当前输入的文本消息 |
| 换行输入 | Shift + Enter | 在输入框中换行，不发送消息 |
| 粘贴图片 | Ctrl/Cmd + V | 直接粘贴图片作为附件 |
| 移除附件 | 点击附件上的 X 按钮 | 从待发送消息中移除图片附件 |
| 终止响应 | 点击"停止"按钮 | 中断 AI 正在生成的响应 |

#### 2. 消息队列管理

- **队列显示**: 当有多条消息等待处理时，显示队列计数
- **移除队列消息**: 可以移除尚未处理的排队消息
- **队列状态**: 显示当前队列中的消息数量

#### 3. 会话管理

| 功能 | 说明 |
|------|------|
| 新建会话 | 创建全新的对话会话，清空历史 |
| 切换会话 | 通过 URL 参数 `?session=xxx` 切换到指定会话 |
| 会话持久化 | 会话历史自动保存，刷新页面不会丢失 |

#### 4. 专注模式 (Focus Mode)

- **启用**: 点击专注模式按钮，隐藏侧边栏和导航
- **退出**: 再次点击按钮退出专注模式
- **用途**: 减少干扰，专注于对话内容

#### 5. Markdown 侧边栏

- **功能**: 展示工具调用的长文本输出（如代码、文档等）
- **操作**: 
  - 拖拽分割线调整宽度比例
  - 切换"原始文本"视图
  - 点击关闭按钮收起侧边栏

#### 6. 欢迎发现卡片

**首次访问时显示**，包含：
- 能力扫描：检测系统已安装的工具和配置
- 个性化建议：基于检测结果推荐常用操作
- 示例对话：点击即可快速开始对话

#### 7. 思考深度设置

| 级别 | 说明 |
|------|------|
| 浅度 (low) | 快速响应，适合简单问题 |
| 中度 (medium) | 平衡模式，默认选项 |
| 深度 (high) | 深入思考，适合复杂问题 |

#### 8. 消息显示

- **消息分组**: 同一轮对话的消息归组显示
- **工具调用卡片**: 展示 AI 调用的工具及结果
- **流式输出**: 实时显示 AI 生成的内容
- **等待指示器**: 显示等待响应的时间和状态
- **上下文压缩提示**: 当上下文被压缩时显示提示

### 配置项说明

| 配置 | 路径 | 说明 |
|------|------|------|
| 默认会话 | `settings.sessionKey` | 默认使用的会话 Key |
| 思考深度 | `agents.defaults.thinking` | 默认思考深度级别 |

## 控制台组

### 概览 /overview

#### 页面说明

系统仪表板，提供网关连接状态和系统概览信息。

#### 功能特性

##### 1. 网关连接配置

| 配置项 | 说明 | 用途 |
|--------|------|------|
| 网关地址 | WebSocket URL | 连接到网关的地址，默认 `ws://localhost:18789` |
| 令牌 (Token) | 认证令牌 | 用于网关认证，通过 `openclawcn gateway token` 生成 |
| 密码 | 可选认证方式 | 替代令牌的认证方式 |

##### 2. 连接操作

| 操作 | 说明 |
|------|------|
| 连接 | 使用当前配置连接到网关 |
| 断开连接 | 断开当前 WebSocket 连接 |
| 刷新状态 | 重新获取网关状态信息 |

##### 3. 系统快照

| 信息项 | 说明 |
|--------|------|
| 运行时间 | 网关已运行的时间 |
| 心跳间隔 | 系统心跳检测间隔 |
| 渠道状态 | 已配置渠道的整体状态 |

##### 4. 统计卡片

| 卡片 | 显示内容 | 交互 |
|------|----------|------|
| 实例 | 在线信标数量 | 点击跳转到实例页面 |
| 会话 | 活跃会话数量 | 点击跳转到会话页面 |
| 定时任务 | 任务数量和下次执行时间 | 点击跳转到定时任务页面 |

##### 5. Token 用量卡片

- **今日用量**: 显示今日消耗的 Token 数量
- **近30天趋势**: 迷你图表展示用量趋势
- **趋势指示**: 上升/下降/持平箭头
- **查看详情**: 点击跳转到用量统计页面

##### 6. 连接错误提示

| 错误类型 | 提示内容 |
|----------|----------|
| 认证失败 | 提示重新复制令牌 URL 或更新令牌 |
| 网络错误 | 提示检查网关是否正常运行 |
| 不安全上下文 | 提示使用 HTTPS 或在网关主机上打开 |

### 指挥渠道 /channels

#### 页面说明

管理各种消息渠道（聊天平台）的连接和配置。

#### 支持的渠道

##### 国内渠道（优先显示）

| 渠道 | 说明 | 配置项 |
|------|------|--------|
| **飞书** | 飞书企业内部应用机器人 | App ID, App Secret, Encrypt Key, Verification Token |
| **钉钉** | 钉钉企业内部应用机器人 | App Key, App Secret, Robot Token |

##### 国际渠道

| 渠道 | 说明 | 配置项 |
|------|------|--------|
| **WhatsApp** | WhatsApp Web 连接 | QR 码扫描登录 |
| **Telegram** | Telegram Bot | Bot Token |
| **Discord** | Discord Bot | Bot Token |
| **Google Chat** | Google Workspace Chat | Credential, Audience |
| **Slack** | Slack App (Socket Mode) | App Token |
| **Signal** | Signal CLI | Base URL |
| **iMessage** | Apple iMessage (仅 macOS) | - |
| **Nostr** | Nostr 协议 | Profile 配置 |

#### 功能特性

##### 1. 渠道状态卡片

每个渠道显示一个可折叠的状态卡片，包含：

| 信息 | 说明 |
|------|------|
| 状态徽章 | 运行中/已停止/未配置 |
| 配置状态 | 是否已配置凭证 |
| 连接状态 | 当前是否连接 |
| 最后活动 | 最后一次消息活动时间 |
| 错误信息 | 如有错误则显示 |

##### 2. WhatsApp 特殊功能

| 操作 | 说明 |
|------|------|
| 显示二维码 | 生成登录二维码供手机扫描 |
| 等待扫码 | 显示扫码等待状态 |
| 重新关联 | 重新生成二维码 |
| 登出 | 断开 WhatsApp 连接 |

##### 3. 渠道配置

- **展开配置表单**: 点击渠道卡片展开详细配置
- **凭证验证**: 保存前验证凭证有效性（钉钉、飞书支持在线验证）
- **保存配置**: 将配置写入 config.json

#### 配置项说明

| 配置路径 | 说明 |
|----------|------|
| `channels.feishu.app` | 飞书应用配置 |
| `channels.dingtalk.app` | 钉钉应用配置 |
| `channels.telegram.token` | Telegram Bot Token |
| `channels.discord.token` | Discord Bot Token |

### 定时任务 /cron
