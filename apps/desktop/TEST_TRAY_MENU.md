# 系统托盘菜单测试指南

## 🧪 如何测试新增的托盘功能

### 前提条件
✅ Tauri 应用正在运行 (PID: 95608)
✅ 系统托盘图标已显示

---

## 📍 找到托盘图标

### Windows 11
1. 查看任务栏右下角的系统托盘区域
2. 点击 `^` 箭头图标展开隐藏图标
3. 找到 ClawdbotCN 图标

### 提示
- 图标可能在隐藏图标中
- 图标外观: 应用默认图标 (32x32 PNG)

---

## 🐛 故障排查

### 问题: 托盘图标不显示

**可能原因**:
- Tauri 进程未启动
- 系统托盘区域隐藏了图标

**解决方案**:
```bash
# 检查进程
tasklist | grep -i "clawdbot-desktop"

# 重启应用
cd apps/desktop
pnpm tauri dev
```

---

### 问题: 点击菜单无响应

**检查**:
- 查看控制台是否有错误输出
- 确认编译是否成功

**控制台位置**:
- 运行 `pnpm tauri dev` 的终端窗口

---

### 问题: "查看日志" 无法打开目录

**Windows 检查**:
```bash
# 验证 explorer 命令
explorer d:\codeknowledge\clawdbot-main\clawdbot-main\apps\desktop\src-tauri\target\debug\logs
```

**手动创建目录**:
```bash
mkdir -p d:\codeknowledge\clawdbot-main\clawdbot-main\apps\desktop\src-tauri\target\debug\logs
```
