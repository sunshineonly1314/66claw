# LLM 🔮

多提供商大语言模型（LLM）集成。

## 支持的提供商

- OpenAI（GPT-4、GPT-4o）
- Anthropic（Claude）
- Google（Gemini）
- 本地模型（Ollama、LM Studio）

## 功能

- 统一聊天界面
- 模型对比
- Token 计数
- 成本估算
- 流式响应

## 使用示例

```
"Compare GPT-4 vs Claude on this task"
"Use local Llama model"
"Estimate tokens for this prompt"
```
