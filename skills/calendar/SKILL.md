# Calendar 📅

日历与日程安排管理。

## 功能

- 创建事件
- 安排会议
- 设置提醒
- 查看空闲时间
- 周期性事件
- 日历同步

## 支持的提供商

- Google Calendar
- Apple Calendar
- Outlook Calendar

## 使用示例

```
"Schedule meeting tomorrow at 2pm"
"Show my calendar for this week"
"Find free time for a 1-hour meeting"
```
