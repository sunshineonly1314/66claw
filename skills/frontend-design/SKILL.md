本技能指导创建风格鲜明、面向生产环境的前端界面，规避泛滥成灾的“AI 套路化”审美。实现真正可用的代码，同时对美学细节与创意决策倾注非凡关注。

用户提出前端需求：组件、页面、应用或界面。可能附带用途、目标用户或技术约束等上下文信息。

## 设计思维

编码前，请深入理解上下文，并坚定确立一种**大胆鲜明的美学方向**：
- **目的**：此界面解决什么问题？谁是使用者？
- **基调**：选择一种极致风格：极简到冷峻、繁复到混沌、复古未来主义、有机自然风、奢华精致感、童趣玩具感、杂志编辑风、粗野主义/原始感、装饰艺术/几何风、柔和粉彩系、工业实用风等。风格选择极其丰富——可从中汲取灵感，但最终设计必须忠于所选美学方向。
- **约束条件**：技术要求（框架、性能、无障碍访问等）。
- **差异化亮点**：什么能让它**令人过目不忘**？用户最可能记住的**唯一亮点**是什么？

**至关重要**：选定清晰的概念方向，并以精准执行力贯彻始终。大胆的繁复风格与克制的极简风格同样有效——关键在于**意图明确**，而非强度高低。

随后实现可运行的代码（HTML/CSS/JS、React、Vue 等），确保其：
- 达到生产级标准且功能完备
- 视觉上震撼夺目、令人难忘
- 整体风格统一，具有明确的美学观点
- 每一处细节都经过精心雕琢

## 前端美学指南

重点关注：
- **排版（Typography）**：选用优美、独特、富有趣味性的字体。避免 Arial、Inter 等通用字体；转而选择能提升界面格调的标志性字体——出人意料、富有个性的字体组合。以醒目独特的展示字体搭配精致考究的正文字体。
- **色彩与主题**：坚持整体美学一致性。使用 CSS 变量保障配色统一。主色调搭配锐利点缀色，远胜于畏首畏尾、平均分配的配色方案。
- **动效（Motion）**：运用动画增强视觉效果与微交互体验。HTML 场景优先采用纯 CSS 方案；React 场景若可用，则推荐 Motion 库。聚焦高影响力时刻：一次编排精妙的页面加载动画（配合 staggered reveals 与 animation-delay），远胜于零散堆砌的微交互。善用滚动触发与悬停状态，制造惊喜感。
- **空间构成（Spatial Composition）**：突破常规布局。拥抱不对称、重叠、对角线流动、打破网格的元素、充裕的留白，或受控的密集感。
- **背景与视觉细节**：营造氛围与纵深感，而非依赖纯色背景。添加契合整体美学的上下文效果与纹理：渐变网格、噪点纹理、几何图案、多层透明叠加、戏剧性阴影、装饰性边框、自定义光标、颗粒质感覆盖层等。

**切勿使用**泛滥的 AI 生成式审美：过度使用的字体家族（Inter、Roboto、Arial、系统字体）、陈腐的配色方案（尤其是白色背景上的紫色渐变）、可预测的布局与组件模式，以及缺乏上下文特性的模板化设计。

请创造性地诠释需求，做出出人意料却真实贴合场景的设计选择。每个设计都应独一无二。在明暗主题、字体选择、美学风格之间保持变化。**切勿**在不同生成结果间趋同（例如反复使用 Space Grotesk）。

**重要提示**：实现复杂度须匹配美学构想。繁复风格需大量动画与特效支撑；极简或精致风格则需克制、精准与对间距、排版及细微之处的极致关注。优雅，源于对构想的完美执行。
