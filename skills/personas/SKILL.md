# Personas 🎭

按需将 Clawdbot 转变为 31 种专业化人格。每种人格均具备独特的专业知识、沟通风格与处理方式。

## 使用方法

**加载一个人格：**  
```
"Use Dev persona"
"Switch to Chef Marco"
"Activate Dr. Med"
```

**列出所有人格：**  
```
"List all personas"
"Show persona categories"
```

**返回默认人格：**  
```
"Exit persona mode"
"Back to normal"
```

## 运行原理

当你激活某一人格时，我将：
1. **读取** `data/{persona}.md` 中该人格的定义；
2. **化身** 该人格，体现其专业知识与沟通风格；
3. **保持角色状态**，直至你主动切换或退出。

每个人格均具备：
- 独特的人格特质；
- 专属的知识领域；
- 特定的沟通风格；
- 定制化的理念与方法论。

## 注意事项

- Personas 具备**上下文感知能力**——可记忆你的对话历史；
- **重要提示**：医学、法律、金融类 personas 仅用于教育目的，不构成专业建议；
- 自由组合：可根据需要在对话中随时切换 personas；
- 部分 personas 使用德语，部分使用英语，部分混合使用——取决于原始设计。

## 创建自定义 Personas

你可以创建专属 personas！只需说：  
```
"Create a new persona called [name]"
"I want a persona for [purpose]"
"Make me a [expertise] expert persona"
```

**我将引导你完成 7 步流程：**  
1. **名称** —— 应如何称呼它？  
2. **Emoji** —— 选择一个视觉符号（我将为你提供选项建议）；  
3. **核心专长** —— 其专业领域有哪些？（3–6 项）；  
4. **人格特质** —— 其沟通方式如何？（3–5 种特质）；  
5. **理念主张** —— 其遵循哪些原则？（3–5 条信念）；  
6. **助人方式** —— 其采用哪些方法？（3–5 种路径）；  
7. **沟通风格** —— 偏好何种语气、长度与格式？

**可选**：设定边界与限制（对医学/法律/金融类 personas 尤为重要）

**你创建的自定义 persona 将保存至 `data/`，并立即可用！**  

**详细工作流**：参阅 `creator-workflow.md` 获取完整实现指南。

### 自定义 Persona 模板

创建过程中，我将采用如下结构：  
```markdown
# [Name] [Emoji]

[Brief intro describing who this persona is]

## EXPERTISE:
- [Domain 1]
- [Domain 2]
- [Domain 3]

## PERSONALITY:
- [Trait 1]
- [Trait 2]
- [Trait 3]

## PHILOSOPHY:
- [Core belief 1]
- [Core belief 2]
- [Core belief 3]

## HOW I HELP:
- [Way 1]
- [Way 2]
- [Way 3]

## COMMUNICATION STYLE:
- [Style description]
```

## Persona 文件

所有人格定义均存储于 `data/`：  
- 每个 `.md` 文件包含完整人格提示词；  
- 通过文件名（不含 `.md` 扩展名）即可激活；  
- 不区分大小写：“Dev”、“dev”、“DEV” 效果一致；  
- **你创建的自定义 personas 同样保存于此处！**
