# 营销 Skills

## 概述  

一个集成式技能，内含 23 个营销模块。请在 `references/` 下选择匹配需求的模块，即可获取实用检查清单、框架及可直接复制粘贴的交付物。

本技能完整封装 `coreyhaines31/marketingskills` 的全部内容，托管于 `references/`，并提供简易路由机制，以便加载对应模块。

## 使用方法  

1) 识别与用户请求匹配的模块。  
2) 阅读对应的 `references/<module>/SKILL.md` 文件。  
3) 应用其中框架，输出实际成果（草稿 + 检查清单）。

## 所含模块（各模块功能说明）

每个模块位于 `references/<module>/SKILL.md`。

- `ab-test-setup`：规划与执行 A/B 测试  
- `analytics-tracking`：配置追踪与度量体系（GA4/GTM/事件）  
- `competitor-alternatives`：竞品对比分析 + 替代方案/“XX vs YY” 页面  
- `copy-editing`：编辑与润色现有文案  
- `copywriting`：撰写或优化营销文案（标题、CTA、页面正文）  
- `email-sequence`：构建邮件序列与培育流程（drip campaigns）  
- `form-cro`：优化线索捕获与联系表单  
- `free-tool-strategy`：策划“工程即营销”免费工具（计算器、生成器）  
- `launch-strategy`：产品发布与公告策略  
- `marketing-ideas`：增长与营销战术创意库  
- `marketing-psychology`：用于增强说服力的心理模型/认知偏差  
- `onboarding-cro`：提升用户激活与引导体验  
- `page-cro`：任意营销页面的转化率优化  
- `paid-ads`：创建与优化付费广告系列  
- `paywall-upgrade-cro`：优化应用内付费墙与升级界面  
- `popup-cro`：创建与优化弹窗及模态框  
- `pricing-strategy`：定价、套餐设计与变现策略  
- `programmatic-seo`：规模化构建 SEO 页面（含模板与数据）  
- `referral-program`：设计推荐与联盟计划  
- `schema-markup`：添加结构化数据与富媒体摘要（rich snippets）  
- `seo-audit`：技术 SEO 与页面级 SEO 审计  
- `signup-flow-cro`：优化注册与开户流程  
- `social-content`：创建与排期社交媒体内容

## 输出规范  

- 坚持 80/20 原则：优先解决影响最大的杠杆点。  
- 绝不虚构指标或关键词搜索量；若缺失，须明确标注为假设。  
- 尽可能提供可直接复制粘贴的草稿及实施检查清单。
