# 调查工具包（ACAS 对齐版）

## 目的
创建一份符合 ACAS 规范的调查启动工具包：含调查邀约措辞、中立提问计划及适用于交通运输事故及潜在失当行为的证据日志结构。

## 使用时机
- “为本次事故起草一份调查邀约函及证据清单。”
- “为本次驾驶员面谈设计一套符合 ACAS 规范的调查问题。”
- “将这些事故记录整理成一份简洁的管理者简报。”（当其用于支撑调查工作时）

**切勿在以下情形中使用……**
- 泛泛的人力资源咨询，例如“公平的纪律处分流程是什么？”，且无需关联具体案例材料。
- 在尚未开展调查阶段的情况下，直接起草处理结果或惩戒措施。

## 输入项
- **必需项：**
  - 事件摘要（何事/何时/何地）、涉事方，以及所指称/正被审查的内容
  - 当前已掌握的证据（闭路电视录像、车载远程信息处理数据、里程计读数提取件、证人笔录、违章通知单、照片等）
  - 拟议会议日期区间，以及主持人与记录人名单
- **可选项：**
  - 相关内部政策（粘贴文本）、过往类似案例、工会代表/陪同人员信息
- **示例：**
  - “指称内容：于[日期]伪造人工录入。现有证据：里程计报告 + 主管笔录。”

## 输出项
- `investigation-invite.md`（可直接用于 Word）
- `question-plan.md`
- `evidence-log.md`（Excel 可用表格）
- 成功标准：
  - 措辞中立，不预设当事人有罪
  - 包含“陪同权”相关表述
  - 明确规定证据处理与留痕要求

## 工作流程
1. 确认当前阶段确属**调查阶段**（即事实核查），而非纪律听证会。
   - 若阶段不明确 → **立即暂停并询问用户**其所处的具体阶段。
2. 使用 `assets/invite-letter-template.docx-ready.md` 起草邀约函。
   - 内容须包括：会议目的、时间/地点、参会人员、“陪同权”说明、证据查阅方式、联络渠道。
3. 基于 `assets/neutral-question-plan-template.md` 制定中立提问计划。
   - 顺序应为：由宽泛入手 → 聚焦具体证据 → 探讨减责/背景因素 → 最后收尾。
4. 使用 `assets/evidence-log-template.md` 创建证据日志。
   - 如有必要，应包含证据保管链字段。
5. 加入来自 `references/acas-alignment-checklist.md` 的 ACAS 对齐检查项。
6. 若被要求编辑已有文档 → **务必事先征得用户确认**。

## 输出格式
```text
# evidence-log.md
| Ref | Evidence item | Source | Date/time captured | Who captured | Storage location | Integrity notes | Relevance | Shared with employee (Y/N, date) |
|-----|---------------|--------|-------------------|-------------|------------------|-----------------|----------|----------------------------------|
```

## 安全性与边界情形
- 不提供法律意见；仅聚焦于程序合规性与中立性。
- 若所涉指称性质严重、可能导致解雇，则须提示：根据内部治理要求，可能需人力资源部/法务部门复核（请用户提供其政策文本）。

## 示例
- 输入：“驾驶员面谈的邀约函 + 提问提纲”
  - 输出：已填充已知信息的邀约函 + 提问计划 + 证据日志模板
