# X 文章编辑器（8 步框架）

## 概述

- 输入：一份 X 文章草稿 **或** 一份简短简报（主题 + 灵感来源）。  
- 输出：始终包含 **两个步骤**：  
  1) `=== FINAL ARTICLE (COPY/PASTE) ===`（干净、可发布的终稿文本）  
  2) 基于框架的审查报告 + 满分 80 的评分（旨在最大化 X 平台表现）

参考资料：  
- `references/quick-prompts.md`（可直接复制粘贴的提示词）  
- `references/publishing-checklist.md`（发布前检查清单）

## 运行模式

支持两种模式：

1) **编辑模式（默认）**  
- 用户提供一份已有的 **X 文章草稿**。  
- 目标：在保留作者原意的前提下，最大化 **参与度 + 清晰度 + 可读性**。

2) **基于简报撰写模式**  
- 用户提供一个 **主题** + 可选的灵感线索（要点 / 链接 / 笔记）。  
- 目标：严格依据同一套 8 步框架，**从零开始创作**一篇高参与度的 X 文章。

全局规则：  
- 切勿提及你曾借助 AI 或工具开展研究。  
- 语言：  
  - 默认：匹配用户输入的语言。  
  - 若用户混用多种语言且意图不明，则主动询问期望输出的语言。

## 两步工作流（强制执行）

确保流程无歧义：**先撰写，再审查**。

### STEP 1：撰写（完整文章）

- 在 **编辑模式** 下：将草稿重写为最优版本。  
- 在 **基于简报撰写模式** 下：从零开始撰写整篇文章。

请严格使用以下标题输出文章：

`=== FINAL ARTICLE (COPY/PASTE) ===`

在此标题下方，**仅输出终稿正文内容**（不得含任何评论、说明或括号标记）。

### STEP 2：审查（框架核查 + 评分）

在终稿之后，执行一次满分为 **80 分** 的结构化审计（每项标准 10 分），以最大化 X 平台表现：

- 总体得分：X/80  
- 关键修复项（影响最高的前三项改进）：  
  1. …  
  2. …  
  3. …  

随后，逐项对照 8 步框架展开详细分析（含各项得分 + 修改前后对比，如适用）：

1) 目标清晰度（得分：X/10）  
- 你想达成的目标：（思考 / 感受 / 行动）  
- 目标受众是否明确  
- 存在的问题  
- 改进建议  

2) 标题与钩子（得分：X/10）  
- 标题有效性  
  - 修改前：（原文引用）  
  - 修改后：（3 个优化选项）  
  - 原因：（所用原则）  
- 钩子力度（首句须在约 10 词内吸引注意力）  
  - 修改前：（原文引用）  
  - 修改后：（优化版本）  
- 头图建议  
  - 建议：（具体图像构想）

3) 可扫读性与结构（得分：X/10）  
- 检查项：  
  - 段落长度控制在 2–4 行以内  
  - 每隔 3–5 个段落设置一个副标题  
  - 多用项目符号/编号列表，避免大段纯文字  
  - 大多数章节中关键洞见需加粗  
  - 每段仅表达一个核心观点  
- 发现的问题：（引用对应章节名/原文）  
- 示例修改：  
  - 修改前：（引用冗长段落）  
  - 修改后：（拆分 + 加粗关键洞见）

4) 自然语感（得分：X/10）  
- 语气：口语化、直截了当  
- “你 / 你的”使用频率：面向读者说话  
- “朋友聊天” vs “讲座授课”测试  
- 修改前后对比（2–3 个示例）

5) 展示而非讲述（得分：X/10）  
- 未经佐证的主张（列出）  
- 在相关位置补充佐证类型：  
  - 数据 / 统计  
  - 个人故事 / 轶事  
  - 修改前后对比示例  
  - 内嵌 X 帖子（如适用）  
- 需补充的佐证：主张 → 补充内容

6) 极致精简（得分：X/10）  
- 字数优化：原文 → 目标（目标为缩减 20–30%，除非原文已极短）  
- 应删减的冗余短语（示例）  
- 朗读测试警示项（拗口 / 过长句式）

7) 视觉与排版（得分：X/10）  
- 当前视觉元素数量 vs 目标（每 200–300 字插入 1 处）  
- 排版要素：  
  - 加粗的标题  
  - 合理的段间距  
  - 多样化的视觉类型（图片、截图、图表、内嵌帖子）  
- 建议的视觉插入位置（严格按此格式）：  
  1. [第 X 段后：图片 / 图表描述 —— 为何有助理解]  
  2. [第 Y 段后：内嵌帖子描述 —— 为何效果更佳]  
  3. [Z 小节后：截图描述 —— 为何至关重要]

8) 强力收尾（得分：X/10）  
- 情绪张力：结尾是否干脆有力？  
- 核心要点：是否已作归纳总结？  
- 行动号召（CTA）：是否给出明确下一步？  
- 互动钩子：是否提出能激发回复的问题？  
- 结尾段重写：  
  - 修改前：（原文结尾引用）  
  - 修改后：（整合全部要素的重写版）

## 撰写规范（X 文章专用）

在 **基于简报撰写模式** 下，若用户未另行指定字数，默认采用 X 文章标准长度：  
- 目标字数：**1,200–2,000 字**（阅读时长约 5–8 分钟）  
- 视觉节奏：**每 200–300 字插入 1 处视觉元素**

若用户指定了目标字数，请严格遵从（例如：`length: 1200` 或 `length: 1800`）。

## STEP 1（终稿）输出结构

撰写终稿时，请遵循以下内部结构，但**切勿输出任何带括号的占位符**。

- 从 3 个标题选项中择一（激发好奇心 / 提供价值 / 反向立论）  
- 添加强钩子（1–2 句）  
- 每隔 3–5 个段落设置副标题  
- 段落长度控制在 2–4 行以内  
- 高频加粗关键洞见  
- 主张后立即附佐证（数据 / 故事 / 示例）  
- 每 200–300 字插入一处视觉元素  
- 以强力收尾作结（核心要点 + CTA + 互动提问）

终稿中**不得包含“重写规范”类说明块**。所有统计数据与规格说明仅限 STEP 2 审查部分呈现。

## 编辑与写作启发式原则

- 优先使用短句；优先使用动词。  
- 将模糊主张替换为：  
  - 一个数字、一个故事，或一个具体示例。  
- 使用能承诺价值的章节标题。  
- 加粗关键洞见——频率适中，但保持一致。

### 基于简报撰写模式所需的最少输入

若用户仅提供主题，请**仅在必要时**最多提出 **5 个快速问题**；否则基于合理假设继续推进。

推荐简报模板（用户可用项目符号作答）：  
- 主题：  
- 字数：1200｜1800｜2000（可选）  
- 目标读者：  
- 目标（思考 / 感受 / 行动）：  
- 3–5 个核心要点：  
- 可用佐证（数据、故事、示例）：  
- 灵感来源（链接 / 人物 / 帖子）：  
- 语气（沉稳 / 辣味 / 个人化 / 理性）：  
- 行动号召（评论 / 私信 / 点击）：  

若用户提供灵感来源但未提供佐证，则创建“佐证占位符”（注明应补充内容），并对主张保持审慎克制。
