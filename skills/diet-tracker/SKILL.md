# 饮食追踪器

该 skill 帮助您跟踪每日饮食，并达成减重目标。

## 使用方法

1.  该 skill 将从 `USER.md` 中读取用户相关信息，以获取：
    *   您的每日热量目标；
    *   您的身高、体重、年龄、性别和活动水平，用于计算 TDEE。

2.  当您提供餐食信息（例如：“我午餐吃了一个三明治”）时，该 skill 将：
    *   识别您餐食中的食物项；
    *   调用 `get_food_nutrition.py` 脚本，从网络获取该食物项的营养信息（热量、蛋白质、碳水化合物、脂肪）；
    *   将餐食信息及营养详情添加至当日记忆文件（memory/YYYY-MM-DD.md）；
    *   计算该餐食的总热量及宏量营养素含量；
    *   更新当日总摄入量及剩余热量预算；
        *   同时根据每日热量摄入预测体重变化。

3.  当您询问剩余热量预算时，该 skill 将：
    *   读取当日记忆文件；
    *   计算截至目前已摄入的总热量；
    *   从您的每日热量目标（见 USER.md）中减去已摄入热量；
    *   报告剩余热量；
        *   同时根据累计的每日热量摄入预测体重变化。

## 脚本

*   `scripts/get_food_nutrition.py`：从网络获取指定食物项的营养信息，并计算 TDEE；
*   `scripts/update_memory.py`：将餐食信息及营养详情更新至当日记忆文件。

## 数据

*   `references/food_database.json`：常见食物及其营养信息的数据库（作为网络不可用时的备用方案）。

## 工作流程

1.  diet-tracker skill 从 `USER.md` 中读取用户相关信息，以获取：
    *   每日热量目标；
    *   身高、体重、年龄、性别及活动水平。活动水平包括：
        *   久坐（几乎不运动或完全不运动）；
        *   轻度活跃（每周轻度运动/体育活动 1–3 天）；
        *   中度活跃（每周中等强度运动/体育活动 3–5 天）；
        *   高度活跃（每周高强度运动/体育活动 6–7 天）；
        *   极度活跃（极高强度运动/体育活动 + 体力劳动工作，或每日两次训练）。
2.  用户提供餐食信息；
3.  skill 识别食物项；
4.  skill 调用 `scripts/get_food_nutrition.py` 获取营养信息；若网络无法获取，则回退使用 `references/food_database.json` 文件；
5.  skill 调用 `scripts/update_memory.py` 更新当日记忆文件；
6.  skill 计算该餐食的总热量及宏量营养素，并更新当日总摄入量；
7.  skill 向用户报告餐食信息、剩余热量预算及预测的体重变化范围。

请务必使用 `exec cat` 命令确认文件类型。
