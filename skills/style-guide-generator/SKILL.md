# 风格指南生成器

## 概述

通过分析用户提供的网址、截图、上传文件及具体需求，自动生成格式专业的网站风格指南与设计系统。输出的 PDF 文档可作为设计与开发团队的唯一可信信息源（single source of truth）。

## 工作流决策树

当用户请求生成风格指南时，请遵循以下决策流程：

1. **收集信息**  
   - 若用户提供网址 → 使用 web_fetch 分析网站  
   - 若用户提供截图/图像 → 分析视觉元素  
   - 若用户提供既有文档 → 提取并结构化信息  
   - 若用户提供信息极少 → 就品牌、目标与需求提出澄清问题  

2. **提取设计元素**  
   - 色彩（主色、辅色、强调色、文字色、背景色、成功色、警告色、错误色）  
   - 排版（字体、字重、字号、行高）  
   - 标志使用规范  
   - 图标风格  
   - 图像偏好  
   - UI 组件模式  
   - 布局与间距系统  
   - 无障碍访问要求  

3. **组织内容**  
   - 遵循标准模板结构（参见“模板结构”章节）  
   - 将提取的信息归入对应章节  
   - 如已提供或可推断，则补充使命/愿景声明  
   - 记录设计原则  
   - 编写组件规格说明  

4. **生成 PDF**  
   - 使用 PDF skill 创建专业文档  
   - 应用统一的格式与排版  
   - 以表格形式呈现色彩方案、排版规格与组件状态  
   - 确保无障碍访问（满足适当对比度）  
   - 添加版本号与最后更新日期  

## 标准模板结构

每份风格指南均须遵循此专业结构（基于行业最佳实践）：

### 1.0 引言  
- 版本号与最后更新日期  
- 编写目的与适用范围说明  
- 目标读者（设计与开发团队）  

### 1.1 使命与愿景  
- 公司使命声明  
- 公司愿景声明  
- 战略定位  

### 1.2 设计原则  
- 4–6 条指导设计决策的核心原则  
- 每条原则含名称与说明  
- 示例：“清晰至上”、“以简驭繁赋能用户”、“一致铸就信任”、“以人为本”  

### 2.0 品牌识别  

#### 2.1 标志使用  
- 主标志规格  
- 留白要求  
- 错误使用示例  
- 最小尺寸要求  
- 色彩变体（全彩、黑色、白色）  

#### 2.2 色彩方案  
- 按角色、色名、HEX 值、RGB 值组织的表格  
- 主色（1–2 种）  
- 辅色（1–3 种）  
- 强调色  
- 文字色  
- 背景色  
- 系统色（成功、警告、错误）  
- 每种色彩组合的无障碍访问备注  

#### 2.3 排版  
- 标题字体规格（H1、H2、H3）  
- 正文字体规格  
- 标注/小字号文本规格  
- 字体族、字重、字号与行高的表格化呈现  
- Web 字体加载考量  
- 备用字体  

#### 2.4 图标  
- 图标风格指南（线性、填充、线宽）  
- 网格系统规格  
- 尺寸变体  
- 使用示例  
- 图标库链接  

#### 2.5 图像  
- 摄影风格指南  
- 插画风格指南  
- 图像处理规范  
- “应做”与“勿做”清单  
- 质量要求  

### 3.0 内容风格指南  

#### 3.1 语气与语调  
- 语气特征（稳定属性）  
- 语调变化（语气如何随情境调整）  
- 不同场景下的示例  

#### 3.2 语法与格式规范  
- 标点规则  
- 大小写标准  
- 语态偏好（主动/被动）  
- 数字格式  
- 日期与时间格式  

### 4.0 UI 组件  

#### 4.1 按钮  
- 状态变体（主、次、辅助、禁用）  
- 尺寸变体  
- 使用指南  
- 代码片段（HTML/CSS）  
- 无障碍访问要求  

#### 4.2 表单  
- 输入框规格  
- 标签位置  
- 验证状态  
- 必填字段标识  
- 错误消息样式  
- 帮助文本格式  

#### 4.3 [其他所需组件]  
- 卡片  
- 模态框  
- 导航  
- 表格  
- 提示/通知  
- 工具提示  
- 徽章  
- 进度指示器  

### 5.0 布局与网格  
- 网格系统规格（列数、沟槽）  
- 响应式断点  
- 间距比例尺（基础单位及倍数）  
- 容器宽度  
- 外边距与内边距规范  

### 6.0 无障碍访问（A11y）  
- WCAG 合规等级（2.1 AA 标准）  
- 色彩对比度要求  
- 替代文本（alt text）指南  
- 键盘导航标准  
- 屏幕阅读器考量  
- 焦点指示器  

### 7.0 资源  
- 设计文件链接（Figma、Sketch、Adobe XD）  
- 图标库位置  
- 插画库位置  
- 字体文件仓库  
- 代码仓库  
- 其他文档  

### 8.0 更新日志  
- 含日期的版本历史  
- 各版本变更摘要  

## 信息提取流程

分析所提供材料时，请系统性提取以下信息：

### 从网址/网站中提取：
1. 使用 web_fetch 获取网站  
2. 分析 HTML/CSS，提取：  
   - 色彩值（background-color、color 属性）  
   - 字体族与排版（font-family、font-size、font-weight）  
   - 间距模式（margin、padding 值）  
   - 组件结构  
3. 注意观察：  
   - 视觉层级  
   - 按钮样式与状态  
   - 表单元素处理方式  
   - 导航模式  
   - 响应式行为（如可观察）  

### 从截图/图像中提取：
1. 通过视觉分析识别色彩方案  
2. 判定排版层级  
3. 记录间距与布局模式  
4. 识别 UI 组件变体  
5. 观察实践中体现的设计原则  

### 从既有文档中提取：
1. 提取使命/愿景声明  
2. 汇总现有品牌指南  
3. 收集色彩规格  
4. 记录当前排版标准  
5. 注明任何现有组件库  

## 专业表格制作

对规格说明使用格式良好的表格。示例格式如下：

**色彩方案表：**  
```
| Role       | Color       | HEX     | RGB           |
|------------|-------------|---------|---------------|
| Primary    | Brand Blue  | #378DFF | 55, 141, 255  |
| Secondary  | Light Blue  | #A5CAFF | 165, 202, 255 |
```  

**排版表：**  
```
| Element | Font Family | Weight  | Size (px) | Line Height |
|---------|-------------|---------|-----------|-------------|
| H1      | Inter       | Bold    | 48        | 1.2         |
| H2      | Inter       | Bold    | 36        | 1.3         |
| Body    | Inter       | Regular | 16        | 1.5         |
```  

**按钮状态表：**  
```
| State     | Appearance              | Usage                          |
|-----------|-------------------------|--------------------------------|
| Primary   | Solid fill, primary     | Main call to action on a page  |
| Secondary | Outline, primary color  | Secondary actions              |
| Tertiary  | Text only              | Less important actions         |
```  

## PDF 生成最佳实践

1. **专业排版：**  
   - 使用一致的标题层级  
   - 各节之间留有恰当间距  
   - 对结构化数据使用表格  
   - 在可能处加入视觉示例  

2. **排版：**  
   - 使用专业字体（Inter、Roboto 或系统字体）  
   - 维持一致的字号层级  
   - 确保足够行高以保障可读性  

3. **色彩使用：**  
   - 以色块形式展示色彩并标注 HEX 值  
   - 确保满足无障碍访问所需的对比度  
   - 清晰说明各色彩的角色  

4. **组织结构：**  
   - 清晰编号各节（1.0、1.1、2.0 等）  
   - 为较长指南添加目录  
   - 合理使用分页符  
   - 添加页码  

5. **无障碍访问：**  
   - 确保文档对屏幕阅读器友好  
   - 使用正确的标题结构  
   - 为图片添加替代文本（alt text）  
   - 最小字号不低于 12pt  

## 处理信息不全情况

当信息缺失或模糊时：

1. **合理推断：**  
   - 从截图中提取色彩方案  
   - 从网站分析中推断排版  
   - 基于视觉模式估算间距  

2. **使用占位符：**  
   - “[插入公司使命声明]”表示未知内容  
   - “[设计文件链接]”表示暂不可用资源  
   - 默认版本号为“1.0”，日期为当前日期  

3. **提出澄清问题：**  
   - “贵公司的使命声明是什么？”  
   - “您已有品牌色吗？还是应从网站中提取？”  
   - “除 WCAG 2.1 AA 外，是否有特定无障碍访问要求？”  

4. **提供模板：**  
   - 为需用户输入的章节提供示例文本  
   - 展示用户应提供内容的格式  
   - 指导用户理想情况下应提供哪些信息
