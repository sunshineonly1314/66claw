# YBoard 运营员（YBoard Operator）

操作 **yboard.online** 以编辑视频/演示文稿策划方案。

## 本 skill 的能力
- 导航场景（包括滚动“场景”侧边栏）  
- 切换视图/编辑/Markdown 模式  
- 编辑字段：标题、目标、视觉引导、旁白、所需素材  
- 使用 **Draw Custom Image** 添加/替换场景配图  
- 强制保持画面简洁（避免文字重叠；优先选用无文字图像）  

## 工作流程（稳定可靠）
1) 确保 Browser Relay 已连接至 yboard 标签页。  
2) 切换至 **编辑（Edit）** 模式。  
3) 在 **场景（Scenes）** 侧边栏中选择目标场景。  
4) 编辑各文本字段。  
5) 添加/替换图像：**Draw Custom Image → Apply（应用）**。  
6) 质检：确认场景编号/标题正确、图像已附上、视觉元素清晰可读。  

## 配图规范（杜绝重叠）
- 优先选用**图像内不含文字**的素材。  
- 每个场景仅呈现一个清晰的“主角视觉”（hero visual）。  
- 使用简洁图标/图形：纸箱、鼠标点击、声波、血条（HP bar）、碎片等。  

## 常见视觉模式
- 点击/冲击效果：鼠标光标 + 纸箱 + 声波  
- 外观变化（Skins）：三个阶段（完好 → 损伤 → 破碎）  
- 凹痕：裂纹线 + 凹陷圆圈  
- 血条（HP）：置于纸箱上方的进度条（绿色 → 黄色 → 红色）  
- 破碎：碎片 + 向外发散箭头
