# 戒除咖啡因

借助循证追踪与个性化减量方案，摆脱咖啡因依赖。

## 功能说明

- **咖啡因摄入追踪**：记录每日来自咖啡、茶、能量饮料、巧克力及膳食补充剂的咖啡因摄入量  
- **减量计划支持**：依据当前摄入水平与目标完成日期，自动生成渐进式减量日程  
- **戒断时间线预测**：按天预估戒断症状强度与持续时间，明确各阶段预期表现  
- **天然能量提升**：推荐替代性专注技巧、运动时机安排及睡眠优化策略  
- **进展里程碑追踪**：全程监测情绪、精力水平、睡眠质量与认知功能变化  

## 使用方法

### 启动戒除或减量
“为我制定一份咖啡因戒除计划” 或 “我想在两周内将咖啡因摄入减少 50%”  
- 确立当前摄入基线  
- 生成个性化减量日程表  
- 设定目标完成日期与阶段性里程碑节点  

### 追踪戒断反应
“记录我今天的咖啡因摄入” 或 “我正头痛且思维迟钝”  
- 按时间戳记录每日摄入量  
- 将症状映射至对应戒断阶段  
- 提供针对性症状缓解策略  

### 查看进展
“我的戒断情况如何？” 或 “我是否按计划推进？”  
- 对比实际减量进度与计划进度  
- 突出显示精力水平变化趋势  
- 显示距离预计完成日的剩余天数  

### 替代能量来源
“我需要不靠咖啡因提神” 或 “除了喝咖啡，我还能做什么？”  
- 推荐天然提神方式：补水、身体活动、营养搭配、接触阳光  
- 建议运动与进餐的最佳时间安排  
- 提供应对能量低谷的快速专注技巧  

### 改善睡眠
“我睡得更好了” 或 “追踪我的睡眠质量”  
- 监测睡眠时长与质量改善情况  
- 关联咖啡因减量与睡眠提升效果  
- 提供强化睡眠改善效果的睡前例行程序建议  

## 戒断时间线

**第 1–3 天：症状高峰期**  
- 头痛（最常见）、疲劳、易怒、注意力难以集中  
- 症状强度在 24–48 小时达峰值  
- 此阶段最为艰难；请合理调整预期，必要时可使用止痛药  

**第 4–7 天：逐步好转期**  
- 头痛开始缓解，精力略有回升  
- “脑雾”持续但已可控  
- 情绪趋于稳定，睡眠深度开始增加  

**第 2 周起：趋于稳定期**  
- 大部分戒断症状基本消失  
- 精力水平稳定于新基准线  
- 睡眠质量显著改善，专注力逐步恢复  
- 完全适应通常需 7–14 天，具体取决于初始摄入量  

## 使用提示

1. **建议在 1–2 周内逐步减量，而非突然停用**——可降低戒断高峰强度达 60–70%  
2. **保持充足饮水并适度活动**——水分与轻度运动可减轻头痛强度，并激发天然能量  
3. **协调生活节奏**——若条件允许，尽量选择工作压力较小的时段启动戒断，更易应对症状  
4. **替换仪式感，而不仅是咖啡因本身**——例如改喝无咖啡因茶替代晨间咖啡，用午后散步替代咖啡休息时间  
5. **所有数据均仅保存于您的设备本地**——您的咖啡因日志、戒断追踪与能量数据永不离开您的设备
