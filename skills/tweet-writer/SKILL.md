# 推文撰写技能（Tweet Writer Skill）

## 概述

本技能可帮助您撰写具备病毒式传播潜力、富有说服力的推文及推文串，并针对 X 平台算法进行优化。它融合了经实践验证的文案写作框架、高转化率钩子（hook）公式，以及实时网络研究能力，使您的内容能精准对标您所在细分领域中已取得成功的范例。

**关键词**：twitter、X、tweets、threads、viral content、social media、engagement、hooks、copywriting

## 工作流程

### 第一阶段：细分领域研究（至关重要）

在撰写任何一条推文之前，您必须首先针对用户所处的具体细分领域开展爆款案例研究。

**研究步骤：**

1. **明确细分领域/主题** —— 用户正在撰写哪方面的内容？
2. **搜索爆款范例** —— 使用 WebSearch 查找以下内容：
   - `"[niche] viral tweet examples"`
   - `"[niche] twitter thread went viral"`
   - `"[topic] best performing tweets"`
   - `site:twitter.com OR site:x.com "[niche keyword]" high engagement`
3. **分析共性模式** —— 提取以下要素：
   - 成功的钩子风格
   - 内容结构
   - 语调与声音（tone and voice）
   - 所使用的具体数字/成果数据
   - 推动互动的行动号召（CTA）
4. **记录研究洞见** —— 在动笔前完成一份简明分析报告

**示例研究提示词（Research Prompt）：**  
```
Searching for: "SaaS founder viral tweets"
              "startup advice twitter thread viral"
              "tech entrepreneur best tweets engagement"
```

### 第二阶段：推文创作

运用下方框架，参照成功范例来构建内容。

## X 平台算法（2026 版）

理解算法所奖励的行为至关重要：

### 互动价值层级（由高到低）
1. **回复（Replies）** —— 权重最高的信号
2. **引用式转发（Quote tweets）** —— 高价值信号，表明您的内容激发了对话
3. **收藏（Bookmarks）** —— 强烈的价值信号
4. **转发（Retweets）** —— 传播放大信号
5. **点赞（Likes）** —— 基础互动指标

### 时间敏感性
- **首小时极为关键** —— 若 60 分钟内未能获得初始热度，后续触达量将显著下降
- **黄金发布时间**：工作日东部时间上午 9–11 点、晚上 7–9 点；周末为上午 9–11 点
- **内容新鲜度优先** —— X 平台高度青睐最新发布的内容

### 用户停留时长（Dwell Time）
X 平台会追踪用户在您的内容上停留的时间，停留越久，潜在覆盖范围越大。
- 推文串（threads）天然有助于延长停留时长
- 视觉化内容（如图片、视频）可更长时间地留住用户视线
- 引人入胜的钩子能有效“截停”用户滑动行为

### 格式增益效应（Format Boosts）
- **原生视频（Native video）**：优先级高于外部链接
- **图片/轮播图（Images/carousels）**：互动率约为纯文字推文的 2 倍
- **推文串（Threads）**：互动率约为单条推文的 3 倍
- **投票（Polls）**：参与度信号极强

### 应当避免的行为
- **外部链接（External links）**：严重受罚（尤其对非 Premium 账户）
- **泛泛而谈的内容（Generic content）**：缺乏差异化 = 无法获得曝光
- **直接索求互动（Asking for engagement）**：“请点赞并转发”类表述会损害内容触达

## 钩子公式（最核心要素）

您的钩子决定了推文 80–90% 的成败。您仅有约 1 秒时间来阻止用户滑动。

### 大胆断言式（The Bold Statement）  
```
"Nobody talks about this, but..."
"Unpopular opinion: [controversial take]"
"Everything you've been told about [X] is wrong."
"[Common belief] is a myth. Here's the truth:"
```

### 具体成果式（The Specific Result）  
```
"I [specific result] in [specific timeframe]. Here's how:"
"[Number] [achievement] in [timeframe]. The breakdown:"
"From [bad state] to [good state] in [time]. Thread:"
```  
**示例**：“我在 90 天内从 0 增长至 5 万粉丝。这是完整操作手册：”

### 好奇缺口式（The Curiosity Gap）  
```
"I found a [adjective] [topic] hack that no one talks about..."
"The one thing [type of person] gets wrong about [topic]"
"Why most people fail at [X] (and how to fix it)"
```

### 提问式钩子（The Question Hook）  
```
"Want to know the real secret to [X]?"
"What if everything you knew about [X] was wrong?"
"Ever wonder why [common frustration]?"
```

### 故事式钩子（The Story Hook）  
```
"3 years ago I was [bad state]. Today I [good state]."
"I almost quit [X]. Then this happened:"
"The story of how I [achievement] (with $0 budget):"
```

### 打断惯性式（The Pattern Interrupt）  
```
"Everyone says [X]. They're wrong."
"Stop doing [common practice]. Do this instead:"
"Delete [common thing]. Here's why:"
```

### 清单承诺式（The List Promise）  
```
"[Number] [things] that will [benefit] (thread):"
"[Number] lessons from [experience/achievement]:"
"The [number] [category] I wish I knew earlier:"
```  
**示例**：“上周为我节省 20+ 小时的 7 款 AI 工具：”

## 易于走红的推文格式

### 格式 1：清单体（Listicle，互动率最高）  
```
Hook: "[Number] [things] that [benefit]:"

1. [Item] — [Brief explanation]
2. [Item] — [Brief explanation]
...
[CTA or summary]
```

### 格式 2：反共识观点（Contrarian Take）  
```
Hook: "[Popular belief] is wrong."

Here's why: [2-3 sentences of reasoning]

What actually works: [Your alternative]
```

### 格式 3：前后对比（Before/After）  
```
[Time period] ago: [Bad state]
Today: [Good state]

The difference? [One key insight]
```

### 格式 4：方法论框架（The Framework）  
```
Hook: "The [Name] Framework for [Result]:"

Step 1: [Action]
Step 2: [Action]
Step 3: [Action]

[Optional: brief expansion on each]
```

### 格式 5：“填空式”（Fill in the Blank）  
```
"The most underrated skill for _____ is _____."
"If I could only use one tool for [X], it would be _____."
```  
*可激发海量回复*

### 格式 6：普适体验（Universal Experience）  
```
"When you finally [common experience/realization]"
"Why does nobody talk about [shared frustration]?"
"That moment when [relatable situation]"
```

## 推文串结构（7 条推文的黄金组合）

### 推文串模板

**第 1 条（钩子）**：  
- 呈现最具冲击力的洞见或成果  
- 包含具体数字  
- 明确提示为推文串：“🧵” 或 “（thread）”

**第 2 条（背景）**：  
- 对钩子做进一步展开  
- 阐明此事为何重要  
- 进一步激发好奇心  

**第 3–6 条（核心价值）**：  
- 每条仅传递一个关键洞见  
- 使用编号格式（1/，2/ 等）  
- 每隔 3–4 条插入视觉分隔（如图片、图表）  
- 每条推文本身应具备独立价值  

**第 7 条（衔接/总结）**：  
- 归纳核心要点  
- 关联更广泛的应用场景  

**第 8 条（行动号召 CTA）**：  
- 提出问题（激发回复）  
- 引用您的首条推文（驱动引用式转发）  
- 引导至个人主页/邮件列表等  

### 推文串写作守则  
1. 每条推文都必须“赢得”用户阅读下一条的意愿  
2. 杜绝冗余内容——每个字都须承载信息重量  
3. 句子简短（每条推文不超过 250 字符）  
4. “您的文字读起来应如顺滑斜坡般自然推进”  
5. 为推文编号（如 2/12、3/12 等）

## 推文专用文案框架

### PAS（问题 → 放大痛点 → 解决方案）  
**最可靠的互动提升公式**  

```
[Problem]: You're [specific situation]
[Agitate]: And it's costing you [consequence]
[Solution]: Here's what works: [your answer]
```  

### AIDA（注意 → 兴趣 → 欲望 → 行动）  
**最适合推广类内容**  

```
[Attention]: Hook that stops scroll
[Interest]: "Here's what most people don't realize..."
[Desire]: "Imagine if you could [benefit]"
[Action]: "DM me [X] to get started"
```  

### BAB（之前 → 之后 → 桥梁）  
**最适合讲述转变历程的故事**  

```
[Before]: I was [bad state]
[After]: Now I'm [good state]
[Bridge]: The difference? [Your insight/solution]
```

## 说服力原则  

应用以下原则，让任意推文更具感染力：

**具体性（Specificity）** —— “提升 23%” 优于 “大幅提升”  
- 数字增强可信度  
- 明确的时间范围制造紧迫感  
- 细节令主张更真实可信  

**社会认同（Social Proof）** —— “500+ 客户” 优于 “众多客户”  
- 真实用户的成果反馈  
- 用户数/粉丝数等量化指标  
- 可识别的姓名/品牌背书  

**好奇缺口（Curiosity Gap）** —— 制造信息不对称  
- 暗示有价值信息但不完全揭示  
- 承诺具体成果  
- 使用“大多数人忽略的关键点是……”等句式  

**争议性（Controversy）** —— 挑战既有认知  
- “主流观点是错误的”  
- 反共识观点易获互动  
- 避免冒犯性表达，追求启发思考  

**共鸣感（Relatability）** —— 共享体验引发共振  
- “当你意识到……”  
- 普遍存在的挫败感  
- 共同经历的成长节点

## 增长技巧  

### 30 天子主题策略  
在您的细分领域中选定一个极其聚焦的子主题，连续 30 天只围绕该主题发布内容。  

**示例**：若您从事营销工作，整月专注“邮件主题行”这一单一主题。  

效果：X 平台算法将您归类为该子主题的权威专家。  

### 回复导向策略  
优先追求回复量，而非点赞或转发。  
- 主动提问  
- 发布“填空式”推文  
- 抛出有争议的观点（hot takes）以激发讨论  
- 算法将您识别为“对话发起者”  

### 互动窗口期  
- 每日发布 3–5 条推文  
- 每日与 20+ 账户进行有意义的互动回复  
- 在自己推文发布的首小时内及时回复评论  

### 80/20 法则  
- 80% 内容为纯粹价值输出（无推广）  
- 20% 为推广类内容  
- 价值先行建立信任，最终实现转化

## 推文长度指南  

- **单条推文**：110 字符以内表现最佳  
- **推文串中的单条推文**：每条不超过 250 字符  
- **为何短文本更有效**：便于快速扫读、为引用式转发留出空间、适配移动端浏览  

---

## 应规避的常见陷阱  

**过于泛泛而谈** —— “成功小贴士” → “本周助我拿下 10 场会议的 3 封冷邮件模板”  

**缺乏钩子** —— 以背景信息开场，而非以冲击性结果开场  

**直接索求互动** —— “请点赞并转发！”会损害触达  

**主推文中嵌入外部链接** —— 应将链接置于评论区  

**未使用具体数字** —— “我快速增长” vs “我在 63 天内增长了 12,847 名粉丝”  

**过度推销感** —— 价值占比过低，令人感觉纯属广告  

**缺少行动号召（CTA）** —— 推文串结尾未给出清晰下一步指引

## 本技能使用方式  

当用户请求推文撰写协助时：  

1. **先索取背景信息**：  
   - 所属细分领域/主题？  
   - 核心目标是什么？（提升互动、涨粉、转化等）  
   - 关键信息/洞见是什么？  
   - 是否有需特别强调的具体成果或数字？  

2. **开展研究阶段（务必使用 WebSearch）**：  
   - 搜索其细分领域内的爆款范例  
   - 识别成功模式  
   - 记录有效的钩子类型与结构  

3. **草拟备选方案**：  
   - 提供 2–3 种不同风格的钩子变体  
   - 选用合适框架（PAS、AIDA 等）  
   - 尽可能嵌入具体数字  

4. **优化调整**：  
   - 核查字符数  
   - 强化钩子力度  
   - 添加互动驱动元素或 CTA  

5. **提供多样化版本**：  
   - 单条推文版  
   - 推文串版（如适用）  
   - 多种钩子变体（用于 A/B 测试）
