# AWS 基础设施

## 概述
使用本地 AWS CLI 回答有关 AWS 资源的问题。默认采用只读查询。仅在用户明确请求变更且完成显式确认后，才可提议或执行写入/破坏性操作。

## 快速开始
1. 根据环境变量或 `~/.aws/config` 确定配置文件（profile）与区域（region）。  
2. 从身份信息入手：  
   - `aws sts get-caller-identity`  
3. 使用只读服务命令回答问题。  
4. 若用户请求变更，请先完整列出确切 CLI 命令，并在执行前征得用户确认。

## 安全规则（必须遵守）
- 除非用户明确请求变更 **且** 显式确认，否则所有操作均视为 **只读**。  
- 对任何潜在破坏性变更（删除 / 终止 / 销毁 / 修改 / 扩容 / 账单 / IAM 凭据），均须执行确认步骤。  
- 如可用，优先使用 `--dry-run`，并在执行前向用户展示操作计划。  
- 绝不泄露或记录任何密钥（访问密钥、会话令牌）。

## 任务指南（常见请求类型）
- **资产清点 / 列表查询**：使用 `list` / `describe` / `get` 命令。  
- **健康状况 / 错误排查**：使用 CloudWatch 指标/日志查询。  
- **安全检查**：IAM 权限、S3 公共访问权限、安全组暴露面、KMS 密钥使用情况。  
- **成本分析**：使用成本探索器 / 账单查询（仅限只读）。  
- **变更操作**：展示确切 CLI 命令，并要求用户确认。

## 区域与配置文件处理
- 若用户指定了区域或配置文件，请遵从其指定。  
- 否则，依次尝试使用已设置的 `AWS_PROFILE` / `AWS_REGION`，再回退至 `~/.aws/config`。  
- 当结果具有区域限定性时，应明确说明所使用的区域。
