# 新闻简报摘要（Newsletter Digest）

驯服你的收件箱。借助 AI 获取新闻简报与文章的摘要，确保你只阅读真正重要的内容。

## 功能说明

处理用户转发的新闻简报及链接文章，提取关键洞见，生成优先级排序的阅读清单，并随时间推移学习你的兴趣偏好。永不错过重要内容，也永不淹没于信息噪音之中。

## 使用方法

**汇总内容：**  
```
"Summarize this newsletter" [forward/paste]
"Digest https://article-url.com"
"What's important in my newsletters today?"
```

**构建阅读清单：**  
```
"Add to reading list: [url]"
"What's on my reading list?"
"Clear completed reads"
```

**获取洞见：**  
```
"Key takeaways from tech newsletters this week"
"Trending topics across my subscriptions"
"Compare viewpoints on [topic]"
```

**管理偏好设置：**  
```
"I'm interested in AI, fintech, productivity"
"Skip newsletters about marketing"
"Prioritize Stratechery"
```

## 主要特性

- **智能摘要**：提炼核心要点，而非简单缩略原文  
- **主题提取**：自动打标签并分类  
- **跨源关联**：在不同来源间发现相关内容  
- **稍后阅读**：将文章加入队列，留待专注阅读时段处理  

## 使用提示

- 将新闻简报转发至 Clawd 进行处理  
- 说 “brief” 可获得两句话的简明摘要；说 “detailed” 则触发深度分析  
- 提问 “what did I miss this week?” 可获取本周补漏式摘要  
- 支持任意文本内容——不仅限于新闻简报
