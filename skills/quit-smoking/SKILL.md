# 戒烟

借助持续追踪、烟瘾应对支持与健康恢复路线图，迈向无烟生活。

## 功能说明

- **戒烟追踪**：设定戒烟起始日，持续记录无烟天数，数据持久保存  
- **烟瘾应对支持**：烟瘾来袭时提供即时支持——替代方案、呼吸练习、激励话语  
- **健康获益时间线**：直观呈现戒烟带来的医学益处（20 分钟内心率与血压下降，48 小时内味觉嗅觉改善，数月内肺功能提升）  
- **进展里程碑**：庆祝戒烟 1 天、1 周、1 个月、3 个月、6 个月及 1 年等关键节点  
- **节省金额追踪**：基于常规单包价格，实时计算您已节省的金钱总额  

## 使用方法

**启动戒烟**
- “我今天开始戒烟”  
- “将我的戒烟日期设为 [日期]”  
- “请帮助我戒掉香烟”  

**应对烟瘾**
- “我此刻有烟瘾”  
- “请帮我度过这次烟瘾”  
- “除了吸烟，我还能做什么？”  
- “请给我一个呼吸练习”  

**追踪进展**
- “我已多少天不吸烟？”  
- “显示我的戒烟天数”  
- “我的戒烟里程碑是什么？”  
- “我已节省多少钱？”  

**健康获益**
- “戒烟能带来哪些健康益处？”  
- “我的肺部何时能恢复？”  
- “烟瘾要多久才会消失？”  

**节省金额**
- “截至目前我已节省多少？”  
- “用这些钱我能买些什么？”  
- “请计算我的戒烟储蓄总额”  

## 健康时间线

| 里程碑 | 健康获益 |
|---------|-----------|
| **20 分钟** | 心率与血压开始下降 |
| **8 小时** | 血氧水平恢复正常，血液中尼古丁开始清除 |
| **24 小时** | 心脏病发作风险开始降低 |
| **48 小时** | 味觉与嗅觉改善，神经末梢开始修复 |
| **2 周** | 血液循环与肺功能开始改善 |
| **1 个月** | 皮肤状态改善，咳嗽症状减轻 |
| **1 年** | 冠心病风险降低一半，肺功能提升 30% |

## 使用提示

- **记录每一次胜利**：每一天无烟都是胜利。您的连续天数就是最强动力源。  
- **替换仪式感**：吸烟是一种习惯。烟瘾来袭时，可用嚼口香糖、喝水、散步或深呼吸替代。  
- **告知他人**：责任感有助成功。告诉亲友您正在戒烟——他们将给予您支持。  
- **安然渡过烟瘾**：多数烟瘾持续 3–5 分钟。使用计时器、专注呼吸、耐心等待其自然消退。  
- **所有数据均仅保存于您的设备本地**：您的戒烟历程、烟瘾记录与健康里程碑仅存储于您的设备——无云端同步，无任何追踪，完全私密。
