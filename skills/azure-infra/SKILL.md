# Azure 基础设施（Azure Infra）

## 概述
使用本地 Azure CLI 回答有关 Azure 资源的问题。默认仅执行只读查询；仅在用户明确请求变更并确认后，才提出或执行写入/破坏性操作。

## 快速入门
1. 确保已登录： `az account show`（若未登录，请运行 `az login --use-device-code`）。
2. 若存在多个订阅，请提示用户选择其一；否则使用默认订阅。
3. 使用只读命令回答问题。
4. 若用户请求变更，请明确列出将执行的确切命令，并在运行前请求确认。

## 安全规则（必须遵守）
- 除非用户明确请求变更且完成确认，否则所有操作均视为 **只读**。
- 对任何潜在破坏性变更（删除/终止/销毁/修改/扩缩/账单/ IAM 凭据等），均须要求确认步骤。
- 在可用时优先使用 `--dry-run`，并在执行前展示操作计划。
- 绝不泄露或记录任何密钥（密钥、客户端密钥、令牌等）。

## 任务指南（常见请求类型）
- **资产清点 / 列表查询：** 使用 `list`/`show`/`get` 等命令。
- **健康状态 / 错误排查：** 使用 Azure Monitor 的指标与日志查询。
- **安全检查：** 检查 RBAC 角色、存储账户的公共访问设置、网络安全组（NSG）暴露情况、密钥保管库访问权限等。
- **成本分析：** 使用成本管理功能（仅限只读）。
- **变更操作：** 明确展示对应 CLI 命令，并要求用户确认。

## 订阅与租户处理
- 若用户指定了订阅或租户，请予以遵循。
- 否则使用 `az account show` 中的默认订阅。
- 当结果按订阅范围限定时，需明确说明所用订阅。
