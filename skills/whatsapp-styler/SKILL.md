# WhatsApp 样式器（WhatsApp Styler）

本 skill 定义了 WhatsApp 的严格格式化规则，确保用户看到的是干净、带样式的文本，而非原始 Markdown 符号。

## 核心语法规则

1. *加粗*：使用单个星号包围文字：`*texto*`。**切勿**使用双星号 `**`。
2. _斜体_：使用单个下划线包围文字：`_texto_`。
3. ~删除线~：使用波浪线包围文字：`~texto~`。
4. `Monospace`：使用三个反引号：``` texto ```（适合代码或技术标识符）。
5. *项目符号列表*：使用单个星号后接空格：`* Item`。
6. *编号列表*：使用标准数字：`1. Item`。
7. *引用*：使用尖括号：`> texto`。

## 禁止使用的格式（请勿使用）

- 不支持标题（`#`、`##`、`###`）。请改用 *加粗大写*。
- 不支持 Markdown 表格。请使用项目符号列表呈现结构化数据。
- 不支持水平分隔线（`---`）。如确需分隔，可使用一行下划线 `__________`。
- 避免嵌套加粗/斜体符号，以防原始字符意外显示。

## 目标
实现“人对人”（Human-to-Human）风格——专业但简洁。
