# WhatsApp 样式器（WhatsApp Styler）

该 skill 定义了 WhatsApp 消息的严格格式规范，确保用户看到的是干净、有样式的文本，而不会出现原始 Markdown 符号。

## 核心语法规则

1. *加粗*：使用单个星号包裹文字：`*texto*`。**切勿**使用双星号 `**`。  
2. _斜体_：使用单个下划线包裹文字：`_texto_`。  
3. ~删除线~：使用波浪线包裹文字：`~texto~`。  
4. `Monospace`：使用三个反引号：``` texto ```（适用于代码或技术标识符）。  
5. *项目符号列表*：使用单个星号加空格：`* Item`。  
6. *编号列表*：使用标准数字：`1. Item`。  
7. *引用*：使用尖括号：`> texto`。  

## 禁用格式（严禁使用）

- 禁用标题（`#`、`##`、`###`）；请改用 *全大写加粗* 替代。  
- 禁用 Markdown 表格；请使用项目符号列表呈现结构化数据。  
- 禁用水平分割线（`---`）；如需分隔，可用一行下划线替代 `__________`。  
- 禁用嵌套加粗/斜体符号，以防原始字符意外暴露。  

## 目标  
追求“人对人”（Human-to-Human）风格——专业但简洁。
