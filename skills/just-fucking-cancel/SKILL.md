# just-fucking-cancel

分析交易记录、归类订阅服务、生成 HTML 审计报告、辅助取消操作。

## 触发条件
- “取消订阅”、“审计订阅”  
- “查找周期性扣款”、“我在为哪些服务付费”  
- “订阅审计”、“清理订阅”

## 工作流

### 1. 获取交易 CSV 文件
向用户索取银行/信用卡 CSV 导出文件。常见来源包括：
- Apple Card：钱包 App → 卡片余额 → 导出  
- Chase：账户页面 → 下载活动记录 → CSV  
- Mint：交易页面 → 导出  

### 2. 分析周期性扣款
读取 CSV，识别周期性模式：
- 同一商户、金额相近、按月/年频次发生  
- 标记类订阅扣款（流媒体、SaaS、会员服务等）  
- 记录扣款频次与年度总费用  

### 3. 与用户协同归类
针对每项订阅，向用户询问归类方式：
- **取消** —— 立即停止  
- **调查** —— 尚未决定（不确定、受合同约束）  
- **保留** —— 主动选择，继续付费  

每次批量询问 5–10 项，避免信息过载。

### 4. 生成 HTML 审计报告
复制 [template.html](assets/template.html) 模板并填充内容：
- 更新页眉摘要：
  - 范围说明行：“发现 N 项订阅 · N 笔交易”  
  - 分类汇总：“已取消 N 项 · 保留 N 项”  
  - 节省金额：年度总额（显著显示），括号内注明月均节省额  
  - 时间戳：当前日期  
- 将条目添加至对应分区（已取消 / 待决策 / 已保留）  
- 包含用户回复中的备注信息  

HTML 注释中列出了各表格行的模板结构。

### 5. 取消订阅
当用户勾选项目并点击浮动按钮复制时，将粘贴：
`Cancel these: Service1 ($XX), Service2 ($XX)...`

对每项服务执行以下操作：
1. 查阅 [common-services.md](references/common-services.md) 获取取消 URL  
2. 使用浏览器自动化导航至页面并完成取消  
3. 更新 HTML 表格行状态为“已取消”，并标注日期  

## HTML 结构

三个分区，空时自动隐藏：
- **已取消**（绿色徽章，文字加删除线）—— 已完成项，体现成果  
- **待决策**（橙色徽章）—— 含复选框，供用户选择是否取消  
- **已保留**（灰色徽章）—— 无复选框，仅作参考  

功能特性：
- 勾选任意项目后，浮动复制按钮即出现  
- 隐私开关可模糊服务名称  
- 点击分区标题可展开/收起  
- 支持深色模式  

## 取消技巧

针对难以取消的服务，请参阅 [common-services.md](references/common-services.md)：
- 50+ 项服务的直达取消 URL  
- 暗黑模式警告（如健身房合同、仅限电话取消）  
- 应对挽留话术的标准应答  
- 信用卡争议备用方案  

## 隐私声明

所有数据均保留在本地。交易 CSV 文件仅在当前会话中进行分析。
