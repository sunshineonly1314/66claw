# 钱包 👛

统一的数字钱包管理接口。

## 功能特性

- 多币种支持
- 余额追踪
- 交易历史
- 收付款功能
- 钱包备份与恢复

## 支持的钱包类型

- 加密货币钱包
- 数字支付钱包
- 硬件钱包集成

## 使用示例

```
"Show all my wallets"
"What's my total balance?"
"Transfer funds between wallets"
```
