# 晨间例行程序

赢下清晨，便赢下全天。

## 功能说明

“晨间例行程序” skill 将您一天最初的几个小时转化为一套结构清晰、可追踪的系统，并随时间推移持续产生复利效应。

- **习惯清单**：定义您的核心晨间习惯，并在完成时逐项勾选
- **时间追踪**：查看每项习惯耗时及您通常完成整套例行程序的时间点
- **连续打卡追踪**：通过每日打卡计数建立动力——见证您的坚持力稳步提升
- **适应性建议**：基于您的使用数据，获得哪些习惯已稳固养成、哪些需调整优化的洞察

## 使用方式

**启动例行程序**  
```
"start my morning routine"
"begin my routine"
"morning routine go"
```  
启动您的习惯清单。Clawd 将引导您逐项完成各项习惯，并提供时间提醒。

**勾选单个习惯**  
```
"I did meditation"
"hydration complete"
"movement done"
"planning finished"
```  
将某项习惯标记为已完成。Clawd 将记录完成时间并存档该操作。

**例行程序状态**  
```
"how's my routine"
"what's left"
"routine progress"
"show me what's next"
```  
获取当前例行程序的实时快照——已完成几项习惯、剩余几项未完成。

**修改例行程序**  
```
"add yoga to my routine"
"remove morning news"
"change routine"
"swap habit"
```  
即时自定义习惯内容。Clawd 将自动保存更改，并立即更新您的清单。

**回顾打卡记录**  
```
"show my streak"
"how many days"
"consistency report"
"routine history"
```  
查看您当前的连续打卡天数、历史最长打卡纪录，以及随时间变化的一致性指标。

## 核心组成要素

最高效的晨间例行程序通常包含以下要素：

- **起床时间**：固定起床时间，为其余所有事项奠定基础  
- **补水**：清晨第一杯水，激活身体系统  
- **运动**：10–20 分钟拉伸、散步或锻炼  
- **正念练习**：冥想、书写日记或呼吸训练  
- **日程规划**：回顾当日安排，明确三项关键优先事项  
- **暂离手机**：核心例行程序完成前，请勿触碰手机  

请从上述模块中构建您的专属例行程序。起步阶段建议仅选择 2–3 项习惯；待其稳定后，再逐步增加。

## 实用提示

- **坚持比完美更重要。** 5 天完成 80% 的例行程序，远胜于 2 天做到 100%。连续打卡靠的是“到场”，而非“完美”。  
- **习惯串联执行。** 例如：刷牙 → 喝水 → 冥想，形成触发链。前一项习惯自然带动下一项。  
- **测算例行程序总耗时。** 明确它实际需要多久。预留缓冲时间，避免匆忙——仓促的清晨会引发一整天的节奏紊乱。  
- **按周复盘，而非每日纠结。** 每周集中查看一次打卡记录与适应性数据。每日过度关注反而扼杀动力。  
- **所有数据均本地存储于您的设备。** 您的例行程序数据永不离开您的终端设备。无云端同步、无行为追踪、无第三方介入——只有您与您的习惯。
