# publisher

**面向 Clawdbot skills 的专业文档编写与发布工具**

一键生成面向用户采纳优化的 README，并发布至 GitHub 与 ClawdHub。

---

## ⚠️ 要求

- bash
- `jq`（用于 JSON 解析）
- `gh` CLI（执行 GitHub 操作）
- `clawdhub` CLI（执行发布操作）
- git

---

## 📋 功能说明

自动化完成整个发布工作流：

### 文档生成
1. 读取您的 SKILL.md，理解该 skill 的功能；
2. 运用经验证的模式生成 3 种一行式描述选项；
3. 按照 GitHub 最佳实践生成 README：
   - 开篇直击问题与解决方案；
   - 采用倒金字塔结构；
   - 使用 Emoji 标题提升可扫视性；
   - 关键成果加粗显示；
   - 文本高亮比例低于 15%；
4. 使用选定的描述更新 SKILL.md 前置元数据。

### 发布
5. 创建 GitHub 仓库（如尚不存在）；
6. 将代码推送至 GitHub；
7. 使用自动检测到的版本号发布至 ClawdHub。

---

## 🚀 安装方法

```bash
clawdhub install skill-publisher
```

---

## 💡 使用方法

```bash
cd ~/clawd/skills/your-skill
skill-publisher
```

脚本将执行以下操作：
1. 展示 3 种一行式描述选项（可任选其一或自定义）；
2. 生成 README 预览；
3. 请求用户确认；
4. 发布至 GitHub 与 ClawdHub。

---

## 🎯 一行式描述生成模式

该工具基于三种经验证的模式生成选项：

### 模式 A：持续性收益
```
Keep [thing] [desired state] [timeframe]
```
示例：“全天候保持您的 Claude 访问令牌新鲜有效”

### 模式 B：问题消除
```
[Do thing] without [pain point]
```
示例：“构建跨设备工具，无需硬编码路径”

### 模式 C：自动化
```
Automatically [action] [thing] [when]
```
示例：“在令牌过期前自动刷新”

---

## 📚 生成的 README 结构

遵循 GitHub 文档最佳实践框架：

### 必备章节（首屏可见区域）
- 标题 + 副标题
- **问题所在：**（一句话）
- **本工具：**（一句话）
- 📋 要求
- ⚡ 功能说明（优先呈现成果，再列具体功能）
- 🚀 安装方法
- 🔧 工作原理（先讲结果，再讲过程）

### 可选章节（可折叠）
- 配置选项
- 故障排查
- 开发者指南
- 实现细节

## 🔧 工作原理

### 第一阶段：分析
- 读取 SKILL.md 前置元数据（如存在）；
- 提取关键信息：名称、描述、要求；
- 解析脚本以识别依赖项。

### 第二阶段：一行式描述生成
分析您的 SKILL.md 描述，生成 3 种选项：
- 模式 A：持续性收益格式；
- 模式 B：痛点消除格式；
- 模式 C：自动化格式。

向您展示全部 3 种选项，供您选择或自定义。

### 第三阶段：README 生成
使用来自 `~/clawd/templates/README-template.md` 的模板：
- 填充标题、问题、解决方案；
- 从 SKILL.md 中提取要求；
- 基于描述生成“功能说明”部分；
- 创建安装步骤；
- 构建“工作原理”部分并附带示例。

### 第四阶段：发布
1. 检查 `gh` CLI 是否已安装（缺失时提供配置引导）；
2. 从 VERSION 文件读取版本号；
3. 使用 `gh repo create` 创建 GitHub 仓库；
4. 提交并推送全部文件；
5. 使用 `clawdhub publish` 发布至 ClawdHub。

## ⚙️ 配置

无需任何手动配置。该工具自动从以下文件中检测全部所需信息：
- `SKILL.md`（名称、描述、要求）；
- `VERSION`（版本号）；
- `scripts/`（代码示例、依赖项）。

## 🐛 故障排查

### “gh: command not found”

请安装 GitHub CLI：
```bash
brew install gh
gh auth login
```

### “SKILL.md not found”

请创建最简 SKILL.md：
```markdown
---
name: your-skill
description: Brief description of what it does
---

# your-skill

More details about your skill here.
```

### “VERSION file not found”

请创建 VERSION 文件：
```bash
echo "1.0.0" > VERSION
```
