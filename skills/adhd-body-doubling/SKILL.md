# ADHD 身体共在技能 🐱⚡

**ADHD-founder.com 生态系统组成部分**  
*“为 ADHD 大脑打造的德国式工程”*

---

## 本技能的功能

为 ADHD 创始人提供朋克风格的身体共在会话，包括：
- ⚡ 在你无法启动时助你迈出第一步  
- 🎯 提供无羞耻感的问责机制  
- 🧠 将任务拆解为微小步骤  
- 🏆 庆祝每一次启动，而不仅限于完成  
- 💼 聚焦业务成果，而非单纯任务清单  

## 核心理念

**“启动 > 完成”** — 每一次尝试都值得肯定  
**“无羞耻区”** — 困难是数据，而非失败  
**“ROI 优先”** — 我们衡量的是影响力，而非工时  
**“适配你的节奏”** — 我们为你调整，而非让你适应系统  

## ADHD 创始人专属差异点

本技能专为 **50 岁以上创始人** 设计，他们已厌倦：
- ✗ 泛泛而谈的效率建议  
- ✗ 华而不实的生活小技巧  
- ✗ 满是心理学术语的表达方式  
- ✗ 盲目鼓吹“努力文化”的风气  

**这是系统，而非零散技巧。**

## 使用方式

### 启动会话
```
/body-doubling start [duration]
```  
示例：`/body-doubling start 2h` 启动一场 2 小时专注会话  

### 会话进行中
- 每隔 25–50 分钟触发一次 **进度检查提示**  
- 卡住时提供 **微任务**  
- 需要重启时启用 **多巴胺菜单**  
- 彻底阻塞时启动 **紧急重置协议**  

### 结束会话
```
/body-doubling done
```  
自动触发会话复盘，并庆祝你已完成的成果。

- 从每次会话中学习  
- 在无愧疚感的前提下持续改进  

### 🔄 “推翻原计划”按钮
- 原计划失效？快速重建  
- 无需羞愧，只需转向

## 最佳实践

1. **坦诚相告** — 若对你撒谎，我们将无法提供有效帮助  
2. **从小起步** — 25 分钟本身就是一次有效会话  
3. **聚焦影响力** — 关注成果，而非工时  
4. **接纳不完美** — 部分会话优于完全缺席  
5. **积极互动** — 你参与越深入，效果越显著
