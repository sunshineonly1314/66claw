# 戒除电子烟

借助持续的戒断天数追踪、渴求管理以及基于科学依据的健康恢复里程碑，摆脱尼古丁成瘾。

## 功能说明

- **戒断状态追踪**：记录您的正式戒断起始日期，并实时计算您已保持无尼古丁状态的天数
- **渴求管理**：当尼古丁渴求来袭时，即时提供应对工具与技巧——呼吸练习、延迟策略、渴求记录功能
- **健康时间线**：展示戒断后20分钟、24小时、48小时、1周、1个月及3个月时，您身体内正在发生的各项变化
- **进展仪表盘**：以可视化方式呈现已戒断天数、节省金额，以及相较于持续使用电子烟所付出的成本而获得的健康收益

## 使用方法

**记录戒断起始日期**  
- 当您准备好开始时，设定您的正式戒断起始日期  
- 本 skills 将自动从该时刻起启动追踪  
- 如需重新开始，可随时重新计算  

**应对尼古丁渴求**  
- 当尼古丁渴求出现时，请求即时响应  
- 获取快速呼吸技巧、延迟策略（如5–10分钟的替代活动）或即刻激励语句  
- 记录每次渴求发生的时间点，以识别规律与诱因  

**查看进展**  
- 查看当前戒断天数/小时数  
- 对比昨日、上周、首月等不同阶段，直观了解自身进步  
- 在达成关键里程碑（如7天、30天、100天）时，接收庆祝提示  

**健康恢复进程**  
- 跟踪您身体真实的恢复时间线  
- 查看各项改善指标：血氧水平恢复正常、心率趋于平稳、味觉与嗅觉逐步恢复  
- 将生理层面的积极变化与下一阶段的持续动力相联结  

**节省金额统计**  
- 基于您日常电子烟使用习惯，追踪未用于电子烟消费的金额  
- 查看累计节省总额——财务自由的可视化证明  
- 将每日/每周/每月节省金额与其他生活目标进行横向对比  

## 健康时间线

| 里程碑 | 身体正在发生的变化 |
|-----------|------------------|
| **20分钟** | 血压与心率回落至正常水平 |
| **24小时** | 一氧化碳完全排出体外；肺功能开始改善 |
| **48小时** | 神经末梢开始再生；味觉与嗅觉逐步恢复 |
| **1周** | 呼吸更轻松；尼古丁戒断症状达峰值后逐渐消退；睡眠趋于规律 |
| **1个月** | 肺功能提升30%；血液循环增强；精力水平上升 |
| **3个月** | 肺活量最多提升10%；咳嗽减少；皮肤状态改善 |

## 实用建议

- **累积微小胜利**：为每一次成功抵御渴求而庆祝。记录它们——这正是您强于尼古丁的明证。  
- **识别个人诱因**：记录每次渴求发生的时间、地点及当时所处情境。规律将自然浮现，再主动打破它。  
- **替换原有仪式感**：电子烟常填补您日常中的特定空档（如休息、压力、无聊）。寻找替代行为——嚼口香糖、散步、喝冰水、使用减压玩具等。  
- **建立责任机制**：向支持您戒断的人分享您的戒断天数。正向的同伴压力能反向推动您坚持到底。  
- **所有数据均仅保存于本地设备**：您的戒断历程、戒断天数及健康里程碑数据，仅存储在您自己的设备上。无数据追踪、无远程服务器、无监控——只有您与属于您的自由。
