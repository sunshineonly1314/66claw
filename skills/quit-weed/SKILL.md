# 戒除大麻

保持头脑清醒。追踪戒断天数。培养新习惯。

## 功能说明

**quit-weed** 通过以下方式，助您开展大麻耐受性中断（t-break）或永久戒断：

- **戒断天数追踪**：持续记录您未使用大麻的天数  
- **渴求应对工具**：当强烈欲望袭来时，提供即时干预措施（呼吸练习、转移注意力技巧、激励提醒）  
- **清醒时间线**：展示关键里程碑节点下预期出现的心理/生理改善  
- **目标设定**：定义您的目标（7日耐受性中断、30日戒断，或永久戒断）  
- **进展追踪**：每日打卡，强化自我责任感  

## 使用方法

### 开启耐受性中断  
请 clawd 启动新的戒断计数：  
- “开启耐受性中断”  
- “开始我的大麻戒断之旅”  
- “设定一个30日大麻戒断目标”  

clawd 将记录起始日期及您设定的目标持续时长。

### 应对渴求  
当欲望来袭时，触发即时支持：  
- “我现在正经历一次渴求”  
- “帮我度过这一关”  
- “我该如何应对这种欲望？”  

获取接地技巧（grounding techniques）、转移注意力建议，以及激励提醒。

### 追踪进展  
随时查询您的戒断天数：  
- “我已经干净多少天了？”  
- “显示我的进展”  
- “当前戒断状态”  

查看当前计数、已达成的里程碑，以及距离下一个目标还剩多少时间。

### 设定目标  
明确何为“成功”：  
- “我想戒断2周”  
- “设定一个90日目标”  
- “让这次戒断成为永久性的”  

clawd 将保存您的目标，并据此动态调整清醒时间线。

### 效益核查  
理解当下身体与心智正在发生的变化：  
- “到目前为止我应该看到哪些益处？”  
- “脑雾何时会消散？”  
- “生理效益时间线”  

获取各阶段关于睡眠、专注力、情绪与认知能力的、基于科学依据的预期效果。

## 清醒时间线

| 里程碑 | 心理/生理变化 |
|-----------|------------------------|
| **第1天** | 初始渴求达峰值；睡眠可能紊乱；精力下降；易怒较常见。 |
| **第3天** | 脑雾开始轻微缓解；睡眠模式趋于正常；食欲恢复。 |
| **第1周** | 思维清晰度明显提升；生动梦境重现；情绪趋于稳定；焦虑减轻。 |
| **第2周** | 专注力与注意力显著增强；精力回升；睡眠质量加深。 |
| **第1个月** | 记忆力与认知功能恢复至基线水平；动力增强；肺部清洁；食欲恢复正常。 |

## 实用建议

1. **大量饮水**：饮水量达日常的2–3倍。有助于净化体内系统并降低渴求强度。

2. **积极活动身体**：每天进行20–30分钟运动（步行、跑步、瑜伽等），可有效压制渴求并加速恢复清醒。

3. **追踪渴求，而不仅是天数**：记录渴求发生的具体*时间*（时刻、诱因、情绪状态），从而识别规律并主动规避。

4. **寻找替代性仪式**：若您习惯在特定时段吸食，请以饮茶、写日记或散步等方式替代。习惯的力量远胜意志力。

5. **所有数据均仅保存于本地设备**：您的戒断天数、目标设定及渴求记录，永不离开您的设备。始终享有完整隐私。
