# 社交媒体戒断计划

*重掌注意力——从每一天无屏幕开始。*

## 功能说明

社交媒体戒断计划通过三大核心机制，助您打破无意识刷屏循环：

- **无屏连续日（Screen-Free Streaks）** —— 连续多日不使用社交媒体应用。积累势头并庆祝里程碑（7 天、30 天、100 天）。  
- **冲动记录（Urge Logging）** —— 当产生刷屏冲动时，即时记录。注明发生时间、所涉平台及触发原因。长期坚持后，规律自然浮现；您将清楚识别自身意志力最薄弱的时段。  
- **时间重获（Time Reclaimed）** —— 计算节省出的时间总量。直观呈现您已夺回多少注意力，并可视化微小决策带来的复利效应。

## 使用方式

### 启动戒断计划  
开启全新戒断连续日。明确您将暂停使用的平台（Instagram、TikTok、Twitter、YouTube 等）。可选设定目标：戒断时长、每日屏幕使用上限，或需屏蔽的应用。

```
"Start my social media detox"
"Detox from Instagram and TikTok for 30 days"
"Begin digital detox - no social media"
```

### 记录冲动  
当您感到想打开某平台时，请立即记录。填写应用名称、发生时间、情绪状态，以及触发因素（无聊、错失恐惧 FOMO、压力、习惯性动作等）。

```
"I wanted to check Instagram at 2pm"
"Log an urge for TikTok - felt bored"
"I almost scrolled Twitter, but didn't"
```

### 追踪重获时间  
查看您已重获的时间总量。按日、周、月分项统计节省时长，并与您过往使用基线进行对比。

```
"How much time have I saved?"
"Show my detox stats"
"Time reclaimed this week"
```

### 设定边界  
配置应用屏蔽器、通知设置或基于时间的限制规则。关闭社交媒体平台的推送通知；若您倾向适度使用而非完全戒断，可设定固定时段进行“检查”。

```
"Block Instagram on my phone"
"Turn off Twitter notifications"
"Set a 15-minute daily limit for YouTube"
```

### 查看进展  
浏览您的连续日数、冲动模式及累计重获时间。识别最难抗拒的应用，定位您意志最薄弱的高发时段。

```
"Show my detox progress"
"What's my current streak?"
"Which app do I miss most?"
```

## 时间重获效果

远离社交媒体的每一分钟都在累积复利。以下是为期一个月的戒断效果示意：

| 指标 | 小时数 | 天数 |
|------|--------|------|
| 日均基线（普通用户） | 2–3 小时 | — |
| 月度重获总量（30 天） | 60–90 小时 | 2.5–3.75 天 |
| 周均重获量 | 14–21 小时 | 0.6–0.9 天 |
| 单小时影响 | 每记录 1 小时 = 100+ 分钟心智清晰度 | — |

*您可自定义基线值，计算逻辑将自动适配您的实际使用数据。*

## 实用建议

1. **每次冲动均须记录，包括成功克制的情形** —— 即使您“差点就点开 Instagram 却及时停下”，也请记录。这些正是您重塑大脑神经通路的关键时刻。

2. **识别您的高危时段** —— 多数复发集中于特定时间段（通勤途中、午休、睡前）。一旦明确自身高危时段，即可提前准备替代活动。

3. **重在替代，而非单纯删除** —— 卸载应用只是第一步；第二步是在那个渴求多巴胺的瞬间，拥有更优选择（散步、阅读、给朋友发消息）。

4. **庆祝每一个短周期连胜** —— 第 3 天往往比第 1 天更难坚持。当达成 7 天、14 天、30 天时，请给予肯定。微小胜利能持续推动正向循环。

5. **所有数据均本地存储于您的设备** —— 戒断日志、冲动模式与重获时间等全部数据永不离开您的设备。隐私保护内置于设计之中。
