# 男性心理健康

一个无评判的空间，助您自我觉察、应对压力、建立心理韧性，远离外界干扰。

## 功能说明

本 skill 提供以下工具：

- **情绪自查**：识别并理解您当前的情绪状态  
- **压力管理**：当事务堆积时，提供切实可行的减压技巧  
- **健康应对方式**：替代有害行为模式、真正有效的策略  
- **模式追踪**：识别反复引发压力的诱因，以及助您恢复的有效方式  

## 使用方法

### 自查
当您需要厘清思绪时，请从此处开始。快速回答几个关于当前状态的问题——情绪、诱因、身体症状。本 skill 将复述您所述内容，并提供视角反馈。

### 减压工具
当压力加剧时，可立即调用以下技巧：呼吸练习、身体扫描、认知重构工具、接地练习。根据紧急程度，耗时约 2–10 分钟。

### 倾诉
有时您只需把事情说出来。此功能助您梳理某个情境，而无需立刻寻求解决方案。本 skill 专注倾听、给予认可，并协助您理清思路。

### 模式追踪
长期使用后，您可识别持续消耗或提振您精力的因素。观察睡眠、工作、人际关系与心理状态之间的关联。所有数据均本地存储——仅您本人可见。

### 获取新视角
当您陷入思维定式时，可与本 skill 展开对话。它将提出澄清性问题、提供认知重构建议，并帮您发现可能忽略的角度。

## 常见议题

- **工作压力**：高压、无力感、有毒职场文化  
- **人际关系**：冲突、疏离、沟通失效  
- **身份认同**：男子气概、社会期待、“足够好”的标准  
- **愤怒**：暴怒、易怒、对控制与释放的挣扎  
- **孤独感**：寂寞、退缩、缺乏联结  
- **人生意义**：方向感缺失、存在意义、对自身道路的质疑  

## 使用提示

1. **请坦诚表达**。此处没有评判。您越真实，获得的反馈越有价值。  
2. **定期使用**，而非仅在危机时刻。自查最适合作为一种习惯——每周一次，或在状态发生变化时启用。  
3. **结合其他工具使用**。治疗师、可信赖的朋友或医生能处理本 skill 无法覆盖的问题。请将其作为补充，而非替代。  
4. **关注长期模式**。单次对话已有帮助；持续数月的数据追踪，才能揭示真正影响您状态的关键因素。  
5. **所有数据均本地保存于您的设备**。未经您明确授权，数据不会离开您的设备。

## 如遇危机

本 skill 不能替代专业心理援助。

- **988**（自杀与危机生命热线）  
- **向 741741 发送短信 “HOME”**（危机短信热线）

若您处于即刻危险中，请拨打 911 或前往最近的急诊室。
