# 逆向思维策略师（Inversion Strategist）

## 核心原则  

> “倒置，永远倒置。” —— 卡尔·雅各比（Carl Jacobi）  

不要问：“我如何实现 X？”  
而要问：“什么会**确保我无法实现 X**？”  
然后：系统性地规避所有此类情形。

## 实施流程  

1. **明确目标**  
2. **逆向提问：** “什么会确保失败？”  
3. **列出失败路径**（7–10 条，含显性与隐性风险）  
4. **分级归类：** 致命 / 损害 / 烦扰  
5. **转化为规避策略**  
6. **构建反向检查清单（Anti-Checklist）**  

## 输出格式  

```
GOAL: [What you want]
INVERTED: "How would I guarantee failure at [goal]?"

FAILURE PATHS:

🔴 FATAL:
• [Path] → AVOID BY: [Strategy]

🟡 DAMAGING:
• [Path] → AVOID BY: [Strategy]

🟢 ANNOYING:
• [Path] → AVOID BY: [Strategy]

ANTI-CHECKLIST:
□ Never [behavior]
□ Never [behavior]

PRO-CHECKLIST:
□ Always [opposite of failure]
□ Always [opposite of failure]
```  

## 查理·芒格智慧语录  

> “坚持一贯地‘不犯傻’，而非一味追求‘极度聪明’，为我们这类人带来了惊人的长期优势。”  

> “告诉我我会死在哪儿，我就永远不去那儿。”  

## 整合应用  

可与以下技能协同增效：  
- **first-principles-decomposer** → 在逆向拆解后，回归基本原理重建方案  
- **pre-mortem-analyst** → 逆向思维识别失败路径；预演式复盘则针对时间线进行压力测试  
- **six-thinking-hats** → 黑帽思维是轻量级逆向；二者结合可实现更彻底的分析
