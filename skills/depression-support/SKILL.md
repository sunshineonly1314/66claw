# 抑郁支持

**每日签到与微小成就。一次一小步。**

## 功能说明

本 skill 提供三项核心功能，助你应对抑郁：

- **情绪追踪**：使用简单的 1–10 分量表或描述性词语（如“糟糕”“尚可”“很好”）记录今日情绪状态；长期追踪可帮助你识别哪些因素有助于改善情绪。
- **行为激活建议**：当动力匮乏时，该 skill 会推荐若干微小、易达成的任务——它们无需消耗精力或意志力，仅需启动惯性即可完成。
- **自我关怀提示**：根据你当前可承受的程度，个性化推送关于补水、活动、睡眠及人际联结的提醒。

## 使用方式

### 记录情绪
提问：“记录我的情绪” 或 “检查我当前的情绪状态”
- 在量表上为情绪打分（1–10 分，或选择描述词：糟糕、不好、尚可、良好、极佳）
- 可选：添加备注，说明可能的诱因或背景情况
- 所有数据仅本地存储，仅你本人可见

### 获取建议
提问：“我今天该做些什么？” 或 “我不知道该做什么”
- 根据你的能量水平，接收 3–5 项微任务
- 每项任务耗时 5–15 分钟（无需承诺长期坚持）
- 示例：喝一杯水、出门站立 30 秒、给一人发条消息、打开一扇窗

### 微小成就
提问：“庆祝一项成就” 或 “我今天完成了某件事”
- 记录任何成就，无论多微小
- 长期追踪行动累积的正向势能
- 逐步积累证据，驳斥“一切皆无意义”的消极声音

### 自我关怀自查
提问：“提醒我自我关怀” 或 “我是否在好好照顾自己？”
- 快速核查基础需求：睡眠、饮食、饮水、活动、人际联结
- 不带评判——只唤起觉察
- 即刻为你推荐一项可立即执行的小行动

### 追踪模式
提问：“展示我的情绪历史” 或 “你发现了哪些规律？”
- 按周或按月概览情绪趋势
- 识别与状态改善相关的因素（例如：更多睡眠？更多户外时间？与人交谈？）
- 帮助你提前识别恶化征兆

## 行为激活（Behavioral Activation）

当抑郁告诉你“一切皆无意义”，并剥夺了你的动力时，行为激活通过将行动与感受解耦，打破这一恶性循环。

**原有循环**：你不想做某事 → 于是等待“想做”的感觉出现 → 但抑郁状态下你永远等不到这种感觉 → 最终什么也不做 → 进而加剧抑郁。

**逆转方式**：即便只有 5% 的能力，也先行动起来。感受会跟随行动而来，而非相反。

**本 skill 推荐的微任务示例**：
- 身体类：伸展、站立、走到窗边、喝水、洗澡  
- 社交类：给一人发消息、阅读一条信息、对一则帖子做出反应  
- 创意类：画一条线、写下三个词、哼一首歌  
- 认知类：阅读一段文字、观看一个 2 分钟视频、解一道谜题  

从最小可行版本开始。“去散个步”可简化为“踏出屋外”。仅此而已。势能由此而生。

## 实用提示

1. **每日签到，而非反复刷屏**：一天一次足矣。抑郁易诱发思维反刍——切勿每小时都追踪情绪。

2. **完成任务无需以感觉变好为前提**：任务本身即是成就。感觉变好只是附带效果，而非必要条件。

3. **微小成就仍是成就**：糟糕日子里洗个澡，其意义不亚于状态良好时攀登一座山峰。你的大脑无法区分二者——它只确认你确实做了某事。

4. **状态尚可时，请为未来的自己铺路**：在状态较好的日子里，记下哪些方法曾帮到你，并写下来。你抑郁时的自己，将迫切需要这些信息。

5. **所有数据均仅保存于你的本地设备**：不上传云端。你的情绪记录、备注与模式分析，仅存在于你的设备中——无追踪、无数据分析、无共享。
