# Twitter 🐦

Twitter/X 平台集成。

## 设置

```bash
export TWITTER_API_KEY="your_api_key"
export TWITTER_API_SECRET="your_api_secret"
export TWITTER_ACCESS_TOKEN="your_access_token"
```

## 功能

- 发布推文  
- 读取时间线  
- 搜索推文  
- 管理关注者  
- 数据分析  
- 定时发布  

## 使用示例

```
"Post tweet: Hello world!"
"Show my latest mentions"
"Search tweets about #AI"
```
