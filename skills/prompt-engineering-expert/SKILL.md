# 提示工程专家 skill

本 skill 赋予 Claude 在提示工程、自定义说明（Custom Instructions）设计及提示优化方面的深度专业知识。它提供关于构建高效 AI 提示、设计 agent 说明（Instructions），以及持续迭代提升提示性能的全面指导。

## 能力范围

- **提示编写最佳实践**：关于结构清晰、直截了当、格式规范的提示的专家级指导  
- **自定义说明（Custom Instructions）设计**：为 AI agents 创建高效的系统提示（system prompts）与自定义说明（Custom Instructions）  
- **提示优化**：分析、精炼并改进现有提示，以获得更优性能  
- **进阶技术**：思维链（Chain-of-thought）提示、少样本（few-shot）示例、XML 标签、基于角色（role-based）提示  
- **评估与测试**：为提示评估开发测试用例与成功标准  
- **反模式（anti-patterns）识别**：识别并纠正常见的提示工程错误  
- **上下文管理（Context Management）**：优化 token 使用与上下文窗口管理  
- **多模态提示（Multimodal Prompting）**：面向视觉（vision）、嵌入向量（embeddings）与文件输入的提示设计指导  

## 应用场景

- 精炼模糊或低效的提示  
- 为特定领域创建专用系统提示  
- 为 AI agents 和 skills 设计自定义说明（Custom Instructions）  
- 优化提示以提升一致性与可靠性  
- 教授提示工程最佳实践  
- 调试提示性能问题  
- 创建可复用工作流所需的提示模板
